## Practical file

`10-Practical-File/` has two sub-folders:

- `Activity-Records/` — one page per NCERT activity: aim, materials, observation
  table, result. The lab exam is drawn from these.
- `Diagrams/` — labelled diagrams (human heart, nephron, flower, ray diagrams,
  magnetic field patterns). Practise them at exam scale, not tiny.

Physics numericals (Chapters 9, 10, 11) and the electricity/mirror-lens formula
set are the usual mark-losers — keep a running list of them in
`09-Revision-Sheets/`.
