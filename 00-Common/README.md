# 00 · Common (all subjects)

Things that are not subject-specific. Fill these first — they are what stop you
studying the wrong thing.

| Folder | What goes in it |
|---|---|
| `01-CBSE-Syllabus-PDFs/` | The official syllabus PDF for **every** subject you take, for the current session. One file per subject, named `041-Mathematics-Standard.pdf` style. |
| `02-Exam-Date-Sheet/` | The board date sheet as soon as CBSE publishes it, plus your own countdown. |
| `03-Marking-Scheme/` | CBSE marking schemes for past papers. Reading one tells you exactly how marks are split inside an answer — usually worth more than another hour of revision. |
| `04-Sample-Papers/` | The official CBSE sample paper for each subject, plus your timed attempts. |
| `05-Previous-Year-Papers/` | Full past board papers, by year. Name them `2025-Science-Set1.pdf`. |
| `06-Study-Plan/` | Your timetable, the chapter tracker, and a weak-area list. |
| `07-Misc/` | Anything that does not fit above. |

## The five-minute setup

1. Download the current session's syllabus PDF for each of your six subjects
   into `01-CBSE-Syllabus-PDFs/`.
2. In each subject's README, tick off any chapter CBSE has marked as not for
   assessment, and cross it out in your own textbook.
3. Start a `chapter-tracker.md` in `06-Study-Plan/` — one row per chapter,
   columns for *read*, *notes done*, *NCERT solved*, *PYQ done*, *revised*.

  <https://cbseacademic.nic.in/curriculum_2027.html>

The page also lists skill subjects (`Curriculum27/sec/…`) — those file names
differ per subject and per class, so take them from the page itself.

CBSE normally publishes the session's curriculum mid-year and the date sheet
early in the exam season. Re-check both — chapter lists do change between
sessions. The folder tree in this repository was checked against the 2026–27
curriculum on 12 Sep 2026.
