CBSE • CLASS 10 • COMPUTER APPLICATIONS

Computer Applications — Practical & internal assessment

Computer Applications का 50 अंक का प्रैक्टिकल — लैब टेस्ट (20) + फ़ाइल वर्क (10) + वाइवा (5) + वेबसाइट प्रोजेक्ट (15)।

  • Lab test (20): निर्धारित समय में एक HTML पेज या छोटी वेबसाइट — टेबल, फ़ॉर्म, लिंक और छवि सहित।
  • File work (10): पूरे वर्ष के अभ्यास का क्रमबद्ध संग्रह; हर प्रयोग का उद्देश्य, कोड और आउटपुट लिखें।
  • Viva (5): टैग की परिभाषा, प्रोटोकॉल के पूरे नाम, साइबर-सुरक्षा के उपाय — छोटे और सीधे प्रश्न।
  • Website project (15): बहु-पेज साइट — होम पेज, कम-से-कम तीन अन्य पेज, नेविगेशन लिंक, टेबल, फ़ॉर्म और छवियाँ।
  • अभ्यास: किसी भी टेक्स्ट एडिटर में पेज लिखें और ब्राउज़र में खोलें। रोज़ एक पेज = प्रोजेक्ट आधा पूरा।
