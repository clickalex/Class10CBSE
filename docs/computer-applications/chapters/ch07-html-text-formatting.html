🎯 Marks lens

Produce a given visual output as HTML; name the attribute that does a given job.
Output-prediction questions are pure practice.

📖 Deep concepts

1. Style tags. <b> makes text bold, <i> makes it italic, <u> underlines it, <tt> shows typewriter text, <strike> draws a line through it. <sub> lowers text for chemical formulas like H<sub>2</sub>O, and <sup> raises it for powers like x<sup>2</sup>. <center> centres a block of content.
2. The attributes that matter. align takes left, center or right and is used on <p>, <h1>–<h6> and <div>. <font> takes face (typeface), size (1 to 7) and color (a name or a hex code like #FF0000). <body> accepts bgcolor for the page background and text for the default text colour. <hr> accepts size, width, color and noshade.
3. Unordered lists. <ul> makes a bulleted list, and each item goes in <li>. The type attribute changes the bullet: disc is the filled circle and the default, circle is hollow, and square is a filled square.
4. Ordered lists. <ol> makes a numbered list, also using <li>. Its type attribute chooses the numbering style: 1 for numbers (the default), A for capital letters, a for small letters, I for capital Roman and i for small Roman. The start attribute says which number to begin at — <ol start='5'> begins at 5.
5. Definition lists. <dl> is a definition list; each term goes in <dt> and its description in <dd>, which the browser indents automatically. Lists can be nested — a <ul> inside an <li> creates a sub-list.

🛠️ Method, step by step

1. Identify what the output shows: a paragraph, a heading, or a list?
2. If it is a list, count the items and check whether the markers are bullets (<ul>) or numbers (<ol>).
3. Write the opening list tag with its type attribute if the marker is not the default.
4. Wrap every item in <li> ... </li>.
5. Close the list tag.
6. For formatting, apply <b>, <i>, <u>, <sub> or <sup> to only the words that look different.

🧠 Memory tricks

  • <ul> = bullets, <ol> = numbers. Both use <li>.
  • <font> has three attributes: face, size, color. Nothing else.
  • <sub> sinks, <sup> rises. H<sub>2</sub>O versus x<sup>2`</sup>.
  • <ol type='A'> gives A, B, C; <ol start='3'> begins at 3. They can be combined.

⚠️ Mistakes that cost marks

  • Using <ul> when the output clearly shows numbers.
  • Forgetting <li> around each item — the list tag alone does not create items.
  • Writing align='middle' — the correct value is center.
  • Thinking <font size> takes pixel values — it takes 1 to 7.
  • Nesting wrongly: <b><i>text</b></i> should be <b><i>text</i></b>.

SHORTS13 marks

1. Write HTML to display a numbered list of four subjects beginning at number 3, using capital Roman numerals.

Show Answer

Ans:

<html>
<body>
<ol type='I' start='3'>
<li>Mathematics</li>
<li>Science</li>
<li>Social Science</li>
<li>English</li>
</ol>
</body>
</html>
The type='I' attribute gives capital Roman numerals and start='3' makes the list begin at III.

SHORTS22 marks

2. Write the HTML to display the text 'Water' with the 2 as a subscript.

Show Answer

Ans:

<p>Water is written as H<sub>2</sub>O.</p>
The <sub> tag lowers the character it wraps, producing H₂O. Its opposite is <sup>, which raises text — used for powers such as x<sup>2</sup>.

SHORTS33 marks

3. Explain the <font> tag with its attributes.

Show Answer

Ans:

The <font> tag changes how a piece of text looks. It takes three attributes. face sets the typeface, for example face='Arial'. size sets the size on a scale of 1 to 7, for example size='5'. color sets the colour, either by name such as color='red' or by hexadecimal code such as color='#FF0000'. An example is <font face='Arial' size='5' color='blue'>Hello</font>.

SHORTS42 marks

4. Differentiate between <ul> and <ol>.

Show Answer

Ans:

<ul> creates an unordered list, where each item is marked with a bullet and the order does not matter. <ol> creates an ordered list, where each item is numbered and the sequence is meaningful. Both use <li> for the individual items, and both can be nested inside another list to create sub-levels.

SHORTS52 marks

5. Write HTML for a horizontal line, 5 pixels thick, covering half the page width, in red.

Show Answer

Ans:

<hr size='5' width='50%' color='red'>
<hr> is an empty tag, so it has no closing partner. size sets the thickness in pixels, width can be a percentage or a pixel value, and color sets the line colour.
