🎯 Marks lens

Definitions, one-mark factual questions and the history of the internet.
The terms you learn here reappear in every later chapter.

📖 Deep concepts

1. What the internet is. The internet is a worldwide network of networks — millions of smaller networks joined together so that any computer can reach any other. It is not owned by any single organisation; it runs on shared standards called protocols.
2. How it began. It grew out of ARPANET, started in 1969 by the US Department of Defense's research agency. The first message travelled between UCLA and Stanford. India connected to the internet on 15 August 1995 through VSNL. The World Wide Web, invented by Tim Berners-Lee in 1989, is what made the internet usable by ordinary people — the web is part of the internet, not the same thing as it.
3. The building blocks. A client requests something, a server supplies it. An ISP (Internet Service Provider) gives you the connection — Airtel, Jio, BSNL. A host is any computer permanently attached to the internet with its own address. Bandwidth is how much data can move per second; latency is how long a request takes to arrive.
4. Addressing. Every device on the internet has an IP address (for example 192.168.1.5). Because numbers are hard to remember, DNS (Domain Name System) translates names like clickalex.github.io into IP addresses. IPv4 uses 32 bits, which ran out — IPv6 uses 128 bits and is the replacement.

🧮 Formulas to memorise

  • Bandwidth measured in bps: 1 Kbps = 1000 bps · 1 Mbps = 1000 Kbps · 1 Gbps = 1000 Mbps
  • Download speed in seconds ≈ file size in megabits ÷ speed in Mbps
  • ISP = Internet Service Provider; every device on the internet has an IP address
  • IP address formats: IPv4 = 4 numbers 0–255 separated by dots; IPv6 = eight groups of hex

🛠️ Method, step by step

  1. Identify how the device connects — fibre, DSL, cable, mobile data or Wi-Fi.
  2. Check the IP configuration; a device with no IP or an address starting 169.254 is not connected.
  3. Test the link in order: your device → the router → the ISP → a website by name.
  4. If a name fails but a ping to an IP works, the fault is DNS, not the connection.

🧠 Memory tricks

  • ARPANET 1969, Berners-Lee 1989, India 1995. Three dates, three marks.
  • Web ≠ internet. The web is one service running on the internet, like email and FTP.
  • DNS = the internet's phone book. Names in, IP addresses out.
  • IPv4 = 32 bits, IPv6 = 128 bits. The number of bits is the whole difference you are asked about.

⚠️ Mistakes that cost marks

  • Calling the World Wide Web the same thing as the internet — the web is a service on it.
  • Writing that the internet has a single owner or central controller — it does not.
  • Confusing bandwidth (capacity) with latency (delay).

SHORTS11 mark

1. When did India first get internet access, and through which provider?

Show Answer

Ans:

India got internet access on 15 August 1995, through VSNL (Videsh Sanchar Nigam Limited).

SHORTS22 marks

2. What is the internet? Give two of its features.

Show Answer

Ans:

The internet is a worldwide network of networks in which millions of smaller networks are interconnected, allowing any computer to communicate with any other. Two of its features are: it has no single owner or central control, running instead on shared protocols; and it provides many services at once — the World Wide Web, email, file transfer and video calls all travel over the same infrastructure.

SHORTS32 marks

3. What was ARPANET and why is it important?

Show Answer

Ans:

ARPANET (Advanced Research Projects Agency Network) was started in 1969 by the US Department of Defense's research agency. It is important because it was the first packet-switched network and the direct ancestor of today's internet — its first connection ran between UCLA and Stanford Research Institute.

SHORTS42 marks

4. What is the role of DNS?

Show Answer

Ans:

DNS (Domain Name System) translates human-readable domain names such as clickalex.github.io into the numeric IP addresses that computers actually use to find each other. Without it, users would have to memorise numbers like 140.82.121.4 to reach any website. DNS works like a distributed phone book for the internet.

SHORTS52 marks

5. What is the internet and how did it begin?

Show Answer

Ans:

The internet is a worldwide network of networks that links millions of computers using the TCP/IP family of protocols. It began in 1969 as ARPANET, a project of the US Department of Defense that linked four university computers, and grew into the public network we use after the World Wide Web was invented in 1989.

SHORTS63 marks

6. Distinguish between IPv4 and IPv6.

Show Answer

Ans:

IPv4 uses 32-bit addresses, giving roughly 4.3 billion possible addresses — written as four numbers separated by dots, such as 192.168.1.5. IPv6 uses 128-bit addresses, written in hexadecimal groups such as 2001:0db8:85a3::8a2e:0370:7334. IPv6 was created because the supply of IPv4 addresses was exhausted by the growth in connected devices; it also has better built-in support for security and automatic configuration.

SHORTS93 marks

9. Explain the terms World Wide Web, webpage, website and homepage.

Show Answer

Ans:

The World Wide Web is the collection of linked documents and resources reached over the internet, invented by Tim Berners-Lee.
A webpage is a single document, written in HTML, that a browser displays.
A website is a group of related webpages stored under one domain name, such as a school's site with pages for admissions, results and contact.
The homepage is the first page that opens when you visit a website, from which the other pages are reached.
