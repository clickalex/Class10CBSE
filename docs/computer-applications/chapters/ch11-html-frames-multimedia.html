📖 Deep concepts

1. Frames. A frame divides the browser window into separate regions, each showing a different HTML document. Frames are declared in a <frameset> document, which replaces <body> entirely. rows='30%,70%' splits the window horizontally into stacked bands; cols='25%,75%' splits it vertically into side-by-side columns. Each region is then filled by a <frame src='file.html'>. The name attribute on a frame lets a link in one frame load its target into another, using target.
2. iframe. <iframe src='page.html' width='600' height='400'> embeds another page inside the current one, without needing a frameset. It is still widely used for maps and embedded videos. frameborder='0' removes the visible border.
3. Multimedia. <audio src='song.mp3' controls> plays sound; <video src='clip.mp4' width='400' controls> plays video. The controls attribute is what makes the play, pause and volume buttons appear — without it the media is invisible and unusable. autoplay starts immediately, loop repeats, and muted silences it.
4. Special tags. <marquee> scrolls text or an image across the page; direction sets the direction, behavior sets scroll, slide or alternate, and scrollamount sets the speed. <meta> sits in <head> and describes the page to browsers and search engines. <pre> preserves spaces and line breaks exactly as typed, which is why it is used for code samples. <div> and <span> are generic containers used to group content for styling.

🧠 Memory tricks

  • rows = horizontal bands, cols = vertical columns. Picture the lines you are drawing.
  • A frameset document has no <body>.
  • No controls attribute = no visible player.
  • <marquee> scrolls, <pre> preserves spacing.
  • <iframe> embeds inside a normal page; <frameset> splits the whole window.

⚠️ Mistakes that cost marks

  • Writing a <body> in a frameset document — <frameset> replaces it.
  • Forgetting controls on <audio> or <video>, so nothing shows.
  • Confusing rows and cols in a frameset.
  • Confusing <iframe> with <frame> — one works inside a normal page, the other only inside a frameset.

SHORTS13 marks

1. Write HTML to divide the browser window into two rows, the top 25% showing a header and the bottom 75% showing content.

Show Answer

Ans:

<html>
<head><title>Frames</title></head>
<frameset rows='25%,75%'>
<frame src='header.html'>
<frame src='content.html'>
</frameset>
</html>
Note that there is no <body> — a <frameset> document replaces it. rows splits the window into horizontal bands, and each <frame> loads one document into its band.

SHORTS23 marks

2. Explain the <audio> tag with its attributes.

Show Answer

Ans:

The <audio> tag embeds a sound file in a page. src gives the location of the audio file. controls displays the play, pause and volume buttons — without it the player is invisible and the user cannot control playback. autoplay starts the sound as soon as the page loads, loop repeats it endlessly, and muted starts it silently. An example is <audio src='song.mp3' controls loop>.

SHORTS32 marks

3. What is the difference between <frame> and <iframe>?

Show Answer

Ans:

A <frame> can only be used inside a <frameset>, which replaces the document's <body> and splits the entire browser window into separate regions. An <iframe> (inline frame) is placed inside an ordinary page and embeds another document in a rectangular area within it, leaving the rest of the page untouched. In practice iframes are still common for maps and embedded videos, while framesets are considered outdated.

SHORTS42 marks

4. What does the <marquee> tag do? Name two of its attributes.

Show Answer

Ans:

The <marquee> tag makes its content scroll across the page. Two of its attributes are direction, which sets the direction of movement — left, right, up or down — and scrollamount, which sets how fast it moves. A third, behavior, chooses between scroll (continuous), slide (moves once and stops) and alternate (bounces back and forth).

SHORTS52 marks

5. Why is the <pre> tag used?

Show Answer

Ans:

The <pre> tag displays text exactly as it is typed, preserving all spaces, tabs and line breaks. Ordinary HTML collapses multiple spaces into one and ignores line breaks, so <pre> is used whenever the formatting itself matters — for code samples, ASCII diagrams or poetry.
