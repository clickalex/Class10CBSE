🎯 Marks lens

Define IPR and its types, explain plagiarism and software piracy, distinguish FOSS from proprietary software.
Be precise about the four IPR types.

📖 Deep concepts

1. Cybercrime. A cybercrime is any illegal act in which a computer or network is used as a tool, a target, or a place to store evidence. Examples are hacking, spreading malware, online fraud, identity theft, publishing obscene material, and attacking a website so that it stops working.
2. Intellectual property rights. IPR is the legal right given to the creator of an original work, so that others cannot copy or profit from it without permission. The four main types are: copyright, which protects original literary, artistic, musical and software works; patent, which protects an invention or process for a fixed period; trademark, which protects a brand name, logo or slogan; and trade secret, which protects confidential business information such as a recipe or a formula.
3. Violations. Software piracy is copying, distributing or using software without a licence. Plagiarism is presenting someone else's words, ideas or code as your own, even with no money involved — which is what makes it an ethical offence as well as a legal one. Both are avoided by citing sources properly and using only licensed or freely licensed material.
4. FOSS versus proprietary. Free and Open Source Software (FOSS) can be used, studied, modified and redistributed by anyone because its source code is available; examples are Linux, Firefox and LibreOffice. Free software here means freedom, not necessarily zero price. Proprietary software keeps its source code secret and restricts copying and modification under a licence; examples are Microsoft Windows and Adobe Photoshop. Freeware is free to use but closed, and shareware is free to try for a limited period before payment.

🧠 Memory tricks

  • Copyright = works, patent = inventions, trademark = brands, trade secret = secrets.
  • Piracy involves money or licences; plagiarism involves credit.
  • FOSS = source code is open. Free as in freedom, not free as in price.
  • Freeware is closed but free; shareware is a paid trial.

⚠️ Mistakes that cost marks

  • Confusing copyright and patent — copyright covers creative works, patent covers inventions.
  • Confusing plagiarism with piracy — plagiarism is taking credit, piracy is unlicensed copying.
  • Saying FOSS is free because it costs nothing — it is free because the source is open.
  • Listing freeware as open source — freeware is usually closed source.

SHORTS13 marks

1. What is IPR? Name and explain its four main types.

Show Answer

Ans:

IPR (Intellectual Property Rights) are the legal rights granted to the creator of an original work, allowing them to control and benefit from its use and stopping others from copying it without permission. The four main types are copyright, which protects original literary, artistic, musical and software works; patent, which protects an invention or process for a fixed period; trademark, which protects a brand name, logo or slogan; and trade secret, which protects confidential business information such as a formula or a method.

SHORTS22 marks

2. What is plagiarism and how can it be avoided?

Show Answer

Ans:

Plagiarism is presenting someone else's words, ideas, data or code as if they were your own, without giving credit. It is an ethical offence even when no money changes hands. It is avoided by always citing the source, using quotation marks around copied text, paraphrasing genuinely rather than swapping a few words, and keeping a record of every source consulted while working.

SHORTS33 marks

3. Differentiate between free and open source software and proprietary software, with examples.

Show Answer

Ans:

FOSS makes the source code available, so anyone may use, study, modify and redistribute the program; examples are Linux, Firefox and LibreOffice. Here 'free' refers to freedom rather than price. Proprietary software keeps its source code secret and grants only a licence to use it, forbidding copying, modification or redistribution; examples are Microsoft Windows and Adobe Photoshop. The practical difference is that with FOSS you can fix or extend the software yourself, while with proprietary software you depend entirely on the vendor.

SHORTS42 marks

4. What is software piracy?

Show Answer

Ans:

Software piracy is the unauthorised copying, distribution or use of software without a valid licence. It includes installing one licensed copy on many machines, downloading cracked versions, and selling counterfeit discs. It deprives developers of income and often exposes the user to malware, since pirated copies are frequently bundled with it.

SHORTS52 marks

5. Distinguish between freeware and shareware.

Show Answer

Ans:

Freeware can be used free of charge indefinitely, but its source code is usually closed and it cannot be modified or sold — an example is Skype. Shareware is distributed free only as a trial, either for a limited period or with reduced features, and the user must pay to continue using it after the trial ends.
