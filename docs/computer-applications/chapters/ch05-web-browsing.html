🎯 Marks lens

Define terms, compare browsers with search engines, explain cookies and caching.
This chapter closes Unit I — revise it as one block.

📖 Deep concepts

1. Browser versus search engine. A web browser (Chrome, Firefox, Edge, Safari) is software on your device that requests and displays pages. A search engine (Google, Bing) is a website that indexes other websites so you can find them. You use a browser to reach a search engine — they are not alternatives to each other.
2. Pages, sites and home pages. A web page is a single HTML document. A website is a collection of related pages under one domain. The home page is the entry page, usually index.html. A web portal gathers links, news and services in one place.
3. Cookies and cache. A cookie is a small piece of data a website stores in your browser to remember you — a login, a language, the contents of a cart. Caching stores a local copy of a page or image so it loads faster and uses less bandwidth the next time. Browsing history is the record of pages visited. All three raise privacy questions, which is why browsers now offer private modes.
4. Finding things. A search engine uses a crawler (or spider) to visit pages, an index to store what it found, and a ranking algorithm to order results. Bookmarking saves an address you want to return to; RSS feeds push updates from a site to you instead of you checking it.

🧮 Formulas to memorise

  • A URL reads: scheme://host:port/path?query#fragment — https://cbse.gov.in/syllabus
  • Search operators: "exact phrase", -exclude, site:domain, filetype:pdf
  • Browser cache stores copies; incognito mode does not save history or cookies locally
  • Cookie = a small file a site leaves on your device to remember you

🛠️ Method, step by step

  1. Read the address bar first — the scheme (http or https) and the domain tell you where you are.
  2. Check the padlock: it means the connection is encrypted, not that the site is honest.
  3. Search with operators — quotes for a phrase, minus to drop a meaning, site: to stay on one domain.
  4. Judge the result before using it: who published it, when, and does another source agree.

🧠 Memory tricks

  • Browser is on your machine; search engine is on the web.
  • Cookie remembers you, cache speeds you up, history records you. Three different things, three different questions.
  • Crawler visits → index stores → algorithm ranks.
  • A website is many pages; a web page is one document.

⚠️ Mistakes that cost marks

  • Calling Google a browser — it is a search engine, a website.
  • Confusing cookies with cache — cookies are identity data, cache is a speed copy.
  • Saying a home page is the same as a web page in general — the home page is specifically the entry page.

SHORTS11 mark

1. Name any three web browsers.

Show Answer

Ans:

Google Chrome, Mozilla Firefox and Microsoft Edge. Apple's Safari and Opera are other common examples.

SHORTS22 marks

2. Differentiate between a web browser and a search engine.

Show Answer

Ans:

A web browser is software installed on your computer or phone — Chrome, Firefox, Edge or Safari — that sends requests for pages and renders the HTML it receives into the page you see. A search engine such as Google is itself a website whose job is to index other websites and return a ranked list of results for your query. You need a browser in order to open a search engine, so they work together rather than as alternatives.

SHORTS32 marks

3. What are cookies and why are they used?

Show Answer

Ans:

A cookie is a small piece of data that a website stores in the user's browser. Websites use cookies to remember something about the user between visits — whether they are logged in, which language they chose, or what is in their shopping cart. Without cookies, every page request would be treated as a brand-new visitor. Because cookies can also be used to track browsing behaviour, browsers offer private modes that discard them when the window closes.

SHORTS42 marks

4. What is caching and what is its benefit?

Show Answer

Ans:

Caching means keeping a local copy of a resource — a page, an image or a stylesheet — so that it does not have to be downloaded again. The benefits are that pages load faster and use less bandwidth, which matters most on slow or metered connections. The trade-off is that a cached copy can be out of date, which is why a forced refresh sometimes shows a different page.

SHORTS52 marks

5. How does a search engine find and rank pages?

Show Answer

Ans:

A search engine uses a crawler — also called a spider — that automatically visits web pages and follows the links on them to discover more. What it finds is stored in an index, a huge searchable catalogue. When you type a query, a ranking algorithm scores the matching pages by relevance, authority and quality, and returns them in order.

SHORTS62 marks

6. What is the difference between a web browser and a search engine?

Show Answer

Ans:

A browser is the program that requests, receives and displays web pages — Chrome, Firefox, Edge or Safari. A search engine is a website, such as Google or Bing, that keeps an index of pages and returns a list of results for your query. The browser is the tool you use; the search engine is a site you visit with it.

SHORTS93 marks

9. What are cookies and cache, and why should you clear them sometimes?

Show Answer

Ans:

Cookies are small files a website stores on your computer to remember who you are, what is in your basket and what your preferences are.
The cache stores copies of images, scripts and pages so that a site loads faster the next time you visit it.
Clearing them removes old or corrupted files that can make a site load wrongly, frees disk space, logs you out of accounts and limits tracking.
The cost is that you have to sign in again and the first visit to a site is slower.
