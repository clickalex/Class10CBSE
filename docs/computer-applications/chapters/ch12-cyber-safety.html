🎯 Marks lens

Define terms, list threats, give safety measures.
Shortest unit, highest marks per hour studied.

📖 Deep concepts

1. The core definitions. Cyber ethics are the moral rules that guide behaviour on the internet — what is right to do online. Cyber safety is the practice of protecting yourself and your devices from online harm. Cyber security is the wider technical protection of systems, networks and data from attack. Ethics is about behaviour, safety is about personal protection, security is about defending systems.
2. Common threats. Malware is any malicious software. A virus attaches itself to a file and spreads when that file is shared. A worm spreads on its own across a network without needing a host file. A trojan horse pretends to be a useful program but carries a hidden payload. Spyware quietly collects information about you. Ransomware encrypts your files and demands payment for the key. A logic bomb waits for a trigger — a date or an event — before firing. Adware pushes unwanted advertising.
3. Attacks on people. Phishing is a fake email or website that tricks you into handing over passwords or card details. Smishing does the same by SMS, and vishing by voice call. Cyberstalking is repeated online harassment. Identity theft is using someone's personal data to impersonate them. Cyberbullying is the use of digital tools to intimidate or humiliate, mostly affecting students.
4. Staying safe. Use a strong, unique password for every account and a password manager. Turn on two-factor authentication. Keep the operating system, browser and antivirus updated. Never open attachments or links from unknown senders. Use HTTPS sites for any payment. Do not share personal details, photographs or your location publicly. Back up important files regularly, and report abuse rather than replying to it.

🧠 Memory tricks

  • Virus needs a host file, worm travels alone.
  • Trojan looks useful, spyware watches you, ransomware locks you out.
  • Phishing = email, smishing = SMS, vishing = voice call.
  • Ethics = behaviour, safety = you, security = systems.

⚠️ Mistakes that cost marks

  • Confusing virus and worm — a worm does not need a host file.
  • Confusing cyber safety with cyber security — one protects the person, the other the system.
  • Listing safety measures without naming strong passwords and two-factor authentication.
  • Treating trojan as a self-spreading threat — it must be installed by the user, tricked into it.

SHORTS12 marks

1. What is the difference between cyber safety and cyber security?

Show Answer

Ans:

Cyber safety is about protecting an individual user online — using strong passwords, avoiding suspicious links, not oversharing personal information. Cyber security is the broader technical discipline of protecting computers, networks, systems and data from unauthorised access and attack, using firewalls, encryption, access control and monitoring. Safety is personal practice; security is systematic defence.

SHORTS23 marks

2. Differentiate between a virus, a worm and a trojan horse.

Show Answer

Ans:

A virus is malicious code that attaches itself to a legitimate file and spreads only when that infected file is opened or shared, so it needs a human action to move. A worm is a standalone program that copies itself across a network automatically, needing no host file and no user action, which is why worms spread so fast. A trojan horse does not spread at all — it disguises itself as a useful or attractive program so the user installs it willingly, and only then does its hidden payload run.

SHORTS32 marks

3. What is phishing? How can it be avoided?

Show Answer

Ans:

Phishing is an attack in which a fake email or website imitates a trusted organisation — a bank, a school or a popular service — and tricks the user into entering passwords, card numbers or other sensitive data. It can be avoided by checking the sender's actual address rather than the display name, never clicking links in unsolicited messages, typing the website address yourself instead, looking for HTTPS before entering credentials, and enabling two-factor authentication so a stolen password alone is not enough.

SHORTS43 marks

4. List five safety measures for using the internet safely.

Show Answer

Ans:

  • Use a strong, unique password for each account and never reuse one; a password manager helps.
  • Enable two-factor authentication so a stolen password is not enough on its own.
  • Keep the operating system, browser and antivirus software updated, since updates close known security holes.
  • Never open attachments or follow links from unknown senders, and verify the address of any site asking for payment.
  • Back up important files regularly, and avoid sharing personal details, photographs or location publicly.
SHORTS51 mark

5. What is ransomware?

Show Answer

Ans:

Ransomware is a type of malware that encrypts the victim's files so they cannot be opened, and then demands payment — usually in cryptocurrency — in exchange for the decryption key. Regular offline backups are the main defence, because they let the victim restore the data without paying.
