Chapter 9 · HTML Tables

Chapter 9 of 14. rowspan and colspan are worth real marks and almost everyone gets them backwards.

🎯 Marks lens

Convert a drawn table into HTML and vice versa; explain rowspan and colspan.
Draw the grid first, then write the code.

📖 Deep concepts

1. The structure. A table is built from three nested levels. <table> is the whole grid. Each <tr> is one row (think table row). Each <td> is one cell or data column inside that row (think table data). A table with three rows and two columns needs three <tr> blocks, each containing two <td> cells.
2. Table attributes. On <table>: border sets the thickness of the grid lines in pixels (border='1' is the common value), width and height size the table, align positions it, cellpadding is the space between a cell's content and its own edge, and cellspacing is the gap between neighbouring cells. bgcolor fills the background.
3. Header cells. <th> is a header cell. The browser renders its text bold and centred by default, and it marks the cell as a label for the column or row. A <caption> placed just inside <table> gives the whole table a title.
4. Merging cells — the exam favourite. colspan='n' merges a cell across n columns, so that row then needs fewer <td> tags. rowspan='n' merges a cell down n rows, so the rows below must omit the cell it is covering. Get these wrong and the table visibly breaks.

🧮 Formulas to memorise

  • A 2×2 table with a heading row
  • <table border='1'>
  • <tr><th>Name</th><th>Marks</th></tr>
  • <tr><td>Asha</td><td>88</td></tr>
  • </table>
  • Merging: <td colspan='2'>Full width</td> spans two columns. <td rowspan='2'>Tall cell</td> spans two rows.

🛠️ Method, step by step

1. Sketch the table on paper and count rows and columns.
2. Write <table border='1'> and </table>.
3. Write one <tr> ... </tr> per row.
4. Inside each row write one <td> ... </td> per cell.
5. Use <th> instead of <td> for the header row.
6. For any merged cell, add colspan or rowspan and delete the cells it replaces.
7. Open it in a browser and compare with your sketch.

🧠 Memory tricks

  • <tr> = row, <td> = cell. Rows contain cells, never the other way round.
  • colspan = wide, rowspan = tall. Say it out loud.
  • Every cell you merge must be deleted from its row, or the table shifts.
  • cellpadding is inside the cell, cellspacing is between cells.

⚠️ Mistakes that cost marks

  • Putting <td> directly inside <table> without a <tr>.
  • Swapping rowspan and colspan — the single most common table error.
  • Forgetting to remove the cells a merge replaces, so the row ends up too wide.
  • Writing border=1 when the question asks for no border — use border='0'.
  • Confusing cellpadding with cellspacing.

❓ Exam Q&A

4 marks Write HTML for a table with a merged title cell across two columns, a header row and one data row.

<table border='1' width='300'>
<tr><th colspan='2'>Student Report</th></tr>
<tr><th>Name</th><th>Marks</th></tr>
<tr><td>Asha</td><td>88</td></tr>
</table>
The first row uses colspan='2' so the title stretches across both columns; that row therefore contains only one cell instead of two.

3 marks Explain colspan and rowspan with an example.

colspan='n' makes a single cell stretch across n columns. For example <td colspan='3'>Heading</td> occupies the width of three columns, so that row needs three fewer <td> tags than a normal row. rowspan='n' makes a cell stretch down n rows. For example, a <td rowspan='2'>Science</td> in the first of two rows covers both rows, so the second row must not include a cell in that position. Using them incorrectly is what makes a table look misaligned.

2 marks What is the difference between <td> and <th>?

<td> is an ordinary data cell and displays its content left-aligned in normal weight. <th> is a header cell: the browser automatically shows its text bold and centred, and it tells assistive technology that the cell labels a column or row. <th> is normally used in the first row of a table.

2 marks Differentiate between cellpadding and cellspacing.

cellpadding is the space between the content of a cell and that cell's own border — it makes the text sit further inside the box. cellspacing is the gap between one cell's border and the next cell's border — it widens the grid lines themselves. Both are set on the <table> tag.

1 marks What does <caption> do in a table?

<caption> gives the table a title. It is placed immediately after the opening <table> tag and is displayed above the table by default.

✍️ Hands-on task

Draw a 4×4 timetable on paper with one merged title row and one merged subject column. Now write it in HTML without looking at notes. Compare with your drawing — if they match, this chapter is done.
