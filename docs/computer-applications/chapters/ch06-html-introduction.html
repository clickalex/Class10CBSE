🎯 Marks lens

Write a complete HTML page by hand; give the purpose of a tag; predict the output of a snippet.
Hand-written code is the whole skill — you cannot click your way through the exam.

📖 Deep concepts

1. What HTML is. HTML stands for HyperText Markup Language. It is not a programming language — it has no variables, conditions or loops. It is a markup language: you surround content with tags that describe what the content is, and the browser decides how to display it. HTML files are saved with a .html or .htm extension and are plain text.
2. Tags, elements and attributes. A tag is written in angle brackets — <p>. Most tags come in pairs: an opening <p> and a closing </p> with a slash. The opening tag, the content and the closing tag together form an element. An attribute adds information inside the opening tag — <p align='center'>. Some tags have no closing partner at all; these are called empty or void tags, for example <br>, <hr> and <img>.
3. The document skeleton. Every page has the same five-part shape: <html> wraps everything, <head> holds information about the page, <title> names the tab, <body> holds everything the visitor actually sees, and </html> closes the file. <title> goes inside <head>, never inside <body> — this is one of the most common exam traps.
4. The basic body tags. <h1> to <h6> are headings, with <h1> largest and <h6> smallest. <p> is a paragraph and adds spacing automatically. <br> forces a line break without starting a new paragraph. <hr> draws a horizontal rule across the page. <!-- ... --> is a comment, invisible in the browser, used to leave notes in the code.

🧮 Formulas to memorise

  • The skeleton to memorise
  • <html>
  • <head>
  • <title>My Page</title>

🛠️ Method, step by step

1. Write <html> and </html> first — the outer wrapper.
2. Inside it write <head> and </head>, and put <title> inside that.
3. Write <body> and </body> below the head.
4. Put every visible element inside <body>.
5. Close tags in the reverse order you opened them — last opened, first closed.
6. Save as index.html and open it in a browser to check.

🧠 Memory tricks

  • <title> lives in <head>, not <body>. This single fact is worth a mark in most papers.
  • Empty tags have no partner: <br>, <hr>, <img>, <input>.
  • Headings run 1 to 6, biggest to smallest. H1 is the largest, not the smallest.
  • Last opened, first closed. Nesting is the one thing browsers punish visibly.

⚠️ Mistakes that cost marks

  • Putting <title> inside <body>.
  • Writing </br> or </hr> — these tags are empty and take no closing partner.
  • Thinking <h6> is the largest heading — it is the smallest.
  • Forgetting the closing slash: <p>text<p> instead of <p>text</p>.
  • Claiming HTML is a programming language — it is a markup language.

❓ Exam Q&A

3 marks Write an HTML page that displays the heading 'My School' and a paragraph about it.

<html>
<head>
<title>My School</title>
</head>
<body>
<h1>My School</h1>
<p>My school is located in the centre of the city and has a large playground, a library and a computer laboratory.</p>
</body>
</html>
The <title> sits inside <head> and names the browser tab; everything visible is inside <body>.

2 marks What is the difference between a tag and an element?

A tag is the marker itself, written in angle brackets — for example <p> or </p>. An element is the complete unit made of the opening tag, the content and the closing tag — <p>This is a paragraph.</p>. So tags are the parts and the element is the whole thing they enclose.

2 marks What are empty tags? Give two examples.

Empty tags, also called void tags, are tags that carry no content and therefore have no closing partner. They do their work on their own. Two examples are <br>, which inserts a line break, and <hr>, which draws a horizontal rule. <img> and <input> are other common empty tags.

2 marks What is the purpose of the <head> section?

The <head> section holds information about the page rather than content shown on it. It contains the <title>, which appears on the browser tab and in search results, and can hold links to stylesheets, scripts and metadata. None of what is inside <head> is displayed in the page body.

1 marks What is the difference between <br> and <p>?

<br> inserts a single line break inside existing text without any spacing, while <p> starts a new paragraph, which the browser surrounds with vertical space before and after.

✍️ Hands-on task

Write the full skeleton from memory, without looking. Then add three headings and two paragraphs. Open it in a browser. Do this every day for a week and Unit II stops being scary.
