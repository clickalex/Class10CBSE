🎯 Marks lens

Write a working link or image tag; explain the difference between absolute and relative paths.
href versus src is the classic confusion.

📖 Deep concepts

1. The anchor tag. <a href='destination'>text</a> creates a hyperlink. href (hypertext reference) holds the address of the destination. The destination can be another page on the same site, a page on another site, an email address using mailto:, or a place further down the same page.
2. Absolute versus relative paths. An absolute address gives the complete location starting with the protocol — https://clickalex.github.io/IT-402-/index.html — and works from anywhere. A relative address is measured from the current file: chapters/ch01.html looks inside a subfolder, and ../index.html goes up one folder first. The .. is the part students forget.
3. Anchors within a page. Give an element an id, then link to it with a hash: <a href='#top'>Back to top</a> jumps to <h1 id='top'>. target='_blank' opens the link in a new tab; the default opens it in the same tab.
4. The image tag. <img> is an empty tag — it has no closing partner. src gives the image file's location and is compulsory. alt supplies text shown when the image cannot load, and read aloud by screen readers. width and height set the display size in pixels or as a percentage. align positions the image relative to surrounding text. border draws a frame around it.

🛠️ Method, step by step

1. Decide the destination: same folder, subfolder, parent folder, or another website?
2. For another website, write the full address including https://.
3. For a subfolder, write folder/file.html. For the parent folder, start with ../.
4. Put the visible link text between <a> and </a>.
5. For images write <img src='...' alt='...'> — never a closing tag.
6. Always include alt; it is both good practice and sometimes asked for directly.

🧠 Memory tricks

  • href for links, src for sources. <a href>, <img src>, <script src>.
  • .. means go up one folder. ../index.html is the one students miss.
  • <img> is empty — no </img>.
  • target='_blank' = new tab.
  • mailto: opens the mail program, not a web page.

⚠️ Mistakes that cost marks

  • Writing <img href=...> instead of <img src=...>.
  • Writing </img> — the tag is empty.
  • Forgetting ../ when linking to a file in the parent folder.
  • Using a relative path for a page on another website — it will not work.
  • Omitting alt text.

❓ Exam Q&A

3 marks Write HTML to create a link to the CBSE website that opens in a new tab, and a link that emails the principal.

<a href='https://www.cbse.gov.in' target='_blank'>Visit CBSE</a>
<br>
<a href='mailto:principal@school.edu'>Email the Principal</a>
The first uses an absolute URL and target='_blank' so it opens in a new tab. The second uses the mailto: prefix, which makes the browser open the user's email program with the address already filled in.

3 marks Explain the <img> tag with any four of its attributes.

The <img> tag inserts an image into a page and is an empty tag, so it has no closing partner. src gives the location of the image file and is compulsory — without it nothing displays. alt provides alternative text shown when the image fails to load and read by screen readers. width and height set the displayed size in pixels or as a percentage of the container. align controls how the image sits beside surrounding text, and border draws a frame around it. An example is <img src='logo.png' alt='School logo' width='200' height='100'>.

2 marks What is the difference between an absolute and a relative path?

An absolute path gives the complete address of a resource starting from the protocol, such as https://example.com/images/logo.png. It works from anywhere on the internet. A relative path is written relative to the location of the current file, such as images/logo.png for a subfolder or ../index.html to go up one level first. Relative paths are shorter and keep working if the whole site is moved, but they only work within the same site.

2 marks How do you create a link that jumps to the top of the same page?

First give the target element an id — for example <h1 id='top'>Title</h1>. Then link to it using a hash followed by that id: <a href='#top'>Back to top</a>. Clicking the link scrolls the page to the element carrying that id, without loading anything new.

1 marks What does the alt attribute do?

The alt attribute supplies alternative text for an image. It is displayed when the image cannot be loaded and is read aloud by screen readers for visually impaired users, which is why it should always be included.

✍️ Hands-on task

Build two pages in the same folder that link to each other, plus one image on each with alt text. Then add a 'back to top' link on the longer page. That is the whole chapter.
