Chapter 10 · HTML Forms

Chapter 10 of 13. Forms are the second big written question in Unit II. Learn the input types as a list.

Open this chapter’s questions + MCQs →

🎯 Marks lens 📖 Deep concepts 🧮 Formulas 🛠️ Steps 🧠 Tricks ⚠️ Mistakes ❓ Exam Q&A ✍️ Task

🎯 Marks lens

Write a complete form; name the input type for a given control; explain method and action.
The type attribute values are pure recall.

📖 Deep concepts

1. The form tag. <form> wraps every control. Its two important attributes are action, the URL that receives the data, and method, which is either get or post. GET appends the data to the URL as a query string, so it is visible, short and can be bookmarked — suitable for searches. POST sends the data in the body of the request, so it is not shown in the address bar and has no practical size limit — used for logins and form submissions.
2. The input types. <input> is an empty tag; what it becomes depends entirely on its type attribute. text is a single-line box. password hides what is typed. radio gives a set of choices where only one may be picked — all radios in a group must share the same name. checkbox gives choices where several may be picked. submit sends the form, reset clears it, and button does nothing by itself. file opens a file picker, hidden carries data the user cannot see, and image uses a picture as the submit button. HTML5 added email, number, date, color and range.
3. Input attributes. name identifies the field when the data is sent — a control without a name is not submitted at all. value is the initial content or the button's label. size sets the visible width in characters, maxlength caps how much may be typed, and checked pre-selects a radio button or checkbox.
4. Other controls. <textarea rows='4' cols='30'> is a multi-line box — note it is a paired tag, unlike <input>. <select> with <option> children makes a drop-down list; adding multiple turns it into a list box where several items can be chosen. <button> is a clickable button that can contain formatted text, whereas <input type='button'> shows only a plain label.

🧮 Formulas to memorise

  • Form shell: <form action="submit.php" method="post"> … </form>
  • Input types: text password radio checkbox submit reset file hidden
  • <textarea rows="4" cols="40"> for long text; <select><option> for a drop-down
  • Every field that is submitted needs a name; value is what travels, placeholder is only a hint
  • method="get" puts data in the URL (short, visible); method="post" sends it in the body

🛠️ Method, step by step

1. Write <form action='...' method='post'> and </form>.
2. For each field write a <label> or plain text, then the control.
3. Give every control a name — without it the data is never sent.
4. Choose the right type: text, password, radio, checkbox, file, hidden.
5. For radio buttons, give every option in the group the same name and different values.
6. End with <input type='submit' value='Send'> and <input type='reset' value='Clear'>.
7. Close the form.

🧠 Memory tricks

  • Radios share a name; checkboxes do not. That one rule separates the two.
  • <textarea> is paired, <input> is empty.
  • No name, no submission. A nameless control is invisible to the server.
  • GET shows data in the URL, POST hides it in the body.
  • checked pre-selects a radio or checkbox.

⚠️ Mistakes that cost marks

  • Giving radio buttons in the same group different names — then several can be selected at once, which defeats the purpose.
  • Forgetting the name attribute on fields.
  • Writing </input> — the tag is empty.
  • Using <input type='textarea'> — a text area is its own paired tag, <textarea>.
  • Confusing size (visible width) with maxlength (how much may be typed).

SHORTS12 marks

1. What is the difference between radio buttons and checkboxes?

Show Answer

Ans:

Radio buttons allow the user to choose only one option from a group, and all buttons in that group must share the same name attribute. Checkboxes allow any number of options to be selected at once, including none or all. Visually, radios are round and checkboxes are square.

SHORTS22 marks

2. Why is the name attribute important in a form?

Show Answer

Ans:

The name attribute is the identifier used for a field when the form data is sent to the server — the server reads name=value pairs. If a control has no name, it is not submitted at all, even if the user filled it in. Radio buttons additionally rely on a shared name to behave as a single group.

SHORTS32 marks

3. Write the HTML for a drop-down list of three subjects with Science pre-selected.

Show Answer

Ans:

<select name='subject'>
<option>Mathematics</option>
<option selected>Science</option>
<option>Social Science</option>
</select>
<select> is a paired tag containing <option> children. The selected attribute on the Science option makes it the default choice shown when the page loads.

SHORTS42 marks

4. What do the action and method attributes of the <form> tag do?

Show Answer

Ans:

action gives the URL of the page or program that will receive and process the data, for example action="save.php". method says how the data is sent: GET appends it to the URL, which is fine for short, public searches, and POST sends it in the body of the request, which is needed for passwords, long text and file uploads.

SHORTS53 marks

5. What is the difference between the GET and POST methods?

Show Answer

Ans:

GET appends the form data to the URL as a query string, such as search.html?q=physics. The data is visible in the address bar, is limited in length, and can be bookmarked or shared — which makes GET suitable for searches. POST places the data in the body of the HTTP request, so it does not appear in the URL, has no practical size limit, and can carry files. POST is therefore used for logins, registrations and any form carrying sensitive or large data.

SHORTS83 marks

8. Write the HTML for a form with a text box for a name, two radio buttons for gender, a checkbox for a hobby and a submit button.

Show Answer

Ans:

Open the form with <form action="save.php" method="post">.
Name: <input type="text" name="name"> and then <br> for a new line.
Gender: <input type="radio" name="gender" value="f"> Female and <input type="radio" name="gender" value="m"> Male; radio buttons with the same name allow only one choice.
Hobby: <input type="checkbox" name="hobby" value="music"> Music, then <input type="submit" value="Send"> and close with </form>.
