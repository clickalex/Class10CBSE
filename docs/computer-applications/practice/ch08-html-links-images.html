MCQs · Drill

MCQM11 mark

1. Which attribute of <a> gives the destination address? (a) src (b) href (c) link (d) target

Show Answer

Ans:

(b) href.

MCQM21 mark

2. Which opens a link in a new tab? (a) target='_new' (b) target='_blank' (c) new='true' (d) href='_blank'

Show Answer

Ans:

(b) target='_blank'.

MCQM31 mark

3. <img> is — (a) a paired tag (b) an empty tag (c) a heading tag (d) not a valid tag

Show Answer

Ans:

(b) an empty tag — it has no closing partner.

MCQM41 mark

4. To link to a file in the parent folder you write — (a) /index.html (b) ./index.html (c) ../index.html (d) index.html

Show Answer

Ans:

(c) ../index.html.

MCQM51 mark

5. mailto: is used to — (a) download mail (b) open the email program (c) create a table (d) send an image

Show Answer

Ans:

(b) open the email program with the address filled in.

MCQM61 mark

6. The attribute of the <a> tag that holds the destination address is: (a) href (b) src (c) link (d) target

Show Answer

Ans:

(a) href. The target attribute only decides where the page opens.

MCQM71 mark

7. The attribute of <img> that shows text if the picture cannot be displayed is: (a) alt (b) src (c) title (d) name

Show Answer

Ans:

(a) alt. It is also read aloud by screen readers for blind users.

MCQM81 mark

8. An in-page link to a section with id='top' is written as: (a) <a href='#top'> (b) <a src='top'> (c) <a link='top'> (d) <a href='top.html'>

Show Answer

Ans:

(a) <a href='#top'>. The #id form jumps within the page; the target carries the matching id.

Written questions · Write

SHORTS11 mark

1. What does the alt attribute do?

Show Answer

Ans:

The alt attribute supplies alternative text for an image. It is displayed when the image cannot be loaded and is read aloud by screen readers for visually impaired users, which is why it should always be included.

SHORTS22 marks

2. What is the difference between an absolute and a relative path?

Show Answer

Ans:

An absolute path gives the complete address of a resource starting from the protocol, such as https://example.com/images/logo.png. It works from anywhere on the internet. A relative path is written relative to the location of the current file, such as images/logo.png for a subfolder or ../index.html to go up one level first. Relative paths are shorter and keep working if the whole site is moved, but they only work within the same site.

SHORTS32 marks

3. How do you create a link that jumps to the top of the same page?

Show Answer

Ans:

First give the target element an id — for example <h1 id='top'>Title</h1>. Then link to it using a hash followed by that id: <a href='#top'>Back to top</a>. Clicking the link scrolls the page to the element carrying that id, without loading anything new.

SHORTS42 marks

4. What is the difference between an absolute and a relative URL in a link?

Show Answer

Ans:

An absolute URL gives the complete address, such as https://www.example.com/notes/unit1.html, and works no matter where the linking page is stored. A relative URL gives the path from the page you are on, such as notes/unit1.html or ../images/logo.png, and stops working if the folder structure changes.

SHORTS53 marks

5. Write HTML to create a link to the CBSE website that opens in a new tab, and a link that emails the principal.

Show Answer

Ans:

<a href='https://www.cbse.gov.in' target='_blank'>Visit CBSE</a>
<br>
<a href='mailto:principal@school.edu'>Email the Principal</a>
The first uses an absolute URL and target='_blank' so it opens in a new tab. The second uses the mailto: prefix, which makes the browser open the user's email program with the address already filled in.

SHORTS63 marks

6. Explain the <img> tag with any four of its attributes.

Show Answer

Ans:

The <img> tag inserts an image into a page and is an empty tag, so it has no closing partner. src gives the location of the image file and is compulsory — without it nothing displays. alt provides alternative text shown when the image fails to load and read by screen readers. width and height set the displayed size in pixels or as a percentage of the container. align controls how the image sits beside surrounding text, and border draws a frame around it. An example is <img src='logo.png' alt='School logo' width='200' height='100'>.

APPLICATIONA73 marks

7. Riya is revising “HTML III — Links & Images” (The <a> tag, href, anchors, and the <img> tag with its attributes.). A classmate lost marks by doing this: Writing <img href=...> instead of <img src=...>. Apply the correct method and rewrite the scoring answer.

Show Answer

Ans:

Correct method: href for links, src for sources. <a href>, <img src>, <script src>.
Why the mistake costs marks: Writing <img href=...> instead of <img src=...>.
Write the definition or formula first, then the working or example.

APPLICATIONA83 marks

8. Amit is given this exam-style task from “HTML III — Links & Images”: “Write HTML to create a link to the CBSE website that opens in a new tab, and a link that emails the principal.” Treat it as an application question. Identify the idea, then write the working in points.

Show Answer

Ans:

Idea: The <a> tag, href, anchors, and the <img> tag with its attributes..
<a href='https://www.cbse.gov.in' target='_blank'>Visit CBSE</a> <br> <a href='mailto:principal@school.edu'>Email the Principal</a> The first uses an absolute URL and target='_blank' so it opens in a new tab. The second uses the mailto: prefix, which makes the browser open the user's email program with the address already filled in.

SHORTS93 marks

9. Write HTML to display the image logo.png at 200 by 100 pixels and make it a link to home.html.

Show Answer

Ans:

Put the image inside the anchor: <a href='home.html'>, then the image tag, then </a>.
The image tag is <img src="logo.png" width="200" height="100" alt="School logo">.
The src attribute gives the file, width and height set the size in pixels, and alt gives the text shown if the image cannot load or is read aloud.
Because the <img> tag sits inside the <a> tag, clicking the picture opens the page named in href.

LONGL125 marks

12. Discuss “HTML III — Links & Images” in detail. Include the idea that carries marks, one worked example or answer frame, and why students lose marks.

Show Answer

Ans:

The anchor tag. <a href='destination'>text</a> creates a hyperlink. href (hypertext reference) holds the address of the destination. The destination can be another page on the same site, a page on another site, an email address using mailto:, or a place further down the same page.
Marks lens: Write a working link or image tag; explain the difference between absolute and relative paths.

Do not: Writing <img href=...> instead of <img src=...>.
