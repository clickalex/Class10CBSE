Written questions · Write

SHORTS13 marks

1. Write HTML to create a link to the CBSE website that opens in a new tab, and a link that emails the principal.

Show Answer

Ans:

<a href='https://www.cbse.gov.in' target='_blank'>Visit CBSE</a>
<br>
<a href='mailto:principal@school.edu'>Email the Principal</a>
The first uses an absolute URL and target='_blank' so it opens in a new tab. The second uses the mailto: prefix, which makes the browser open the user's email program with the address already filled in.

SHORTS23 marks

2. Explain the <img> tag with any four of its attributes.

Show Answer

Ans:

The <img> tag inserts an image into a page and is an empty tag, so it has no closing partner. src gives the location of the image file and is compulsory — without it nothing displays. alt provides alternative text shown when the image fails to load and read by screen readers. width and height set the displayed size in pixels or as a percentage of the container. align controls how the image sits beside surrounding text, and border draws a frame around it. An example is <img src='logo.png' alt='School logo' width='200' height='100'>.

SHORTS32 marks

3. What is the difference between an absolute and a relative path?

Show Answer

Ans:

An absolute path gives the complete address of a resource starting from the protocol, such as https://example.com/images/logo.png. It works from anywhere on the internet. A relative path is written relative to the location of the current file, such as images/logo.png for a subfolder or ../index.html to go up one level first. Relative paths are shorter and keep working if the whole site is moved, but they only work within the same site.

SHORTS42 marks

4. How do you create a link that jumps to the top of the same page?

Show Answer

Ans:

First give the target element an id — for example <h1 id='top'>Title</h1>. Then link to it using a hash followed by that id: <a href='#top'>Back to top</a>. Clicking the link scrolls the page to the element carrying that id, without loading anything new.

SHORTS51 mark

5. What does the alt attribute do?

Show Answer

Ans:

The alt attribute supplies alternative text for an image. It is displayed when the image cannot be loaded and is read aloud by screen readers for visually impaired users, which is why it should always be included.

LONGL65 marks

6. Discuss “HTML III — Links & Images” in detail. Include the idea that carries marks, one worked example or answer frame, and why students lose marks.

Show Answer

Ans:

The anchor tag. <a href='destination'>text</a> creates a hyperlink. href (hypertext reference) holds the address of the destination. The destination can be another page on the same site, a page on another site, an email address using mailto:, or a place further down the same page.
Marks lens: Write a working link or image tag; explain the difference between absolute and relative paths.
Method / memory trick: href for links, src for sources. <a href>, <img src>, <script src>.
Do not: Writing <img href=...> instead of <img src=...>.
