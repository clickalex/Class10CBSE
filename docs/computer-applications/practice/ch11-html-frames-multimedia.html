Written questions · Write

SHORTS13 marks

1. Write HTML to divide the browser window into two rows, the top 25% showing a header and the bottom 75% showing content.

Show Answer

Ans:

<html>
<head><title>Frames</title></head>
<frameset rows='25%,75%'>
<frame src='header.html'>
<frame src='content.html'>
</frameset>
</html>
Note that there is no <body> — a <frameset> document replaces it. rows splits the window into horizontal bands, and each <frame> loads one document into its band.

SHORTS23 marks

2. Explain the <audio> tag with its attributes.

Show Answer

Ans:

The <audio> tag embeds a sound file in a page. src gives the location of the audio file. controls displays the play, pause and volume buttons — without it the player is invisible and the user cannot control playback. autoplay starts the sound as soon as the page loads, loop repeats it endlessly, and muted starts it silently. An example is <audio src='song.mp3' controls loop>.

SHORTS32 marks

3. What is the difference between <frame> and <iframe>?

Show Answer

Ans:

A <frame> can only be used inside a <frameset>, which replaces the document's <body> and splits the entire browser window into separate regions. An <iframe> (inline frame) is placed inside an ordinary page and embeds another document in a rectangular area within it, leaving the rest of the page untouched. In practice iframes are still common for maps and embedded videos, while framesets are considered outdated.

SHORTS42 marks

4. What does the <marquee> tag do? Name two of its attributes.

Show Answer

Ans:

The <marquee> tag makes its content scroll across the page. Two of its attributes are direction, which sets the direction of movement — left, right, up or down — and scrollamount, which sets how fast it moves. A third, behavior, chooses between scroll (continuous), slide (moves once and stops) and alternate (bounces back and forth).

SHORTS52 marks

5. Why is the <pre> tag used?

Show Answer

Ans:

The <pre> tag displays text exactly as it is typed, preserving all spaces, tabs and line breaks. Ordinary HTML collapses multiple spaces into one and ignores line breaks, so <pre> is used whenever the formatting itself matters — for code samples, ASCII diagrams or poetry.

LONGL65 marks

6. Discuss “Frames, Multimedia & Special Tags” in detail. Include the idea that carries marks, one worked example or answer frame, and why students lose marks.

Show Answer

Ans:

Frames. A frame divides the browser window into separate regions, each showing a different HTML document. Frames are declared in a <frameset> document, which replaces <body> entirely. rows='30%,70%' splits the window horizontally into stacked bands; cols='25%,75%' splits it vertically into side-by-side columns. Each region is then filled by a <frame src='file.html'>. The name attribute on a frame lets a link in one f.
Marks lens: Explain what a frame does; write an audio or video tag; give the purpose of a special tag.
Method / memory trick: rows = horizontal bands, cols = vertical columns. Picture the lines you are drawing.
Do not: Writing a <body> in a frameset document — <frameset> replaces it.

SHORTS112 marks

11. What is the difference between a frameset and an iframe?

Show Answer

Ans:

A frameset divides the window into two or more independent frames using <frameset> and <frame>, and it replaces the <body> tag entirely; it has been removed from HTML5. An iframe puts a small separate window inside an ordinary page with <iframe src="...">, keeps the rest of the page intact, and is still supported, so it is the way to embed another document today.

SHORTS123 marks

12. Write HTML to embed a video with the browser's own controls, and name two related tags from this chapter.

Show Answer

Ans:

<video src="lesson.mp4" width="320" height="240" controls></video> embeds the video with play, pause and volume controls.
<audio src="song.mp3" controls></audio> does the same for sound.
For older browsers you can list several <source> tags inside <video> so that the browser picks a format it can play.
<marquee> scrolls text across the page, but it is not part of HTML5 and should be avoided in new pages.
