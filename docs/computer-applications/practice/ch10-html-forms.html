MCQs · Drill

MCQM11 mark

1. Which input type hides the characters typed? (a) password (b) text (c) hidden (d) secure

Show Answer

Ans:

(a) password.

MCQM21 mark

2. Radio buttons in one group must share the same — (a) value (b) id (c) size (d) name

Show Answer

Ans:

(d) name.

MCQM31 mark

3. Which method sends data in the request body? (a) GET (b) SEND (c) PUT (d) POST

Show Answer

Ans:

(d) POST.

MCQM41 mark

4. Which of these is a paired tag? (a) <input> (b) <textarea> (c) <img> (d) <br>

Show Answer

Ans:

(b) <textarea>.

MCQM51 mark

5. To pre-select a radio button you use the attribute — (a) checked (b) selected (c) default (d) value

Show Answer

Ans:

(a) checked. selected is used on <option>.

MCQM61 mark

6. The input type that hides the characters as they are typed is: (a) text (b) password (c) hidden (d) email

Show Answer

Ans:

(b) password. It masks the characters but does not encrypt them, so the form should still use POST.

MCQM71 mark

7. The tag that creates a box for several lines of text is: (a) <input type="text"> (b) <select> (c) <textarea> (d) <option>

Show Answer

Ans:

(c) <textarea>. rows and columns are set with the rows and cols attributes.

MCQM81 mark

8. In <select>, the option shown by default is marked with: (a) checked (b) default (c) selected (d) value

Show Answer

Ans:

(c) selected. checked is the equivalent for radio buttons and checkboxes.

Written questions · Write

SHORTS12 marks

1. What is the difference between radio buttons and checkboxes?

Show Answer

Ans:

Radio buttons allow the user to choose only one option from a group, and all buttons in that group must share the same name attribute. Checkboxes allow any number of options to be selected at once, including none or all. Visually, radios are round and checkboxes are square.

SHORTS22 marks

2. Why is the name attribute important in a form?

Show Answer

Ans:

The name attribute is the identifier used for a field when the form data is sent to the server — the server reads name=value pairs. If a control has no name, it is not submitted at all, even if the user filled it in. Radio buttons additionally rely on a shared name to behave as a single group.

SHORTS32 marks

3. Write the HTML for a drop-down list of three subjects with Science pre-selected.

Show Answer

Ans:

<select name='subject'>
<option>Mathematics</option>
<option selected>Science</option>
<option>Social Science</option>
</select>
<select> is a paired tag containing <option> children. The selected attribute on the Science option makes it the default choice shown when the page loads.

SHORTS42 marks

4. What do the action and method attributes of the <form> tag do?

Show Answer

Ans:

action gives the URL of the page or program that will receive and process the data, for example action="save.php". method says how the data is sent: GET appends it to the URL, which is fine for short, public searches, and POST sends it in the body of the request, which is needed for passwords, long text and file uploads.

SHORTS53 marks

5. What is the difference between the GET and POST methods?

Show Answer

Ans:

GET appends the form data to the URL as a query string, such as search.html?q=physics. The data is visible in the address bar, is limited in length, and can be bookmarked or shared — which makes GET suitable for searches. POST places the data in the body of the HTTP request, so it does not appear in the URL, has no practical size limit, and can carry files. POST is therefore used for logins, registrations and any form carrying sensitive or large data.

APPLICATIONA63 marks

6. A student gives three radio buttons for “Class” the names c1, c2 and c3, and finds that two of them can be selected together. What is the error, and how is it fixed?

Show Answer

Ans:

Radio buttons are meant to be mutually exclusive only when they belong to the same group, and a group is formed by a shared name.
With different names, each button is its own group, so several can be selected.
Fix: <input type='radio' name='class' value='X'> for every button, changing only the value.

APPLICATIONA73 marks

7. Write the HTML for a login form with a user-name box, a password box and a Submit button that sends the data by POST to login.php.

Show Answer

Ans:

<form action='login.php' method='post'>
User name: <input type='text' name='user'>
Password: <input type='password' name='pass'>
<input type='submit' value='Submit'>
</form>
type='password' hides the characters typed, and method='post' sends the data in the request body, not in the address bar.

SHORTS83 marks

8. Write the HTML for a form with a text box for a name, two radio buttons for gender, a checkbox for a hobby and a submit button.

Show Answer

Ans:

Open the form with <form action="save.php" method="post">.
Name: <input type="text" name="name"> and then <br> for a new line.
Gender: <input type="radio" name="gender" value="f"> Female and <input type="radio" name="gender" value="m"> Male; radio buttons with the same name allow only one choice.
Hobby: <input type="checkbox" name="hobby" value="music"> Music, then <input type="submit" value="Send"> and close with </form>.

LONGL94 marks

9. Write an HTML form with a name field, a password field, two radio buttons for gender, a hobbies checkbox group, and submit and reset buttons.

Show Answer

Ans:

<form action='/submit' method='post'>
Name: <input type='text' name='uname'><br>
Password: <input type='password' name='upass'><br>
Gender:
<input type='radio' name='gender' value='male'> Male
<input type='radio' name='gender' value='female'> Female<br>
Hobbies:
<input type='checkbox' name='hobby' value='reading'> Reading
<input type='checkbox' name='hobby' value='music'> Music<br>
<input type='submit' value='Send'>
<input type='reset' value='Clear'>
</form>
Both radio buttons share the name gender, so only one can be chosen; the two checkboxes are independent, so both can be ticked.

COMPETENCYC104 marks

10. Read and answer: A student wrote this form, but the server receives nothing for the text box. <form action='save.php' method='get'> <input type='text'> <input type='submit' value='Send'> </form> (a) Why is nothing received? (b) Correct the text box. (c) Why is GET unsuitable for passwords?

Show Answer

Ans:

(a) The text box has no name attribute, so its value is not sent.
(b) <input type='text' name='username'>
(c) GET appends the data to the address, where it is visible in the address bar and the history; POST sends it in the body of the request.

COMPETENCYC114 marks

11. Read and answer: A feedback form needs a box for comments of several lines, a drop-down list of classes IX, X and XI (with X pre-selected) and a checkbox “Subscribe”. (a) Which tag gives the comments box? (b) Write the drop-down list. (c) Write the checkbox.

Show Answer

Ans:

(a) <textarea name='comments' rows='4' cols='30'></textarea>
(b) <select name='class'>
<option>IX</option>
<option selected>X</option>
<option>XI</option>
</select>
(c) <input type='checkbox' name='subscribe' value='yes'> Subscribe

LONGL125 marks

12. Explain any five values of the type attribute of the <input> tag, with one use of each.

Show Answer

Ans:

text: a single-line box, for a name.
password: hides the characters typed, for a password.
radio: one choice from a group that shares a name, for gender.
checkbox: any number of choices can be ticked, for hobbies.
submit sends the form to the server and reset clears all the fields to their starting values.
