Written questions · Write

SHORTS13 marks

1. Write an HTML page that displays the heading 'My School' and a paragraph about it.

Show Answer

Ans:

<html>
<head>
<title>My School</title>
</head>
<body>
<h1>My School</h1>
<p>My school is located in the centre of the city and has a large playground, a library and a computer laboratory.</p>
</body>
</html>
The <title> sits inside <head> and names the browser tab; everything visible is inside <body>.

SHORTS22 marks

2. What is the difference between a tag and an element?

Show Answer

Ans:

A tag is the marker itself, written in angle brackets — for example <p> or </p>. An element is the complete unit made of the opening tag, the content and the closing tag — <p>This is a paragraph.</p>. So tags are the parts and the element is the whole thing they enclose.

SHORTS32 marks

3. What are empty tags? Give two examples.

Show Answer

Ans:

Empty tags, also called void tags, are tags that carry no content and therefore have no closing partner. They do their work on their own. Two examples are <br>, which inserts a line break, and <hr>, which draws a horizontal rule. <img> and <input> are other common empty tags.

SHORTS42 marks

4. What is the purpose of the <head> section?

Show Answer

Ans:

The <head> section holds information about the page rather than content shown on it. It contains the <title>, which appears on the browser tab and in search results, and can hold links to stylesheets, scripts and metadata. None of what is inside <head> is displayed in the page body.

SHORTS51 mark

5. What is the difference between <br> and <p>?

Show Answer

Ans:

<br> inserts a single line break inside existing text without any spacing, while <p> starts a new paragraph, which the browser surrounds with vertical space before and after.

LONGL65 marks

6. Discuss “HTML I — Introduction & Basic Tags” in detail. Include the idea that carries marks, one worked example or answer frame, and why students lose marks.

Show Answer

Ans:

What HTML is. HTML stands for HyperText Markup Language. It is not a programming language — it has no variables, conditions or loops. It is a markup language: you surround content with tags that describe what the content is, and the browser decides how to display it. HTML files are saved with a .html or .htm extension and are plain text.
Marks lens: Write a complete HTML page by hand; give the purpose of a tag; predict the output of a snippet.
Method / memory trick: <title> lives in <head>, not <body>. This single fact is worth a mark in most papers.
Do not: Putting <title> inside <body>.
