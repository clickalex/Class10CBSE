MCQs · Drill

MCQM11 mark

1. HTML stands for — (a) HighText Machine Language (b) HyperText Markup Language (c) HyperTool Markup Language (d) Home Tool Markup Language

Show Answer

Ans:

(b) HyperText Markup Language.

MCQM21 mark

2. Which tag goes inside <head>? (a) <body> (b) <h1> (c) <title> (d) <p>

Show Answer

Ans:

(c) <title>.

MCQM31 mark

3. The smallest heading tag is — (a) <h1> (b) <h3> (c) <h6> (d) <head>

Show Answer

Ans:

(c) <h6>.

MCQM41 mark

4. Which of these is an empty tag? (a) <p> (b) <br> (c) <h1> (d) <title>

Show Answer

Ans:

(b) <br> — it has no closing partner.

MCQM51 mark

5. In an HTML document, the visible content of the page is placed inside the: (a) <head> tag (b) <body> tag (c) <title> tag (d) <html> tag only, outside every other tag

Show Answer

Ans:

(b) <body> tag. <body> holds everything the browser displays; <head> holds information such as the title.

MCQM61 mark

6. The correct way to write a line break in HTML is: (a) </br> (b) <br> (c) <lb> (d) <break>

Show Answer

Ans:

(b) <br>. <br> is an empty tag, so it has no closing form.

MCQM71 mark

7. The tag that sets the text shown in the browser's title bar is: (a) <title> (b) <head> (c) <h1> (d) <body>

Show Answer

Ans:

(a) <title>. It is placed inside the <head> section.

MCQM81 mark

8. The tag used for the most important heading is: (a) <h1> (b) <h6> (c) <p> (d) <b>

Show Answer

Ans:

(a) <h1>. Headings run from <h1>, the largest, down to <h6>, the smallest.

Written questions · Write

SHORTS11 mark

1. What is the difference between <br> and <p>?

Show Answer

Ans:

<br> inserts a single line break inside existing text without any spacing, while <p> starts a new paragraph, which the browser surrounds with vertical space before and after.

SHORTS22 marks

2. What is the difference between a tag and an element?

Show Answer

Ans:

A tag is the marker itself, written in angle brackets — for example <p> or </p>. An element is the complete unit made of the opening tag, the content and the closing tag — <p>This is a paragraph.</p>. So tags are the parts and the element is the whole thing they enclose.

SHORTS32 marks

3. What are empty tags? Give two examples.

Show Answer

Ans:

Empty tags, also called void tags, are tags that carry no content and therefore have no closing partner. They do their work on their own. Two examples are <br>, which inserts a line break, and <hr>, which draws a horizontal rule. <img> and <input> are other common empty tags.

SHORTS42 marks

4. What is the purpose of the <head> section?

Show Answer

Ans:

The <head> section holds information about the page rather than content shown on it. It contains the <title>, which appears on the browser tab and in search results, and can hold links to stylesheets, scripts and metadata. None of what is inside <head> is displayed in the page body.

SHORTS52 marks

5. What is HTML and what is the basic structure of an HTML document?

Show Answer

Ans:

HTML is the markup language in which web pages are written, using tags to describe the structure and meaning of the content. A document starts with <!DOCTYPE html>, then an <html> element containing a <head> with the <title>, and a <body> with everything the visitor sees.

SHORTS63 marks

6. Write an HTML page that displays the heading 'My School' and a paragraph about it.

Show Answer

Ans:

<html>
<head>
<title>My School</title>
</head>
<body>
<h1>My School</h1>
<p>My school is located in the centre of the city and has a large playground, a library and a computer laboratory.</p>
</body>
</html>
The <title> sits inside <head> and names the browser tab; everything visible is inside <body>.

APPLICATIONA73 marks

7. A student says that <h6> makes the largest heading and <h1> the smallest. Correct this and write the tags for the main heading and the smallest heading of a page.

Show Answer

Ans:

It is the other way round: <h1> is the largest (most important) heading and <h6> the smallest.
Main heading: <h1>Welcome to Class 10</h1>
Smallest heading: <h6>Last updated today</h6>

APPLICATIONA83 marks

8. Write the HTML for a page body that shows the main heading “Our Class”, a sub-heading “Roll Call”, the paragraph “Attendance is taken daily.” and then a horizontal line.

Show Answer

Ans:

<h1>Our Class</h1>
<h2>Roll Call</h2>
<p>Attendance is taken daily.</p>
<hr>
<h1> and <h2> are paired heading tags; <hr> is an empty tag, so it has no closing partner.

SHORTS93 marks

9. Write the HTML for a page titled ‘My School' with one heading and one paragraph.

Show Answer

Ans:

Start with <!DOCTYPE html> so that the browser knows this is HTML5.
<html> wraps the whole document, <head> holds <title>My School</title>.
<body> holds <h1>My School</h1> for the main heading and <p>My school has thirty classrooms and a large library.</p> for the text.
Close with </body></html>; every opening tag must have a matching closing tag.

COMPETENCYC104 marks

10. Read and answer: A student wrote this page: <html> <body> <title>My Page</title> <h1>Welcome<h1> <p>Hello</br> </body> </html> (a) Find three errors. (b) Write the corrected code.

Show Answer

Ans:

(a) <title> must be in <head>, not in <body>; the heading is not closed (</h1> is missing); </br> is wrong because <br> is an empty tag; the <p> tag is not closed either.
(b) <html>
<head><title>My Page</title></head>
<body>
<h1>Welcome</h1>
<p>Hello<br></p>
</body>
</html>

COMPETENCYC114 marks

11. Read and answer: A browser is given this code: <h2>Menu</h2> <p>Tea<br>Coffee<br>Milk</p> <hr> <p>Open 9 to 5</p> (a) How many lines does the first paragraph show? (b) What does <hr> do? (c) Why are <br> and <hr> called empty tags?

Show Answer

Ans:

(a) Three lines: Tea, Coffee and Milk, because each <br> breaks the line.
(b) It draws a horizontal line (rule) across the page between the two paragraphs.
(c) They hold no content between an opening and closing tag, so they need no closing tag.

LONGL125 marks

12. Write the HTML for a notice page with the title “Class Notice”, a centred main heading, two paragraphs with a line break inside the second one, and a horizontal line between the paragraphs. Explain each tag you use.

Show Answer

Ans:

<html>
<head><title>Class Notice</title></head>
<body>
<h1 align='center'>Notice</h1>
<p>The sports day is on Friday.</p>
<hr>
<p>Reach school by 8 a.m.<br>Wear the sports uniform.</p>
</body>
</html>
<head> and <title> hold the browser-tab text; <body> holds everything visible; <h1> is the main heading; <p> makes a paragraph; <br> breaks a line; <hr> draws a line.
