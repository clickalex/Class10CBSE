Written questions · Write

SHORTS12 marks

1. What is the difference between HTTP and HTTPS?

Show Answer

Ans:

HTTP (HyperText Transfer Protocol) is the protocol used to fetch web pages, and it sends everything in plain text on port 80. HTTPS is the same protocol wrapped in encryption using TLS/SSL, on port 443. The practical difference is that with HTTPS a third party watching the network cannot read or alter the data — which is why banking and login pages always use it.

SHORTS22 marks

2. Explain the difference between POP3 and IMAP.

Show Answer

Ans:

Both protocols receive email, but they handle storage differently. POP3 downloads messages to your device and normally deletes them from the server, so the mail is only on that one machine. IMAP leaves messages on the server and synchronises, so the same mailbox looks identical on a phone, a laptop and a web browser. IMAP needs a constant connection and server space; POP3 works offline once downloaded.

SHORTS33 marks

3. Break down the parts of this URL: https://clickalex.github.io/IT-402-/index.html.

Show Answer

Ans:

The URL has three parts. https:// is the protocol — it says the page will be fetched securely over HTTPS on port 443. clickalex.github.io is the domain name, which DNS resolves into an IP address. /IT-402-/index.html is the path, pointing to a specific file inside the IT-402- folder on that server.

SHORTS42 marks

4. What is the difference between TCP and UDP?

Show Answer

Ans:

TCP (Transmission Control Protocol) is connection-oriented: it checks that every packet arrived and reorders them, so delivery is guaranteed but slightly slower. UDP (User Datagram Protocol) simply sends packets without checking, so it is faster but some data may be lost. TCP is used for web pages and email, where a missing piece breaks the result; UDP is used for live video, VoIP and gaming, where a small loss is better than a delay.

SHORTS51 mark

5. Give the full form of FTP and its default port.

Show Answer

Ans:

FTP stands for File Transfer Protocol, and its default port is 21. It is used to upload and download files between a client and a server.

LONGL65 marks

6. Discuss “Internet Services & Protocols” in detail. Include the idea that carries marks, one worked example or answer frame, and why students lose marks.

Show Answer

Ans:

The protocol stack. Data on the internet is layered. HTTP/HTTPS carries web pages, TCP makes sure every part of a message arrives and in the right order, and IP handles addressing and routing. Together they are written TCP/IP. UDP is TCP's faster, less careful cousin, used for streaming and calls where a lost packet matters less than a delay.
Marks lens: Match the service to its protocol; explain what each service does.
Method / memory trick: SMTP Sends, POP Pulls, IMAP Keeps. That one sentence settles every email-protocol question.
Do not: Writing that SMTP receives email — it only sends. Receiving is POP3 or IMAP.

SHORTS112 marks

11. Match each service with the protocol it uses: browsing the web, sending email, reading email, transferring files.

Show Answer

Ans:

Browsing uses HTTP or HTTPS; sending email uses SMTP; reading email uses POP3 or IMAP; transferring files uses FTP. DNS is not a service but the system that converts a domain name into an IP address so that the service can find the right computer.

SHORTS123 marks

12. Describe what happens when you send an email.

Show Answer

Ans:

Your mail program hands the message to your mail server using SMTP.
That server asks DNS for the mail server of the recipient's domain, such as gmail.com, and passes the message to it.
The receiving server stores the message in the recipient's mailbox.
The recipient's program collects it with POP3, which usually downloads and deletes it, or with IMAP, which leaves it on the server and synchronises folders.
