SHORTS32 marks

3. What was ARPANET and why is it important?

Show Answer

Ans:

ARPANET (Advanced Research Projects Agency Network) was started in 1969 by the US Department of Defense's research agency. It is important because it was the first packet-switched network and the direct ancestor of today's internet — its first connection ran between UCLA and Stanford Research Institute.

SHORTS42 marks

4. What is the role of DNS?

Show Answer

Ans:

DNS (Domain Name System) translates human-readable domain names such as clickalex.github.io into the numeric IP addresses that computers actually use to find each other. Without it, users would have to memorise numbers like 140.82.121.4 to reach any website. DNS works like a distributed phone book for the internet.

SHORTS52 marks

5. What is the internet and how did it begin?

Show Answer

Ans:

The internet is a worldwide network of networks that links millions of computers using the TCP/IP family of protocols. It began in 1969 as ARPANET, a project of the US Department of Defense that linked four university computers, and grew into the public network we use after the World Wide Web was invented in 1989.

SHORTS63 marks

6. Distinguish between IPv4 and IPv6.

Show Answer

Ans:

IPv4 uses 32-bit addresses, giving roughly 4.3 billion possible addresses — written as four numbers separated by dots, such as 192.168.1.5. IPv6 uses 128-bit addresses, written in hexadecimal groups such as 2001:0db8:85a3::8a2e:0370:7334. IPv6 was created because the supply of IPv4 addresses was exhausted by the growth in connected devices; it also has better built-in support for security and automatic configuration.

Ch 2 · Internet Services & Protocols (12)

SHORTS11 mark

1. Give the full form of FTP and its default port.

Show Answer

Ans:

FTP stands for File Transfer Protocol, and its default port is 21. It is used to upload and download files between a client and a server.

SHORTS22 marks

2. What is the difference between HTTP and HTTPS?

Show Answer

Ans:

HTTP (HyperText Transfer Protocol) is the protocol used to fetch web pages, and it sends everything in plain text on port 80. HTTPS is the same protocol wrapped in encryption using TLS/SSL, on port 443. The practical difference is that with HTTPS a third party watching the network cannot read or alter the data — which is why banking and login pages always use it.

SHORTS32 marks

3. Explain the difference between POP3 and IMAP.

Show Answer

Ans:

Both protocols receive email, but they handle storage differently. POP3 downloads messages to your device and normally deletes them from the server, so the mail is only on that one machine. IMAP leaves messages on the server and synchronises, so the same mailbox looks identical on a phone, a laptop and a web browser. IMAP needs a constant connection and server space; POP3 works offline once downloaded.

SHORTS42 marks

4. What is the difference between TCP and UDP?

Show Answer

Ans:

TCP (Transmission Control Protocol) is connection-oriented: it checks that every packet arrived and reorders them, so delivery is guaranteed but slightly slower. UDP (User Datagram Protocol) simply sends packets without checking, so it is faster but some data may be lost. TCP is used for web pages and email, where a missing piece breaks the result; UDP is used for live video, VoIP and gaming, where a small loss is better than a delay.

SHORTS52 marks

5. Match each service with the protocol it uses: browsing the web, sending email, reading email, transferring files.

Show Answer

Ans:

Browsing uses HTTP or HTTPS; sending email uses SMTP; reading email uses POP3 or IMAP; transferring files uses FTP. DNS is not a service but the system that converts a domain name into an IP address so that the service can find the right computer.

SHORTS63 marks

6. Break down the parts of this URL: https://clickalex.github.io/IT-402-/index.html.

Show Answer

Ans:

The URL has three parts. https:// is the protocol — it says the page will be fetched securely over HTTPS on port 443. clickalex.github.io is the domain name, which DNS resolves into an IP address. /IT-402-/index.html is the path, pointing to a specific file inside the IT-402- folder on that server.

Show Answer

Ans:

Ch 3 · Network Types, Topologies & Devices (12)

SHORTS11 mark

1. Which IEEE standard defines Wi-Fi?

Show Answer

Ans:

IEEE 802.11 defines Wi-Fi. The IEEE 802.3 standard, by contrast, defines wired Ethernet.

SHORTS22 marks

2. Why is optical fibre preferred over copper cable for long distances?

Show Answer

Ans:

Optical fibre carries data as pulses of light through glass, so it suffers almost no signal loss over long distances and is immune to electrical interference from motors, power lines and lightning. It also has a far higher bandwidth than copper. Its drawbacks are that it is more expensive and more fragile to install, which is why copper still dominates the last few metres.

SHORTS32 marks

3. What is the difference between a MAC address and an IP address?

Show Answer

Ans:

A MAC address is a 48-bit hardware address burnt into the network card; it never changes and identifies the physical device. An IP address is assigned logically for the network the device is on, so it changes when the device moves to a different network. MAC works within one local network, while IP works across the whole internet.

SHORTS42 marks

4. Distinguish between a LAN and a WAN.

Show Answer

Ans:

A LAN covers a small area such as a room, a building or a campus, is owned by one organisation, uses switches and cables or Wi-Fi, and is fast. A WAN covers a city, a country or the world, links LANs over leased telephone lines, fibre or satellites, and is slower and shared among many organisations.

SHORTS53 marks

5. Explain star topology with its advantages and disadvantages.

Show Answer

Ans:

In star topology every node is connected by its own cable to a central device — a hub or a switch. All communication passes through that centre. Its advantages are that a cable failure affects only the one node attached to it, nodes can be added or removed without disturbing the rest, and faults are easy to locate. Its disadvantages are that it needs more cable than a bus, and the central device is a single point of failure — if the switch dies, the whole network stops.

SHORTS63 marks

6. Differentiate between a hub, a switch and a router.

Show Answer

Ans:

A hub works at the physical layer and repeats an incoming signal out of every port, so all devices see all traffic and collisions are common. A switch works at the data-link layer, learns the MAC address on each port and forwards a frame only to the intended port, which makes it far faster and more secure. A router works at the network layer and connects different networks, using IP addresses to choose the best path between them — it is what links your LAN to the internet.

Show Answer

Ans:

In a bus topology all computers share one main cable with terminators at each end; it is cheap and needs less cable.

Star is the topology used in almost every modern office network.

Ch 4 · Mobile & Wireless Technology (12)

SHORTS12 marks

1. What is the difference between Bluetooth and NFC?

Show Answer

Ans:

Bluetooth works over a range of a few metres and is used for continuous connections such as headphones, speakers and keyboards. NFC (Near Field Communication) works only within a few centimetres and is used for a single quick exchange — contactless payments, transit cards, pairing by tapping. Bluetooth needs pairing; NFC works by simply bringing two devices together.

SHORTS22 marks

2. What is a cell and what is handover?

Show Answer

Ans:

A cell is the geographic area covered by one mobile tower. A whole city is divided into many cells, which is why mobile networks are called cellular. Handover is the automatic process of moving an ongoing call or data session from one cell's tower to the next as the user travels, so the connection does not drop.

SHORTS32 marks

3. Why does infrared need line of sight but Wi-Fi does not?

Show Answer

Ans:

Infrared uses light waves, which cannot pass through solid objects, so the transmitter and receiver must see each other directly — that is why a TV remote only works when pointed at the TV. Wi-Fi uses radio waves, which pass through walls and furniture, so it works throughout a building without a direct line of sight.

SHORTS42 marks

4. What does 4G mean and how is it better than 3G?

Show Answer

Ans:

4G is the fourth generation of mobile network technology, designed for data rather than voice, with download speeds of up to about 100 Mbps, smooth video streaming and low delay. 3G was built mainly to improve voice calls and gave only modest data speeds, so tasks such as video calling were slow or impossible.

SHORTS53 marks

5. Compare 3G, 4G and 5G.

Show Answer

Ans:

3G made mobile internet practical, offering speeds up to about 2 Mbps, which allowed video calling and basic browsing. 4G (LTE) is an all-IP network designed around data rather than voice, reaching around 100 Mbps and making HD video streaming and VoIP everyday features. 5G targets up to 20 Gbps with latency below one millisecond; its real significance is not faster phones but support for massive numbers of connected devices — IoT sensors, autonomous vehicles and remote medical procedures.

Ch 5 · Web Browsers, Search & Web Concepts (12)

SHORTS11 mark

1. Name any three web browsers.

Show Answer

Ans:

Google Chrome, Mozilla Firefox and Microsoft Edge. Apple's Safari and Opera are other common examples.

SHORTS22 marks

2. Differentiate between a web browser and a search engine.

Show Answer

Ans:

A web browser is software installed on your computer or phone — Chrome, Firefox, Edge or Safari — that sends requests for pages and renders the HTML it receives into the page you see. A search engine such as Google is itself a website whose job is to index other websites and return a ranked list of results for your query. You need a browser in order to open a search engine, so they work together rather than as alternatives.

SHORTS32 marks

3. What are cookies and why are they used?

Show Answer

Ans:

A cookie is a small piece of data that a website stores in the user's browser. Websites use cookies to remember something about the user between visits — whether they are logged in, which language they chose, or what is in their shopping cart. Without cookies, every page request would be treated as a brand-new visitor. Because cookies can also be used to track browsing behaviour, browsers offer private modes that discard them when the window closes.

SHORTS42 marks

4. What is caching and what is its benefit?

Show Answer

Ans:

Caching means keeping a local copy of a resource — a page, an image or a stylesheet — so that it does not have to be downloaded again. The benefits are that pages load faster and use less bandwidth, which matters most on slow or metered connections. The trade-off is that a cached copy can be out of date, which is why a forced refresh sometimes shows a different page.

SHORTS52 marks

5. How does a search engine find and rank pages?

Show Answer

Show Answer

Ans:

It can be avoided by checking the sender's actual address rather than the display name, never clicking links in unsolicited messages, typing the website address yourself instead, looking for HTTPS before entering credentials, and enabling two-factor authentication so a stolen password alone is not enough.

Show Answer

Ans:

You can recognise it by a sender's address that does not match the real company, urgent or threatening language, a link whose real address differs from the text, and the request itself, because no bank ever asks for a password or an OTP.

SHORTS53 marks

5. Differentiate between a virus, a worm and a trojan horse.

Show Answer

Ans:

A virus is malicious code that attaches itself to a legitimate file and spreads only when that infected file is opened or shared, so it needs a human action to move. A worm is a standalone program that copies itself across a network automatically, needing no host file and no user action, which is why worms spread so fast. A trojan horse does not spread at all — it disguises itself as a useful or attractive program so the user installs it willingly, and only then does its hidden payload run.

Three key provisions are: it gives legal recognition to electronic records and digital signatures, so an online document or contract is as valid as a paper one; it defines cyber offences and their punishments, such as tampering with source documents under Section 65 and hacking under Section 66; and it provides a legal framework for electronic governance and secure electronic transactions, including penalties for identity theft under Section 66C and for publishing obscene material under Section 67.

SHORTS53 marks

5. What is a digital footprint? Explain its two types.

Show Answer

Ans:

A digital footprint is the trail of data a person leaves behind while using the internet — accounts, posts, comments, photographs, search history and the metadata attached to them. It has two types. An active footprint is created deliberately, when you post on social media, fill in a form or upload a photograph. A passive footprint is collected without your direct action, such as your IP address, approximate location, browsing history and cookies. Both matter because the internet rarely forgets — content can be copied and screenshotted, and colleges and employers increasingly check what is publicly visible.

SHORTS63 marks

6. Why is e-waste hazardous and how should it be managed?

Show Answer

Ans:

e-Waste is hazardous because discarded electronics contain toxic substances such as lead, mercury, cadmium and brominated flame retardants. When dumped in ordinary landfills these chemicals leach into soil and groundwater, and burning the waste releases poisonous fumes that harm both workers and the surrounding population. At the same time e-waste contains recoverable gold, silver and copper, so throwing it away wastes valuable material. It should be managed through the 3R approach — reduce, reuse and recycle — by repairing and passing on working devices where possible and handing the rest to authorised e-waste recyclers or collection centres rather than to regular waste collection.
