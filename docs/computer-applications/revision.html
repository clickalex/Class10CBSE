Computer Applications — Quick revision

One screen per chapter: formulas and the points that actually get asked. Expand what you need, skip what you know.

Ch 1 Internet Basics

Formulas

  • Bandwidth measured in bps: 1 Kbps = 1000 bps · 1 Mbps = 1000 Kbps · 1 Gbps = 1000 Mbps
  • Download speed in seconds ≈ file size in megabits ÷ speed in Mbps
  • ISP = Internet Service Provider; every device on the internet has an IP address
  • IP address formats: IPv4 = 4 numbers 0–255 separated by dots; IPv6 = eight groups of hex
  • Internet = network of networks; no single owner.
  • ARPANET 1969 → internet; Berners-Lee 1989 → web; India 1995 via VSNL.
  • Client requests, server supplies, ISP connects.
  • DNS converts names to IP addresses.
  • IPv4 = 32 bits, IPv6 = 128 bits.
  • Bandwidth = capacity; latency = delay.

Formulas

  • The protocol table to memorise

Ch 3 Network Types, Topologies & Devices

Formulas

  • LAN < MAN < WAN < the Internet — by area covered
  • Topologies: bus (one cable), star (all to a hub/switch), ring (each to the next), mesh (every node to many)
  • Devices: hub repeats to all · switch sends to one · router joins networks · modem converts the signal
  • Transmission media: twisted pair, coaxial, fibre optic (guided); radio, microwave, satellite (unguided)
  • PAN < LAN < MAN < WAN.
  • Star: safe per node, fragile at the centre. Bus: cheapest, fragile cable. Mesh: most reliable, most expensive.
  • Hub broadcasts, switch forwards to one port, router joins networks, modem converts signals.
  • Twisted pair (RJ-45), coaxial, optical fibre; wireless = 802.11, Bluetooth, infrared.
  • MAC = hardware, IP = network.

Ch 5 Web Browsers, Search & Web Concepts

Formulas

  • A URL reads: scheme://host:port/path?query#fragment — https://cbse.gov.in/syllabus
  • Search operators: "exact phrase", -exclude, site:domain, filetype:pdf
  • Browser cache stores copies; incognito mode does not save history or cookies locally
  • Cookie = a small file a site leaves on your device to remember you
  • Browser = software on your device; search engine = a website.
  • Cookie remembers, cache speeds up, history records.
  • Crawler → index → ranking algorithm.
  • Web page = one document; website = many pages; home page = entry point.
Ch 6 HTML I — Introduction & Basic Tags

Formulas

  • The skeleton to memorise
  • <html>
  • <head>
  • <title>My Page</title>
  • </head>
  • <body>
  • <h1>Heading</h1>
  • <p>A paragraph.</p>
  • </body>
  • </html>
  • HTML = HyperText Markup Language; markup, not programming.
  • Tag = the marker; element = opening tag + content + closing tag.
  • Skeleton: html → head → title → body.
  • Empty tags: br, hr, img, input.
  • h1 largest, h6 smallest.
  • Comments: <!-- ... -->.
Ch 7 HTML II — Text Formatting & Lists

Formulas

  • Logical tags describe meaning: <strong>, <em>, <blockquote>, <code>
  • Physical tags describe looks: <b>, <i>, <u>, <tt>, <big>, <small>
  • Lists: <ul><li> unordered · <ol><li> ordered · <dl><dt><dd> definition
  • Font tag with attributes: <font face="Arial" size="4" color="#0066cc">text</font>
  • <pre> keeps spaces and line breaks exactly as typed
  • ul = bullets, ol = numbers, dl = definitions; all items in li.
  • ol type: 1, A, a, I, i; start sets the first number.
  • ul type: disc (default), circle, square.
  • font: face, size (1–7), color.
  • sub sinks, sup rises.
  • align: left, center, right.
Ch 8 HTML III — Links & Images

Formulas

  • Link: <a href='page.html'>text</a>; open in a new tab with target='_blank'
  • Jump inside a page: <a href="#top"> to an element carrying id="top"
  • Image: <img src="logo.png" width="200" height="100" alt="School logo">
  • Image as a link: put <img> inside <a> — the picture then opens the href
  • Rules: href for links, src for sources — <a href>, <img src>, <script src>
  • <a href='...'>text</a>; target='_blank' opens a new tab.
  • Absolute = full URL; relative = from the current file; .. = up one folder.
  • In-page link: id on the target, #id in href.
  • <img src alt width height align border> — empty tag.
  • href for links, src for sources.
Ch 9 HTML Tables

Formulas

  • A 2×2 table with a heading row
  • <table border='1'>
  • <tr><th>Name</th><th>Marks</th></tr>
  • <tr><td>Asha</td><td>88</td></tr>
  • </table>
  • Merging: <td colspan='2'>Full width</td> spans two columns. <td rowspan='2'>Tall cell</td> spans two rows.
  • table → tr (row) → td (cell).
  • th = header cell, bold and centred.
  • colspan = wide, rowspan = tall.
  • Delete the cells a merge replaces.
  • cellpadding inside, cellspacing between.
  • border, width, height, align, bgcolor on <table>.
Ch 10 HTML Forms

Formulas

  • Form shell: <form action="submit.php" method="post"> … </form>
  • Input types: text password radio checkbox submit reset file hidden
  • <textarea rows="4" cols="40"> for long text; <select><option> for a drop-down
  • Every field that is submitted needs a name; value is what travels, placeholder is only a hint
  • method="get" puts data in the URL (short, visible); method="post" sends it in the body
  • <form action method>; get = visible in URL, post = in body.
  • <input> is empty; type decides the control.
  • Radio: one choice, shared name. Checkbox: many choices.
  • Every control needs a name or it is not submitted.
  • <textarea rows cols> is a paired tag.
  • <select> + <option>; selected picks the default.
Ch 11 Frames, Multimedia & Special Tags

Formulas

  • Frames split a window: <frameset cols="25%,75%"><frame src="menu.html"> … </frameset>
  • Frames need no <body> in the frameset document; <noframes> covers old browsers
  • Inline frame today: <iframe src='page.html' width='600' height='400'></iframe>
  • Multimedia: <audio controls>, <video controls>, or the older <embed src="clip.mp4">
  • Marquee: <marquee behavior="scroll" direction="left">text</marquee> — non-standard, use with care
  • <frameset rows|cols> replaces <body>; each <frame src> fills a region.
  • <iframe src width height> embeds inside a normal page.
  • <audio|video src controls autoplay loop muted>.
  • <marquee direction behavior scrollamount>.
  • <pre> preserves spacing; <meta> describes the page.
Ch 12 Cyber Safety & Security

Formulas

  • Strong password: at least 12 characters, mixed case, digits and symbols, unique per site
  • 2FA / OTP: something you know plus something you have
  • Phishing signals: urgency, a wrong-looking domain, a link that is not where it claims to go
  • Update rule: patch the operating system, browser and apps — most attacks use known, fixed holes
  • Ethics = behaviour; safety = you; security = systems.
  • Virus needs a host file; worm travels alone; trojan must be installed.
  • Spyware watches, ransomware locks, logic bomb waits, adware advertises.
  • Phishing email, smishing SMS, vishing voice.
  • Strong unique passwords, 2FA, updates, HTTPS, backups.

Ch 14 The IT Act, Digital Footprint & e-Waste

Formulas

  • IT Act 2000 (amended 2008) — the Indian law on electronic transactions and cyber crime
  • Digital footprint = active (what you post) + passive (what sites collect about you)
  • E-waste rule: never in the household bin — hand it to an authorised recycler
  • Right to privacy is a fundamental right; ask what data an app collects and why
  • IT Act 2000 (amended 2008): legal validity to e-documents and digital signatures.
  • Sections: 65 tampering, 66 hacking, 66C identity theft, 67 obscenity, 72 confidentiality.
  • Active footprint = you posted it; passive = collected automatically.
  • e-Waste contains lead, mercury, cadmium; manage by 3R.
  • Digital citizenship = responsible, respectful, safe use.
