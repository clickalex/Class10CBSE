CBSE • CLASS 10 • COMPUTER APPLICATIONS

Unit II · HTML

25 marks. The biggest single unit in the paper. Tags, attributes, tables, forms, lists and CSS — plus embedded audio and video — all written by hand in the exam.

  • Ch 6 · HTML I — Introduction & Basic TagsWhat HTML is, the skeleton of a document, and the tags you use on every page.
  • Ch 7 · HTML II — Text Formatting & ListsBold, italic, alignment, colour — plus ordered, unordered and definition lists.
  • Ch 8 · HTML III — Links & ImagesThe <a> tag, href, anchors, and the <img> tag with its attributes.
  • Ch 9 · HTML Tables<table>, <tr>, <td>, borders, and the two attributes that merge cells.
  • Ch 10 · HTML Forms<form>, every <input> type, <textarea>, <select> and the buttons.
  • Ch 11 · CSS and MultimediaCSS properties (colour, font, border, margin, float) plus <audio> and <video>.
