Written questions · Write

SHORTS12 marks

1. Differentiate a hazard and an accident with an IT-lab example.

Show Answer

Ans:

A hazard is a potential source of harm (a loose cable across the aisle). An accident is the event (a student trips and the monitor falls).

SHORTS22 marks

2. List four electrical safety rules for a computer lab.

Show Answer

Ans:

Dry hands; earthed plugs; no overloaded boards; don’t open the power supply; report frayed wires; use a surge protector.

LONGL34 marks

3. Explain four types of workplace hazard with one IT-lab example each.

Show Answer

Ans:

Physical — trailing cables; electrical — open socket; ergonomic — low screen causing neck pain; psychosocial — long hours without a break. Control each: cable covers, close sockets, raise the monitor, timetable breaks.

APPLICATIONA43 marks

4. A student pours water on a sparking socket. Two mistakes and the correct actions.

Show Answer

Ans:

Water on electrical fire; staying next to a live spark. Instead: don’t touch, switch off mains if safe, alert staff, use CO2/powder extinguisher, evacuate.

COMPETENCYC54 marks

5. Read and answer: Lab PCs face a window, chairs don’t adjust, passwords are on sticky notes. (a) Name three hazard/security issues. (b) One control for each. (c) Who should you report this to?

Show Answer

Ans:

(a) Glare (ergonomic), poor posture, password leak (security).
(b) Blinds/position screens, adjustable chairs, unique passwords stored in a password manager / teacher vault — never sticky notes.
(c) Lab teacher / system admin / safety in-charge.

LONGL65 marks

6. Discuss “Health, Safety and Security at the Workplace” in detail. Include the idea that carries marks, one worked example or answer frame, and why students lose marks.

Show Answer

Ans:

Hazard = anything that can cause harm. Risk = chance that the harm will occur.
Marks lens: marks with the rest of Unit 4. Hazard types + two precautions each.
Method / memory trick: Water on an electrical fire is the classic wrong answer.
Do not: Writing “be careful” with no concrete precaution.
