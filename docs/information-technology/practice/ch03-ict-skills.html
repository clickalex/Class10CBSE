Written questions · Write

SHORTS11 mark

1. What is an operating system? Give two examples.

Show Answer

Ans:

System software that manages hardware and runs programs. Examples: Windows, Linux, Android.

SHORTS22 marks

2. Differentiate a file and a folder with one example each.

Show Answer

Ans:

A file stores data (marks.ods). A folder stores files and other folders (Class10/IT/).

SHORTS32 marks

3. What is an operating system? Name two examples.

Show Answer

Ans:

An operating system is the system software that manages the computer's memory, processor, disks and devices and lets the user run application programs. Examples are Windows, Linux, macOS and Android.

SHORTS42 marks

4. What is the Recycle Bin, and how is restoring a file different from deleting it permanently?

Show Answer

Ans:

The Recycle Bin is a holding area where deleted files wait until it is emptied. Restoring returns the file to its original folder, so nothing is lost. Deleting permanently (emptying the Bin, or Shift + Delete) removes the file beyond easy recovery — which is why important files should be backed up before the Bin is emptied.

SHORTS52 marks

5. List four basic care rules that protect a computer from physical damage and data loss.

Show Answer

Ans:

Keep the machine dust-free and away from food and drink, which damage keyboards and circuits.
Use a surge protector so voltage spikes do not harm the hardware.
Shut down through the OS command instead of pulling the plug, which can corrupt files.
Run updated antivirus software and keep a backup of important work.

APPLICATIONA63 marks

6. Amit eats chips over the keyboard and never shuts the PC down. List three risks and three care steps.

Show Answer

Ans:

Risks: crumbs jam keys, oil damage, overheating, data loss. Care: no food/drink, proper shutdown, dust-free vents, surge protector, backups.

APPLICATIONA73 marks

7. Riya is revising “ICT Skills–II” (Operating system, files and folders, and basic care of a computer.). A classmate lost marks by doing this: Calling Writer an operating system. Apply the correct method and rewrite the scoring answer.

Show Answer

Ans:

Correct method: File has an extension; a folder does not need one.
Why the mistake costs marks: Calling Writer an operating system.
Write the definition or formula first, then the working or example.

SHORTS83 marks

8. How would you organise files and folders so that your work is always easy to find?

Show Answer

Ans:

Make one folder for each subject or project, and inside it one folder per term or per type of work.
Give every file a short, descriptive name with the date, such as maths_notes_2026-08-12.
Keep the folder tree shallow — no more than two or three levels — and delete or archive old versions.
Keep a backup copy on an external drive or in the cloud, and run an antivirus scan on anything you download.

SHORTS93 marks

9. Why should files be given clear names and kept in subject-wise folders? Illustrate with a school-project example.

Show Answer

Ans:

Clear names and folders make work findable: a file named aaa.odt on a crowded Desktop is easily lost or overwritten.
Example — a project split as Project/notes.odt, Project/images/, Project/final-report.odt lets any part be found in seconds.
Good organisation also protects against loss: one folder is easy to back up, scattered files are not.

COMPETENCYC104 marks

10. Read and answer: Meera’s project file vanished after a power cut. She had saved only on the Desktop as aaa.odt. (a) Two file-management mistakes. (b) Two care/maintenance steps that would have helped.

Show Answer

Ans:

(a) No backup; a meaningless file name; Desktop-only copy.
(b) Surge protector / UPS; Save As into a named folder; weekly backup on a pen drive or cloud.
