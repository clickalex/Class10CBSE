Written questions · Write

SHORTS12 marks

1. Write the steps to insert a Table of Contents in Writer.

Show Answer

Ans:

Apply Heading styles → Insert → Table of Contents and Index → Table of Contents → OK. Right-click → Update Index after changes.

SHORTS22 marks

2. What is a document template?

Show Answer

Ans:

A model file (.ott) that stores styles, headers and boilerplate so new documents start consistent.

LONGL34 marks

3. Explain mail merge and its advantages.

Show Answer

Ans:

Mail merge combines a main document with a data source to produce personalised letters. Advantages: speed, accuracy of names, one design for many copies, labels/envelopes.

APPLICATIONA43 marks

4. A teacher wants 40 identical permission letters with only the parent name changing. Which Writer feature, and what two files does she need?

Show Answer

Ans:

Mail merge. She needs the main letter and a data source (Calc column ParentName).

COMPETENCYC54 marks

5. Read and answer: Two students edit report.odt. One deletes a paragraph; the other does not know what changed. (a) Which tool should have been on? (b) How do they accept only some edits? (c) When would a Comment be better than changing the text?

Show Answer

Ans:

(a) Track Changes → Record.
(b) Review each change → Accept or Reject.
(c) When suggesting, not rewriting — e.g. “please add the figure here”.

LONGL65 marks

6. Discuss “ToC, Templates and Track Changes” in detail. Include the idea that carries marks, one worked example or answer frame, and why students lose marks.

Show Answer

Ans:

Table of Contents: apply Heading 1/2/3 → Insert → Table of Contents and Index → Table of Contents. Update with right-click → Update Index after edits.
Marks lens: ToC steps and Track Changes on/off are asked every year.
Method / memory trick: Empty ToC ⇒ headings are not Heading styles.
Do not: Saving a template as .odt instead of .ott.
