Written questions · Write

SHORTS12 marks

1. Write a formula that shows cell B4 of sheet Fees on sheet Summary.

Show Answer

Ans:

=Fees.B4 or ='Fees'.B4.

SHORTS22 marks

2. What is a hyperlink in Calc?

Show Answer

Ans:

A clickable link to a web page, file, email or a location in the document, inserted via Insert → Hyperlink.

LONGL34 marks

3. Why is linking sheets better than copy-pasting values for a yearly total?

Show Answer

Ans:

A link stays live: when a term sheet changes, the year sheet updates. Copy-paste values go stale, cause mismatch, and make auditing harder.

APPLICATIONA43 marks

4. Summary sheet must show Total from three term sheets named Term1, Term2, Term3, each total in G20. Write the formula.

Show Answer

Ans:

=Term1.G20+Term2.G20+Term3.G20

COMPETENCYC54 marks

5. Read and answer: A student pastes last month’s numbers into the annual sheet. The teacher later corrects the January file; the annual sheet does not change. (a) What did the student do wrong? (b) How should the cells have been pasted? (c) One risk of live links.

Show Answer

Ans:

(a) Pasted values, not links.
(b) Paste Special → Link, or a formula to the January sheet.
(c) If the source file is moved/renamed, the link breaks — keep files together.

LONGL65 marks

6. Discuss “Linking Spreadsheet Data” in detail. Include the idea that carries marks, one worked example or answer frame, and why students lose marks.

Show Answer

Ans:

Same-file sheet link: =Sheet2.B3 or ='Term 1'.B3 if the sheet name has a space.
Marks lens: Syntax of a sheet reference and Insert → Hyperlink.
Method / memory trick: Sheet names with spaces need single quotes: 'Term 1'.A1.
Do not: Renaming a sheet after writing formulas without checking — some links break.
