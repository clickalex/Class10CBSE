Written questions · Write

SHORTS12 marks

1. Write a formula that shows cell B4 of sheet Fees on sheet Summary.

Show Answer

Ans:

=Fees.B4 — or, if the sheet name contains spaces or punctuation, quote it: ='Fees'.B4. The sheet name comes first, then a full stop, then the cell address; Calc fills this in for you if you type = and then click the cell on the Fees sheet.

SHORTS22 marks

2. What is a hyperlink in Calc?

Show Answer

Ans:

A clickable link to a web page, file, email or a location in the document, inserted via Insert → Hyperlink.

SHORTS32 marks

3. What is meant by linking spreadsheet data?

Show Answer

Ans:

Linking makes one cell take its value from another cell, sheet or file, so that the value is not typed twice. When the source changes, every linked cell updates automatically, which keeps reports consistent and saves the work of retyping.

SHORTS42 marks

4. What is the difference between a hyperlink and a sheet-link formula? Give one example of each.

Show Answer

Ans:

A hyperlink jumps the reader somewhere when clicked — for example, Insert → Hyperlink to https://cbseacademic.nic.in opens the CBSE site.
A sheet-link formula pulls a live value into a cell — for example, =Term1.G20 shows Term1's total inside the Summary sheet and updates whenever Term1 changes.

APPLICATIONA53 marks

5. Summary sheet must show Total from three term sheets named Term1, Term2, Term3, each total in G20. Write the formula.

Show Answer

Ans:

=Term1.G20+Term2.G20+Term3.G20 — one reference per term sheet, added together. Linking this way means each term file can be updated on its own and the Summary total follows automatically, with no retyping and no copy-paste errors.

APPLICATIONA63 marks

6. Riya is revising “Linking Spreadsheet Data” (Sheet links, hyperlinks, linking to external files and data from the web.). A classmate lost marks by doing this: Renaming a sheet after writing formulas without checking — some links break. Apply the correct method and rewrite the scoring answer.

Show Answer

Ans:

Correct method: Sheet names with spaces need single quotes: 'Term 1'.A1.
Why the mistake costs marks: Renaming a sheet after writing formulas without checking — some links break.
Write the definition or formula first, then the working or example.

SHORTS73 marks

7. How do you link a cell to another sheet and to a file outside the workbook?

Show Answer

Ans:

Within the workbook: type = in the target cell, click the sheet tab, click the source cell and press Enter; the formula reads =Sheet2.B3.
To an external file: open both files, copy the source cell, click the target cell and choose Edit → Paste Special → Paste Link.
The formula then contains the full path, for example ='file:///home/user/accounts.ods'#$Sheet1.A1, and you can refresh the links when the source file changes.

SHORTS83 marks

8. Why should linked files be kept in one folder? Describe what breaks when a source file is moved or renamed.

Show Answer

Ans:

Calc stores external links as paths; keeping all files in one folder keeps those paths short and portable.
If the source file moves or is renamed, the link cannot be resolved: the dependent cells show errors or stale values instead of live data.
Fix — keep the set together from the start, and if a move is unavoidable, re-point the links through Edit → Links to External Files.

LONGL94 marks

9. Why is linking sheets better than copy-pasting values for a yearly total?

Show Answer

Ans:

A link stays live: when a term sheet changes, the year sheet updates. Copy-paste values go stale, cause mismatch, and make auditing harder.

COMPETENCYC104 marks

10. Read and answer: A student pastes last month’s numbers into the annual sheet. The teacher later corrects the January file; the annual sheet does not change. (a) What did the student do wrong? (b) How should the cells have been pasted? (c) One risk of live links.

Show Answer

Ans:

(a) Pasted values, not links.
(b) Paste Special → Link, or a formula to the January sheet.
(c) If the source file is moved/renamed, the link breaks — keep files together.

COMPETENCYC114 marks

The chapter is described as: Sheet links, hyperlinks, linking to external files and data from the web.. (a) Name the key idea. (b) How is this usually asked in the paper? (c) State one mistake that would cost a mark.

Show Answer

Ans:

(a) Sheet links, hyperlinks, linking to external files and data from the web.
(b) Syntax of a sheet reference and Insert → Hyperlink.
(c) Renaming a sheet after writing formulas without checking — some links break.

LONGL125 marks

12. Discuss “Linking Spreadsheet Data” in detail. Include the idea that carries marks, one worked example or answer frame, and why students lose marks.

Show Answer

Ans:

Same-file sheet link: =Sheet2.B3 or ='Term 1'.B3 if the sheet name has a space.
Marks lens: Syntax of a sheet reference and Insert → Hyperlink.
Method / memory trick: Sheet names with spaces need single quotes: 'Term 1'.A1.
Do not: Renaming a sheet after writing formulas without checking — some links break.
