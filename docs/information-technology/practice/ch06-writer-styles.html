Written questions · Write

SHORTS12 marks

1. What is a style in Writer? Name any four categories.

Show Answer

Ans:

A named set of formatting that can be reused. Categories: Paragraph, Character, Page, Frame, List, Table.

SHORTS22 marks

2. What is Fill Format mode?

Show Answer

Ans:

A Styles-window tool that copies the selected style onto each paragraph (or object) you click, like a format paintbrush.

SHORTS32 marks

3. Why are styles better than formatting each heading by hand?

Show Answer

Ans:

A style stores the whole set of formatting — font, size, spacing, alignment — in one named item. Change the style once and every paragraph using it changes, the document stays consistent, and headings styled with Heading 1, 2 and 3 can be collected automatically into a table of contents.

SHORTS42 marks

4. What is the difference between a paragraph style and a character style? Give one example of each.

Show Answer

Ans:

A paragraph style formats a whole paragraph at once — for example, Heading 1 sets the font, size and spacing of every chapter title.
A character style formats only selected words inside a paragraph — for example, an Emphasis style that italicises a single term without touching the rest of the line.

APPLICATIONA53 marks

5. A 20-page report uses Bold 16 pt for titles. The examiner wants Heading 1 in navy. What should the student do instead of selecting each title?

Show Answer

Ans:

Create or modify Heading 1 (navy, size, spacing), then Fill Format / select each title and apply Heading 1. Later, one modify updates all.

APPLICATIONA63 marks

6. Riya is revising “Introduction to Styles (Writer)” (Page, paragraph, character, frame, list and table styles in LibreOffice Writer.). A classmate lost marks by doing this: Building a ToC from manually bolded text. Apply the correct method and rewrite the scoring answer.

Show Answer

Ans:

Correct method: Headings must use Heading styles, not just Bold 16 pt — otherwise ToC will be empty.
Why the mistake costs marks: Building a ToC from manually bolded text.
Write the definition or formula first, then the working or example.

SHORTS73 marks

7. Describe how to create and then apply a paragraph style in LibreOffice Writer.

Show Answer

Ans:

Format one paragraph exactly as you want it, then open the Styles window with F11 and click the New Style from Selection button.
Give the style a name such as ‘MyBodyText' and click OK.
To apply it, click anywhere in the paragraph you want to change and double-click the style name under Paragraph Styles.
To change the whole document, right-click the style, choose Modify and set the font, size and spacing once.

SHORTS83 marks

8. What is ‘Update Style’? Describe a situation in which it saves more time than re-applying a style.

Show Answer

Ans:

Update Style takes the manual formatting of the current paragraph and writes it back into the style definition, so every paragraph using that style changes at once.
Situation — a report has forty Heading 2 titles in black; the teacher wants them navy. Format one title navy, click Update Style, and all forty change in one step instead of forty.

LONGL94 marks

9. Why should a long report use styles instead of manual formatting?

Show Answer

Ans:

One change updates every heading; ToC can be generated; the look stays consistent; less chance of mixed fonts; templates become reusable.

COMPETENCYC104 marks

10. Read and answer: Neha’s ToC is empty even though titles look big and bold. (a) Why? (b) Steps to fix it. (c) How will this help next time she changes the colour of all headings?

Show Answer

Ans:

(a) Titles used direct formatting, not Heading styles.
(b) Apply Heading 1/2, then Insert → Table of Contents.
(c) Modify Heading 1 once — every heading and the ToC pick up the new colour.

Change the style once, every place it is used updates. The chapter is described as: Page, paragraph, character, frame, list and table styles in LibreOffice Writer.. (a) Name the key idea. (b) How is this usually asked in the paper? (c) State one mistake that would cost a mark.

Show Answer

Ans:

(a) Page, paragraph, character, frame, list and table styles in LibreOffice Writer.
(b) Theory asks types of styles and why styles beat manual formatting.
(c) Building a ToC from manually bolded text.

LONGL125 marks

12. Discuss “Introduction to Styles (Writer)” in detail. Include the idea that carries marks, one worked example or answer frame, and why students lose marks.

Show Answer

Ans:

A style is a named collection of formatting. Change the style once, every place it is used updates.
Marks lens: Theory asks types of styles and why styles beat manual formatting.
Method / memory trick: Headings must use Heading styles, not just Bold 16 pt — otherwise ToC will be empty.
Do not: Building a ToC from manually bolded text.
