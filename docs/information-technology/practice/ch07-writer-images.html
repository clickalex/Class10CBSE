Written questions · Write

SHORTS12 marks

1. Name any four text-wrapping options in Writer.

Show Answer

Ans:

None, Before, After, Parallel, Optimal, Through, In Background (any four).

SHORTS22 marks

2. What does grouping do?

Show Answer

Ans:

It joins selected drawing objects so they move, resize and copy as a single object.

LONGL34 marks

3. Explain anchoring of images in Writer.

Show Answer

Ans:

Anchor decides what the image sticks to: To Paragraph (moves with the para), To Character, As Character (in the text line), To Page (fixed on that page). Choose To Paragraph + Optimal wrap for reports.

APPLICATIONA43 marks

4. An image covers the heading of a report. Which two settings would you change first?

Show Answer

Ans:

Wrap (Optimal or After) and arrangement (Send to Back) or move the anchor to the correct paragraph.

COMPETENCYC54 marks

5. Read and answer: A student’s picture sits in a huge white box and the caption is not numbered. (a) Two likely causes. (b) Steps to insert a proper Figure caption. (c) Why captions help in a long file.

Show Answer

Ans:

(a) Wrap = None; image as a huge As-Character object; no Insert Caption used.
(b) Right-click → Insert Caption → category Figure → type the title.
(c) Auto numbering and a Table of Figures.

LONGL65 marks

6. Discuss “Working with Images (Writer)” in detail. Include the idea that carries marks, one worked example or answer frame, and why students lose marks.

Show Answer

Ans:

Insert image: Insert → Image, or drag from a folder, or copy-paste. Keep a copy of the picture with the file if you must move the document.
Marks lens: Expect “how to wrap an image” and “difference between anchor types”.
Method / memory trick: If text jumps wildly, the image is probably As Character — change wrap and anchor.
Do not: Stretching a photo so faces look wide — hold Shift or lock ratio.
