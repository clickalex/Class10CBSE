Written questions · Write

SHORTS12 marks

1. Differentiate a form and a report.

Show Answer

Ans:

A form is for entering/editing records on screen. A report is a formatted, usually read-only printout or PDF of selected data.

SHORTS22 marks

2. Why create a report from a query rather than from a whole table?

Show Answer

Ans:

The query filters and sorts first (e.g. only unpaid fees), so the report prints exactly the needed rows.

SHORTS32 marks

3. Why is a form better than the table grid for entering data?

Show Answer

Ans:

A form shows one record at a time in a clean layout, can carry instructions, drop-down lists, buttons and field labels, and prevents the common mistakes of typing into the wrong column or the wrong row. It is designed for the person who uses the database, while the table grid is designed for the person who built it.

SHORTS42 marks

4. What is grouping in a report? Give one example with a suitable total.

Show Answer

Ans:

Grouping collects report rows by a shared field and prints sub-headings and subtotals for each group. Example — a fee-dues report grouped by Section, with each section's list followed by that section's total dues, and a grand total at the end.

APPLICATIONA53 marks

5. The office wants a printed list of Class 10 students owing more than ₹500, grouped by section. Form or report? What sits underneath?

Show Answer

Ans:

A report. Underneath: a query with Class=10, Fees>500, then group by section in the report wizard.

APPLICATIONA63 marks

6. Riya is revising “Forms and Reports” (Data-entry forms and printable reports from tables or queries.). A classmate lost marks by doing this: Building a report on the whole table when the question said “students with marks > 80”. Apply the correct method and rewrite the scoring answer.

Show Answer

Ans:

Correct method: If the report is empty, the query returned zero rows — fix criteria first.
Why the mistake costs marks: Building a report on the whole table when the question said “students with marks > 80”.
Write the definition or formula first, then the working or example.

SHORTS73 marks

7. Describe how to create a report in LibreOffice Base.

Show Answer

Ans:

Choose Reports, then Use Wizard to Create Report, and select the table or query that holds the data.
Pick the fields to show, choose a grouping level if you want subtotals, set the sort order and the layout.
Give the report a title, choose whether it is a columnar or a tabular report, and finish; the wizard opens it for preview.
The report can then be edited in Design View, and printed or exported as a PDF for distribution.

SHORTS83 marks

8. Name two form controls suited to different field types, and explain the match in each case.

Show Answer

Ans:

Check box ↔ Yes/No field — a tick directly means true and an empty box means false, so no typing is needed.
List box ↔ a field with fixed options — showing Class as 9/10/11/12 prevents spellings like ‘ten’ or ‘X’ that would corrupt queries.

LONGL94 marks

9. Write steps to create a data-entry form for the Student table in Base.

Show Answer

Ans:

Forms → Use Wizard → table Student → select fields → choose layout (columnar) → set to display all data / data entry → style → name frmStudent → finish. Test by adding one record.

COMPETENCYC104 marks

10. Read and answer: Data-entry staff keep typing in Datasheet and accidentally delete a column. (a) Which object reduces that risk? (b) Two reasons. (c) How should monthly printouts be produced?

Show Answer

Ans:

(a) A form with only the needed controls.
(b) No access to Design View; labels guide the operator; validation.
(c) A report (from a query), not a screenshot of the datasheet.

COMPETENCYC114 marks

11. Read and answer: A Class 10 student is preparing “Forms and Reports”. Their note says: Form: on-screen layout for entering and editing records, one at a time, with labels and controls. Safer than raw datasheet (validation, no extra columns). The chapter is described as: Data-entry forms and printable reports from tables or queries.. (a) Name the key idea. (b) How is this usually asked in the paper? (c) State one mistake that would cost a mark.

Show Answer

Ans:

(a) Data-entry forms and printable reports from tables or queries.
(b) Practical often: form on Student + report from a query.
(c) Building a report on the whole table when the question said “students with marks > 80”.

LONGL125 marks

12. Discuss “Forms and Reports” in detail. Include the idea that carries marks, one worked example or answer frame, and why students lose marks.

Show Answer

Ans:

Form: on-screen layout for entering and editing records, one at a time, with labels and controls. Safer than raw datasheet (validation, no extra columns).
Marks lens: Practical often: form on Student + report from a query.
Method / memory trick: If the report is empty, the query returned zero rows — fix criteria first.
Do not: Building a report on the whole table when the question said “students with marks > 80”.
