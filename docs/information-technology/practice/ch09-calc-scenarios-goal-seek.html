Written questions · Write

SHORTS12 marks

1. What is Goal Seek in Calc?

Show Answer

Ans:

A what-if tool: you set the result you want in a formula cell and Calc finds the input value that produces it.

SHORTS22 marks

2. What is a scenario?

Show Answer

Ans:

A named set of values for specified cells so you can switch between cases (best/worst) without retyping.

LONGL34 marks

3. Differentiate Consolidate and Subtotals.

Show Answer

Ans:

Consolidate combines several ranges/sheets into one summary (often another sheet). Subtotals insert summary rows inside one sorted list (sum of each group). Consolidate is across blocks; Subtotals is inside a table.

APPLICATIONA43 marks

4. A shop wants profit of ₹8,000. Profit is =B2*B3-B4 (price × qty − cost). Which tool, and which cell is “By changing” if qty and cost are fixed?

Show Answer

Ans:

Goal Seek. Set cell = profit, To value = 8000, By changing = price (B2).

COMPETENCYC54 marks

5. Read and answer: Four quarterly sheets have the same layout of expenses. The owner wants one yearly total that updates if a quarter changes. (a) Which tool? (b) Two settings to tick/choose. (c) Why not just type the four totals by hand?

Show Answer

Ans:

(a) Data → Consolidate.
(b) Function Sum; add each range; Link to source data.
(c) Manual totals go stale; a link updates and reduces typing errors.

LONGL65 marks

6. Discuss “Scenarios and Goal Seek (Calc)” in detail. Include the idea that carries marks, one worked example or answer frame, and why students lose marks.

Show Answer

Ans:

Consolidate: Data → Consolidate. Combines the same layout from several sheets (e.g. four term marks) using Sum/Average. Tick “Link to source data” to auto-update.
Marks lens: Goal Seek and Scenarios are the theory + practical pair.
Method / memory trick: Goal Seek needs a formula in the set cell. Typing a number there will fail.
Do not: Mixing up Goal Seek (one input) with Solver (many inputs + constraints).
