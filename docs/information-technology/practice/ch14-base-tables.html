Written questions · Write

SHORTS12 marks

1. Name four data types in Base and one use each.

Show Answer

Ans:

VARCHAR for names, Integer for roll number, Date for DOB, Decimal for fees, Yes/No for paid flag.

SHORTS22 marks

2. How do you set a primary key in Design View?

Show Answer

Ans:

Right-click the field row → Primary Key so the key icon appears, then save the table.

LONGL34 marks

3. Write field names, types and keys for a table Book.

Show Answer

Ans:

ISBN VARCHAR PK; Title VARCHAR; Author VARCHAR; Price DECIMAL; Available YES/NO. ISBN uniquely identifies a book; Available is Boolean.

APPLICATIONA43 marks

4. A student stores mobile numbers as Integer and 098… becomes 98. Why, and what type should be used?

Show Answer

Ans:

Integer drops leading zeros and is not a “number you calculate with”. Use Text/VARCHAR.

COMPETENCYC54 marks

5. Read and answer: Table Marks has fields Name, Marks, Marks, Date. (a) Three design faults. (b) Redesign with types and a PK. (c) Which view to use in the practical.

Show Answer

Ans:

(a) Duplicate field name; no PK; Name is a weak key; Date of what?
(b) StudentID INTEGER PK; Name VARCHAR; Marks INTEGER; ExamDate DATE.
(c) Design View to build, Datasheet to enter records.

LONGL65 marks

6. Discuss “Tables in LibreOffice Base” in detail. Include the idea that carries marks, one worked example or answer frame, and why students lose marks.

Show Answer

Ans:

Ways to create a table: Design View (exam method), Wizard, View/SQL. Use Design View.
Marks lens: Create a table with four fields, correct types, PK set.
Method / memory trick: Phone numbers are Text, not Integer — or you lose leading 0.
Do not: Forgetting to set the primary key — Base warns, some students click No.
