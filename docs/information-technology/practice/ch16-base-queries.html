MCQs · Drill

MCQM11 mark

1. A query stores: (a) a second full copy of all data always (b) the question (fields, criteria) (c) a Writer template (d) an OS

Show Answer

Ans:

(b).

MCQM21 mark

2. Names starting with R use: (a) Like 'R*' (b) = R (c) Group (d) F11

Show Answer

Ans:

(a) Like 'R*'.

MCQM31 mark

3. Two criteria on the same row mean: (a) OR (b) AND (c) XOR (d) NOT a query

Show Answer

Ans:

(b) AND.

MCQM41 mark

4. To sort marks highest first: (a) Sort Ascending (b) Sort Descending on Marks (c) Primary key (d) Wrap Optimal

Show Answer

Ans:

(b).

MCQM51 mark

5. The most exam-ready way to revise “Queries in Base” is: (a) read the heading only (b) learn the key idea plus one example (c) skip written practice (d) memorise a random extra topic

(b) learn the key idea plus one example. The chapter is Design View queries, criteria, sorting, aliases and related-table queries..

MCQM61 mark

6. A 3-mark answer on “Queries in Base” should: (a) be one sentence (b) start with the idea, then a reason or method (c) copy the whole chapter (d) leave the example out

Show Answer

Ans:

(b) start with the idea, then a reason or method. Step marks follow that frame.

MCQM71 mark

7. To show only the students of Class 10 in a query you would: (a) type a criterion in the Class field (b) sort the Class field (c) rename the field (d) delete the other rows

Show Answer

Ans:

(a) type a criterion in the Class field. Criteria filter the records; sorting only reorders them.

MCQM81 mark

8. Sorting a query result in descending order arranges the values: (a) from largest to smallest (b) from A to Z (c) oldest first (d) in the order they were entered

Show Answer

Ans:

(a) from largest to smallest. For text, Z to A.

Written questions · Write

SHORTS12 marks

1. What is a query in Base?

Show Answer

Ans:

A saved question that selects fields from one or more tables according to criteria and sort order, without storing a second copy of the data.

SHORTS22 marks

2. Write criteria to list students whose names start with A and marks above 70.

Show Answer

Ans:

Put both criteria in the same criteria row: Name with Like 'A*' and Marks with >70. Criteria on the same row are joined by AND, so a student must satisfy both to appear; putting them on different rows would join them by OR and list every student who passes either test.

SHORTS32 marks

3. What is a query and why is it used?

Show Answer

Ans:

A query is a question put to the database. It selects the fields and records you need, filters them by conditions, sorts them and can calculate totals, so you can answer questions such as ‘which students scored above 90 in Science' without reading the whole table.

SHORTS42 marks

4. What is the difference between AND and OR in a query grid? Illustrate with one row each.

Show Answer

Ans:

AND — two criteria on the same grid row must both be true; for example, Class = 10 AND Marks > 75 lists only high-scoring Class 10 students.
OR — criteria on separate rows need only one to be true; for example, Class = 10 on one row and Class = 9 on the next lists both classes.

APPLICATIONA53 marks

5. The librarian wants unpaid fees greater than 500, sorted by fees high to low. Which grid settings?

Show Answer

Ans:

Field Fees, criterion >500, Sort Descending; include Name/AdmNo so the rows are identifiable.

APPLICATIONA63 marks

6. Riya is revising “Queries in Base” (Design View queries, criteria, sorting, aliases and related-table queries.). A classmate lost marks by doing this: Editing query results and expecting the table design to change. Apply the correct method and rewrite the scoring answer.

Show Answer

Ans:

Correct method: Text criteria need quotes in some modes; in the grid Delhi is often enough — follow what the lab build accepts.
Why the mistake costs marks: Editing query results and expecting the table design to change.
Write the definition or formula first, then the working or example.

SHORTS73 marks

7. Describe how to create a query with a condition in LibreOffice Base.

Show Answer

Ans:

Choose Queries, then Create Query in Design View, and add the table or tables you need.
Double-click each field you want to see, so that it appears in the grid below.
Type the condition in the Criterion row of the field you want to filter, for example >90, and set Ascending or Descending in the Sort row.
Run the query to check the result, then save it with a clear name; it can be re-run any time the data changes.

SHORTS83 marks

8. What is an alias in a query? Give one example where renaming a field improves a report.

Show Answer

Ans:

An alias is a display name given to a field in a query (Field AS Alias) without changing the stored data.
Example — a report column headed ‘M’ confuses readers; aliasing it as ‘Marks’ makes the printed report self-explanatory while the table field stays M.

LONGL94 marks

9. How do you create a query that shows student name and book title for issues after 1 Apr 2026?

Show Answer

Ans:

Design View → add Student, Issue, Book (related) → fields Name, Title, IssueDate → criterion on IssueDate > {d '2026-04-01'} or the date the lab uses → Run → Save.

COMPETENCYC104 marks

10. Read and answer: A query saved last month still shows old marks after the teacher updates the table. (a) Is that expected? (b) Why? (c) When would you use a Wizard instead of Design View?

Show Answer

Ans:

(a) No — a select query should show current table data when run again.
(b) Queries read tables live; if it does not update, they opened an old copy or a static export.
(c) Wizard for a simple one-table list; Design View when you need criteria, sorts and two tables.

COMPETENCYC114 marks

11. Read and answer: A Class 10 student is preparing “Queries in Base”. Their note says: Query = a saved question: which fields, from which tables, matching which criteria, in which order. The chapter is described as: Design View queries, criteria, sorting, aliases and related-table queries.. (a) Name the key idea. (b) How is this usually asked in the paper? (c) State one mistake that would cost a mark.

Show Answer

Ans:

(a) Design View queries, criteria, sorting, aliases and related-table queries.
(b) Practical: query with two criteria and a sort.
(c) Editing query results and expecting the table design to change.

LONGL125 marks

12. Discuss “Queries in Base” in detail. Include the idea that carries marks, one worked example or answer frame, and why students lose marks.

Show Answer

Ans:

Query = a saved question: which fields, from which tables, matching which criteria, in which order.
Marks lens: Practical: query with two criteria and a sort.
Method / memory trick: Text criteria need quotes in some modes; in the grid Delhi is often enough — follow what the lab build accepts.
Do not: Editing query results and expecting the table design to change.
