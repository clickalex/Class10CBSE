Information Technology — Quick revision

One screen per chapter: formulas and the points that actually get asked. Expand what you need, skip what you know.

Ch 1 Communication Skills–II

Formulas

  • 7 Cs: Clear · Concise · Concrete · Correct · Coherent · Complete · Courteous
  • Methods: verbal (oral + written), non-verbal, visual.
  • Cycle: Sender → Encoding → Message → Channel → Decoding → Receiver → Feedback.
  • 7 Cs: Clear Concise Concrete Correct Coherent Complete Courteous.
  • Good feedback: descriptive, specific, timely, constructive.
Ch 2 Self-Management Skills–II
  • Self-management = control of emotion + behaviour toward a goal.
  • Eustress helps; distress harms.
  • SMART: Specific Measurable Achievable Realistic Time-bound.
  • Time: list → prioritise → one chunk → review.
Ch 3 ICT Skills–II
  • OS manages hardware and programs.
  • File = data; folder = container.
  • Care: dust, no food, surge protector, shutdown, antivirus, backup.
Ch 4 Entrepreneurial Skills–II
  • Entrepreneur = opportunity + risk + resources + value.
  • Qualities: initiative, risk-taking, creativity, perseverance, confidence.
  • Myths: born-not-made, needs huge money, only for the highly educated.
  • Society: jobs, products, local resources, problem-solving.
Ch 5 Green Skills–II
  • Sustainable development = present + future.
  • Green economy: low carbon, resource-efficient, inclusive.
  • 3 Rs: Reduce, Reuse, Recycle.
  • Green jobs: solar, waste, organic farming, green buildings.
Ch 6 Introduction to Styles (Writer)
  • Style = named formatting.
  • Six types: Paragraph, Character, Page, Frame, List, Table.
  • F11, Fill Format, Update Style, New, Load Styles.
  • Headings → ToC.
Ch 7 Working with Images (Writer)
  • Insert → Image; crop/resize with ratio locked.
  • Wrap: Optimal for body text.
  • Anchor: usually To Paragraph.
  • Caption + Group drawing objects.
Ch 8 ToC, Templates and Track Changes
  • ToC from Heading 1/2/3; Update Index.
  • Template = .ott with styles.
  • Track Changes: Record, Accept, Reject; Comments for notes.
  • Mail merge = letter + data source + fields.
Ch 9 Scenarios and Goal Seek (Calc)

Formulas

  • Profit = Revenue − Cost
  • Goal Seek: set formula cell → target value → change input cell
  • Consolidate sheets; Subtotals after sort; Group to hide detail.
  • Scenario = named inputs.
  • Goal Seek: know result, find input.
  • Solver: many variables + constraints.
Ch 10 Macros in Spreadsheet
  • Macro = recorded commands.
  • Tools → Macros → Record / Run.
  • Name it; save in the document.
  • Security High/Medium; never unknown files.
Ch 11 Linking Spreadsheet Data

Formulas

  • =Sheet2.A1
  • ='Marks Term1'.C5
  • HYPERLINK("https://cbseacademic.nic.in")
  • =Sheet2.A1 and 'Name with space'.A1.
  • Hyperlink: web, file, email, internal target.
  • Paste Special → Link for live copies.
  • Keep linked files in one folder.
Ch 12 Share and Review a Spreadsheet
  • Tools → Share Spreadsheet.
  • Record / Show / Accept / Reject changes.
  • Insert → Comment.
  • Protect Sheet; unlock inputs first.
  • Compare and merge copies.
Ch 13 Introduction to DBMS
  • Data raw; information processed.
  • Database + DBMS (Base).
  • Field, record, table.
  • Primary key unique; foreign key links tables.
  • DBMS: less redundancy, security, backup, sharing.
Ch 14 Tables in LibreOffice Base
  • Design View: fields + types + PK.
  • Text for codes/phones; Date for dates; Decimal for money.
  • Required / Length / Default.
  • Datasheet = records; Design = structure.
Ch 15 Relationships and Multiple Tables
  • Split data: one fact, one table.
  • 1:1, 1:n, n:n (junction).
  • FK on the many side, same type as PK.
  • Referential integrity = no orphans.
Ch 16 Queries in Base

Formulas

  • Marks >= 80
  • City = 'Delhi'
  • Name Like 'S*'
  • Fees BETWEEN 1000 AND 2000
  • Query = live question, not a second database.
  • Design View: tables → fields → criterion → sort → Run.
  • Same row AND; extra row OR.
  • Like 'A*', >75, dates, BETWEEN.
Ch 17 Forms and Reports
  • Form = input UI; Report = printout.
  • Wizards are allowed; name frm / rpt.
  • Report from a query for filters and sorts.
  • Grouping and totals belong on reports.
Ch 18 Health, Safety and Security at the Workplace
  • Hazard = potential; accident = event; risk = chance.
  • Types: physical, electrical, chemical, biological, ergonomic, psychosocial.
  • Electrical: dry, earthed, no overload; never water on electrical fire.
  • Security: locks, passwords, authorised access, backup.
Ch 19 Workplace Quality and Ergonomics
  • Quality = accurate, complete, on time, checked.
  • 5S: Sort, Set in order, Shine, Standardise, Sustain.
  • Ergonomics: 90° elbows/knees, screen eye-level, arm’s length.
  • 20-20-20 for eyes.
Ch 20 Prevent Accidents and Emergencies
  • Accidents = unsafe act + unsafe condition; prevent both.
  • Evacuation: alarm, stairs, assembly, headcount.
  • Shock: power off, then help. Burns: water, not toothpaste.
  • Report incidents and near-misses. Emergency 112.
