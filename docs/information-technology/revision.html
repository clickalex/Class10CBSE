Information Technology — Quick revision

One screen per chapter: formulas and the points that actually get asked. Expand what you need, skip what you know.

Ch 1 Communication Skills–II

Formulas

  • 7 Cs: Clear · Concise · Concrete · Correct · Coherent · Complete · Courteous
  • Methods: verbal (oral + written), non-verbal, visual.
  • Cycle: Sender → Encoding → Message → Channel → Decoding → Receiver → Feedback.
  • 7 Cs: Clear Concise Concrete Correct Coherent Complete Courteous.
  • Good feedback: descriptive, specific, timely, constructive.
Ch 2 Self-Management Skills–II

Formulas

  • SMART goal: Specific · Measurable · Achievable · Relevant · Time-bound
  • Time-management matrix: urgent + important = do now; not urgent + important = schedule; urgent + not important = delegate; neither = drop
  • Stress cycle: trigger → thought → feeling → behaviour → relief or regret
  • Self-management = self-awareness + self-regulation + self-motivation
  • Self-management = control of emotion + behaviour toward a goal.
  • Eustress helps; distress harms.
  • SMART: Specific Measurable Achievable Realistic Time-bound.
  • Time: list → prioritise → one chunk → review.
Ch 3 ICT Skills–II

Formulas

  • Ctrl + C copy · Ctrl + X cut · Ctrl + V paste · Ctrl + Z undo · Ctrl + Y redo
  • Ctrl + S save · Ctrl + P print · Ctrl + F find · Ctrl + A select all
  • File extensions: .odt Writer, .ods Calc, .odp Impress, .odb Base, .pdf portable document
  • 1 byte = 8 bits · 1 KB = 1024 B · 1 MB = 1024 KB · 1 GB = 1024 MB
  • OS manages hardware and programs.
  • File = data; folder = container.
  • Care: dust, no food, surge protector, shutdown, antivirus, backup.
Ch 4 Entrepreneurial Skills–II

Formulas

  • Marketing mix — the 4 Ps: Product, Price, Place, Promotion
  • SWOT: Strengths, Weaknesses (internal) · Opportunities, Threats (external)
  • Profit = Total revenue − Total cost; Break-even = Fixed cost ÷ (Price − Variable cost per unit)
  • A business plan names: the idea, the customer, the money needed, and how it will be earned back
  • Entrepreneur = opportunity + risk + resources + value.
  • Qualities: initiative, risk-taking, creativity, perseverance, confidence.
  • Myths: born-not-made, needs huge money, only for the highly educated.
  • Society: jobs, products, local resources, problem-solving.
Ch 5 Green Skills–II

Formulas

  • The 5 Rs in order: Refuse → Reduce → Reuse → Repurpose → Recycle
  • Carbon footprint = the greenhouse gases one person or activity adds to the air
  • E-waste: any discarded device with a plug, battery or chip — never in the household bin
  • Energy saved at the plug is energy never generated — the greenest unit is the one not used
  • Sustainable development = present + future.
  • Green economy: low carbon, resource-efficient, inclusive.
  • 3 Rs: Reduce, Reuse, Recycle.
  • Green jobs: solar, waste, organic farming, green buildings.
Ch 6 Introduction to Styles (Writer)

Formulas

  • Style hierarchy: Heading 1 → Heading 2 → Heading 3 → Body Text
  • F11 opens the Styles and Formatting window
  • Modify a style once → every paragraph using it changes
  • A style carries font, size, colour, alignment, spacing and outline level together
  • Style = named formatting.
  • Six types: Paragraph, Character, Page, Frame, List, Table.
  • F11, Fill Format, Update Style, New, Load Styles.
  • Headings → ToC.
Ch 7 Working with Images (Writer)

Formulas

  • Anchor as character = the picture moves with the text; anchor to page/paragraph = it stays put
  • Wrap options: None · Before/After · Page · Optimal · Through · In background
  • Crop trims the picture; the original file on disk stays unchanged until you compress it
  • Keep the aspect ratio locked while resizing, or the picture looks stretched
  • Insert → Image; crop/resize with ratio locked.
  • Wrap: Optimal for body text.
  • Anchor: usually To Paragraph.
  • Caption + Group drawing objects.
Ch 8 ToC, Templates and Track Changes

Formulas

  • A table of contents is generated from heading styles — plain bold text will not appear in it
  • Update a ToC: right-click → Update Index/Table (F9 in some builds)
  • Template: .ott — a document that carries styles and layout but not your content
  • Track Changes shows edits; Comments hold questions; Accept/Reject closes them
  • ToC from Heading 1/2/3; Update Index.
  • Template = .ott with styles.
  • Track Changes: Record, Accept, Reject; Comments for notes.
  • Mail merge = letter + data source + fields.
Ch 9 Scenarios and Goal Seek (Calc)

Formulas

  • Profit = Revenue − Cost
  • Goal Seek: set formula cell → target value → change input cell
  • Consolidate sheets; Subtotals after sort; Group to hide detail.
  • Scenario = named inputs.
  • Goal Seek: know result, find input.
  • Solver: many variables + constraints.
Ch 10 Macros in Spreadsheet

Formulas

  • A macro is a recorded sequence of actions you can replay with one key press
  • Record: Tools → Macros → Record Macro; Stop: click Stop Recording
  • Macros are stored per document or in My Macros for use everywhere
  • Only record what you would do by hand — the recorder copies menu clicks, not intentions
  • Macro = recorded commands.
  • Tools → Macros → Record / Run.
  • Name it; save in the document.
  • Security High/Medium; never unknown files.
Ch 11 Linking Spreadsheet Data

Formulas

  • =Sheet2.A1
  • ='Marks Term1'.C5
  • HYPERLINK("https://cbseacademic.nic.in")
  • =Sheet2.A1 and 'Name with space'.A1.
  • Hyperlink: web, file, email, internal target.
  • Paste Special → Link for live copies.
  • Keep linked files in one folder.
Ch 12 Share and Review a Spreadsheet

Formulas

  • Sharing modes: share the file, or share the spreadsheet so several people edit at once
  • Protect Sheet / Protect Document stops accidental edits; a password is optional
  • Record Changes keeps a history of who changed what and when
  • Comments raise questions without touching the cell values
  • Tools → Share Spreadsheet.
  • Record / Show / Accept / Reject changes.
  • Insert → Comment.
  • Protect Sheet; unlock inputs first.
  • Compare and merge copies.
Ch 13 Introduction to DBMS

Formulas

  • Data → Information → Knowledge: raw facts, facts with meaning, meaning applied
  • Table = rows (records) + columns (fields); a primary key makes each row unique
  • DBMS advantages: no duplication, shared access, security, backup, integrity
  • RDBMS: data in related tables; a foreign key links a row to its parent table
  • Data raw; information processed.
  • Database + DBMS (Base).
  • Field, record, table.
  • Primary key unique; foreign key links tables.
  • DBMS: less redundancy, security, backup, sharing.
Ch 14 Tables in LibreOffice Base

Formulas

  • Common Base types: Text (VARCHAR), Integer, Number/Decimal, Date, Time, Boolean (Yes/No)
  • Primary key: unique and never empty — often an auto-incrementing ID
  • Design View: you define fields and types; Data View: you type the rows
  • Field properties: size, format, default value, and 'required' — set them before entering data
  • Design View: fields + types + PK.
  • Text for codes/phones; Date for dates; Decimal for money.
  • Required / Length / Default.
  • Datasheet = records; Design = structure.
Ch 15 Relationships and Multiple Tables

Formulas

  • One-to-many: one class has many students — the most common relationship
  • One-to-one: one student has one locker record; Many-to-many needs a junction table
  • Referential integrity: a child row cannot point to a parent that does not exist
  • Cascade update/delete keeps child rows in step when the parent changes
  • Split data: one fact, one table.
  • 1:1, 1:n, n:n (junction).
  • FK on the many side, same type as PK.
  • Referential integrity = no orphans.
Ch 16 Queries in Base

Formulas

  • Marks >= 80
  • City = 'Delhi'
  • Name Like 'S*'
  • Fees BETWEEN 1000 AND 2000
  • Query = live question, not a second database.
  • Design View: tables → fields → criterion → sort → Run.
  • Same row AND; extra row OR.
  • Like 'A*', >75, dates, BETWEEN.
Ch 17 Forms and Reports

Formulas

  • A form is for entering and editing one record at a time; a table is for seeing many
  • A report groups and totals data for printing; it is not for editing
  • Form/Report Wizard: pick the table or query → pick the fields → pick the layout → finish
  • Reports can sort and group, add totals, and carry a header and footer
  • Form = input UI; Report = printout.
  • Wizards are allowed; name frm / rpt.
  • Report from a query for filters and sorts.
  • Grouping and totals belong on reports.
Ch 18 Health, Safety and Security at the Workplace

Formulas

  • Hazard = something that can hurt; Risk = how likely and how badly
  • PPE: Personal Protective Equipment — gloves, goggles, masks, ear plugs, safety shoes
  • Safety sign colours: red prohibition/fire, yellow warning, blue mandatory, green emergency
  • Report every near-miss — a near-miss today is an accident tomorrow
  • Hazard = potential; accident = event; risk = chance.
  • Types: physical, electrical, chemical, biological, ergonomic, psychosocial.
  • Electrical: dry, earthed, no overload; never water on electrical fire.
  • Security: locks, passwords, authorised access, backup.
Ch 19 Workplace Quality and Ergonomics

Formulas

  • 5S: Sort, Set in order, Shine, Standardise, Sustain
  • Ergonomics = fitting the work to the person, not the person to the work
  • Screen: arm's length away, top of the screen at or just below eye level
  • Quality = doing it right the first time; KAIZEN = small improvements, every day
  • Quality = accurate, complete, on time, checked.
  • 5S: Sort, Set in order, Shine, Standardise, Sustain.
  • Ergonomics: 90° elbows/knees, screen eye-level, arm’s length.
  • 20-20-20 for eyes.
Ch 20 Prevent Accidents and Emergencies

Formulas

  • Fire: Rescue → Alarm → Contain → Extinguish/Evacuate (RACE)
  • Emergency numbers in India: 112 (all-in-one), 101 fire, 102 ambulance, 100 police
  • First aid for burns: cool running water for 10 minutes — no ice, no ointment, no cotton
  • Never use water on an electrical fire — cut the supply and use a CO₂ or dry-powder extinguisher
  • Accidents = unsafe act + unsafe condition; prevent both.
  • Evacuation: alarm, stairs, assembly, headcount.
  • Shock: power off, then help. Burns: water, not toothpaste.
  • Report incidents and near-misses. Emergency 112.
