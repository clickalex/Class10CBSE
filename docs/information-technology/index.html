Assessment at a glance

ComponentMarksPreparation
Theory — Section A objective + Section B subjective**50**Menu paths, definitions, steps and safety reasoning.
Practical exam — Writer 5 + Calc 5 + Base 10 + Viva 10**30**Repeat the 15 file tasks until the clicks are automatic.
Project work / field visit**10**An interdisciplinary case study.
Portfolio / practical file — min. 5 problems each in Writer, Calc and Base**10**Printouts with the problem statement at the top.
Total100Theory 2 hours; practical as scheduled by the school.

Topper’s study order

  1. Unit 3 DBMS first (12 marks) — tables, relationships, queries.
  2. Unit 2 Calc on a computer (10) — Goal Seek and scenarios.
  3. Unit 4 Safety (10) — lists plus examples, fastest theory.
  4. Unit 1 Writer (8) — styles, ToC, mail merge.
  5. Part A (10) — communication 7 Cs, SMART goals, green skills.
  6. Then a timed sample paper, the practical file and a viva drill.

Practical is usually before theory, January–February. Confirm with your school. Target February–March 2027 boards.
