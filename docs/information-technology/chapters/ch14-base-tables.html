Chapter 14 · Tables in LibreOffice Base

Chapter 14 of 20. The practical starts here. Design View + data types + PK is the 10-mark Base task.

Open this chapter’s questions + MCQs →Mock-test this chapter (timed, scored) →

🎯 Marks lens 📖 Deep concepts 🧮 Formulas 🛠️ Steps 🧠 Tricks ⚠️ Mistakes ❓ Exam Q&A ✍️ Task

🎯 Marks lens

Create a table with four fields, correct types, PK set.
Field properties: Required, Length, Default, Format.

📖 Deep concepts

1. Ways to create a table: Design View (exam method), Wizard, View/SQL. Use Design View.
2. Data types: Text [VARCHAR], Integer, Numeric/Decimal, Date, Time, DateTime, Yes/No, Memo (long text), Image (rarely).
3. Set primary key: right-click the field → Primary Key (key icon). Save the table (Student).
4. Field properties: Entry required (Yes), Length (25), Default value, Format example, AutoValue for integer PKs.
5. Datasheet view is for typing records; Design View is for structure. Do not confuse them.
6. Save before closing. Base will not keep an unsaved table design.
7. Good design: one fact per field (separate FirstName, not a whole address in Name).

🧮 Formulas to memorise

  • Common Base types: Text (VARCHAR), Integer, Number/Decimal, Date, Time, Boolean (Yes/No)
  • Primary key: unique and never empty — often an auto-incrementing ID
  • Design View: you define fields and types; Data View: you type the rows
  • Field properties: size, format, default value, and 'required' — set them before entering data

🛠️ Method, step by step

  1. Base → Create Table in Design View.
  2. Type field names and data types down the rows.
  3. Right-click AdmNo → Primary Key.
  4. Set Length / Required as asked.
  5. Save as Student, then open Datasheet to enter two sample rows.

🧠 Memory tricks

  • Phone numbers are Text, not Integer — or you lose leading 0.
  • Fees can be Decimal; age is Integer; DOB is Date.

⚠️ Mistakes that cost marks

  • Forgetting to set the primary key — Base warns, some students click No.
  • Using spaces in field names when the question gave RollNo.

SHORTS12 marks

1. Name four data types in Base and one use each.

Show Answer

Ans:

VARCHAR for names, Integer for roll number, Date for DOB, Decimal for fees, Yes/No for paid flag.

SHORTS22 marks

2. How do you set a primary key in Design View?

Show Answer

Ans:

Right-click the field row → Primary Key so the key icon appears, then save the table.

SHORTS32 marks

3. Describe how to create a table in LibreOffice Base.

Show Answer

Ans:

Open the database, choose Tables, then Create Table in Design View. For each field type the field name and choose a data type such as Text, Integer, Decimal or Date. Right-click the field you want as the primary key and choose Primary Key, then save the table with a clear name and close the design window.

SHORTS42 marks

4. What is the difference between Datasheet View and Design View in Base?

Show Answer

Ans:

Design View defines structure — field names, data types, lengths and the primary key. Datasheet View holds content — the actual records typed row by row. You build the table in Design View first, then enter data in Datasheet View; changing structure later can endanger existing records.

APPLICATIONA53 marks

5. A student stores mobile numbers as Integer and 098… becomes 98. Why, and what type should be used?

Show Answer

Ans:

Integer drops leading zeros and is not a “number you calculate with”. Use Text/VARCHAR.

APPLICATIONA63 marks

6. Riya is revising “Tables in LibreOffice Base” (Create tables in Design View, data types, primary key, field properties.). A classmate lost marks by doing this: Forgetting to set the primary key — Base warns, some students click No. Apply the correct method and rewrite the scoring answer.

Show Answer

Ans:

Correct method: Phone numbers are Text, not Integer — or you lose leading 0.
Why the mistake costs marks: Forgetting to set the primary key — Base warns, some students click No.
Write the definition or formula first, then the working or example.

SHORTS73 marks

7. Choose the data type for a name, a roll number, a date of birth and a fee amount, giving a reason for each.

Show Answer

Ans:

Name — Text (VARCHAR), because it contains letters and its length varies.
Roll number — Integer, so that records sort correctly and no space is wasted.
Date of birth — Date, so that the database can sort dates properly and calculate ages.
Fee amount — Decimal with two decimal places, so that money can be added up exactly.

SHORTS83 marks

8. What are the field properties ‘Required’, ‘Length’ and ‘Default’? Give one example of each.

Show Answer

Ans:

Required — the field cannot be left empty; for example, RollNo must always be filled.
Length — the maximum characters a text field holds; for example, Name limited to 40 characters.
Default — the value filled in automatically; for example, Class defaulting to ‘10’ for a Class 10 table.

LONGL94 marks

9. Write field names, types and keys for a table Book.

Show Answer

Ans:

ISBN VARCHAR PK; Title VARCHAR; Author VARCHAR; Price DECIMAL; Available YES/NO. ISBN uniquely identifies a book; Available is Boolean.

COMPETENCYC104 marks

10. Read and answer: Table Marks has fields Name, Marks, Marks, Date. (a) Three design faults. (b) Redesign with types and a PK. (c) Which view to use in the practical.

Show Answer

Ans:

(a) Duplicate field name; no PK; Name is a weak key; Date of what?
(b) StudentID INTEGER PK; Name VARCHAR; Marks INTEGER; ExamDate DATE.
(c) Design View to build, Datasheet to enter records.
