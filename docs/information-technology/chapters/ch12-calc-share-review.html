Chapter 12 · Share and Review a Spreadsheet

Chapter 12 of 20. The collaboration half of Calc — same idea as Track Changes in Writer.

Open this chapter’s questions + MCQs →

🎯 Marks lens 📖 Deep concepts 🧠 Tricks ⚠️ Mistakes ❓ Exam Q&A ✍️ Task

🎯 Marks lens

Share spreadsheet + record changes is the pair.
Know: comments, compare documents, merge.

📖 Deep concepts

1. Share spreadsheet: Tools → Share Spreadsheet. Several people can open it (on a network). Conflicts are resolved when saving.
2. Record changes: Edit → Track Changes → Record (wording may be Record Changes). Shows who changed which cell.
3. Show changes: Edit → Track Changes → Show. Accept or reject like Writer.
4. Comments on cells: Insert → Comment. A small triangle marks the cell. Use for “please check this total”, not for storing the answer itself.
5. Compare documents: Edit → Track Changes → Compare Document — against an older copy to see differences.
6. Merge: bring another user’s copy back into the shared original.
7. Protect sheet: Tools → Protect Sheet so others can edit only unlocked input cells.

🧠 Memory tricks

  • Sharing is for one file, many users; emailing five copies is how totals diverge.
  • Unlock input cells before protecting the sheet.

⚠️ Mistakes that cost marks

  • Protecting the sheet with no password written in the practical file — you cannot demo it.
  • Recording changes after the work is already done.

SHORTS12 marks

1. How do you share a Calc spreadsheet?

Show Answer

Ans:

Tools → Share Spreadsheet → enable sharing. Save on a network location the team can open.

SHORTS22 marks

2. Why add a comment to a cell instead of changing the value?

Show Answer

Ans:

A comment suggests or questions without overwriting data; the original number stays until someone decides.

LONGL34 marks

3. Explain recording, showing and accepting changes in Calc.

Show Answer

Ans:

Turn Record on before editing. Each changed cell is marked. Show lists author, date and old/new value. Accept keeps the new value; Reject restores the old. Compare Document does this against a saved copy.

APPLICATIONA43 marks

4. Three lab partners type in three copies of stock.ods and the totals disagree. What should they have used?

Show Answer

Ans:

One shared spreadsheet (or one file with Record Changes + merge), not three independent copies.

COMPETENCYC54 marks

5. Read and answer: A teacher wants students to fill only column B, not the formulas in C. (a) Which tool? (b) Steps. (c) How can the teacher see who changed B5?

Show Answer

Ans:

(a) Protect Sheet (unlock B first).
(b) Select B → unprotect cells; Tools → Protect Sheet; set password.
(c) Record / Show Changes — author and date on B5.

LONGL65 marks

6. Discuss “Share and Review a Spreadsheet” in detail. Include the idea that carries marks, one worked example or answer frame, and why students lose marks.

Show Answer

Ans:

Share spreadsheet: Tools → Share Spreadsheet. Several people can open it (on a network). Conflicts are resolved when saving.
Marks lens: Share spreadsheet + record changes is the pair.
Method / memory trick: Sharing is for one file, many users; emailing five copies is how totals diverge.
Do not: Protecting the sheet with no password written in the practical file — you cannot demo it.

APPLICATIONA73 marks

A classmate lost marks by doing this: Protecting the sheet with no password written in the practical file — you cannot demo it. Apply the correct method and rewrite the scoring answer.

COMPETENCYC84 marks

8. Read and answer: A Class 10 student is preparing “Share and Review a Spreadsheet”. Their note says: Share spreadsheet: Tools → Share Spreadsheet. Several people can open it (on a network). Conflicts are resolved when saving. The chapter is described as: Sharing, recording changes, adding comments, comparing and merging sheets.. (a) Name the key idea. (b) How is this usually asked in the paper? (c) State one mistake that would cost a mark.

Show Answer

Ans:

(a) Sharing, recording changes, adding comments, comparing and merging sheets.
(b) Share spreadsheet + record changes is the pair.
(c) Protecting the sheet with no password written in the practical file — you cannot demo it.

SHORTS92 marks

9. What does recording changes do when a spreadsheet is shared?

Show Answer

Ans:

Edit → Track Changes → Record logs every edit with the author's name, the time and the old value. Each change can then be reviewed, accepted or rejected from Edit → Track Changes → Manage, so a team can work on one file without losing track of who changed what.

SHORTS103 marks

10. How do you compare two versions of a document in LibreOffice?

Show Answer

Ans:

Open the newer copy and choose Edit → Track Changes → Compare Document.
Select the older copy in the file dialog and click Insert; LibreOffice shows the differences as tracked changes.
Review each one with Next and Previous, then accept or reject it from the Manage dialog.
This works in both Writer and Calc and is the safest way to merge two people's work.
