Chapter 8 · ToC, Templates and Track Changes

Chapter 8 of 20. The rest of Writer. ToC from Heading styles, a template .ott, and review tools.

Open this chapter’s questions + MCQs →Mock-test this chapter (timed, scored) →

🎯 Marks lens 📖 Deep concepts 🧮 Formulas 🛠️ Steps 🧠 Tricks ⚠️ Mistakes ❓ Exam Q&A ✍️ Task

🎯 Marks lens

ToC steps and Track Changes on/off are asked every year.
Mail merge: data source + main document + merge fields.

📖 Deep concepts

1. Table of Contents: apply Heading 1/2/3 → Insert → Table of Contents and Index → Table of Contents. Update with right-click → Update Index after edits.
2. Template (.ott): a starter document with styles, headers, logos. File → Templates → Save as Template. File → New → Templates to use it.
3. Track Changes: Edit → Track Changes → Record. Insertions show as underline, deletions as strike-out. Accept or Reject from the toolbar. Useful when two people edit one file.
4. Comments: Insert → Comment (Ctrl+Alt+C) for notes in the margin without changing the text.
5. Mail Merge: main letter + data source (Calc/Base/CSV) + merge fields (Name, Address) → Print or save letters. Steps: Tools → Mail Merge Wizard, or insert fields then File → Print → Mail Merge.
6. Advantages of mail merge: same letter to many people, no retyping, fewer spelling mistakes in names, labels and envelopes too.

🧮 Formulas to memorise

  • A table of contents is generated from heading styles — plain bold text will not appear in it
  • Update a ToC: right-click → Update Index/Table (F9 in some builds)
  • Template: .ott — a document that carries styles and layout but not your content
  • Track Changes shows edits; Comments hold questions; Accept/Reject closes them

🛠️ Method, step by step

Mail merge:

  1. Create the letter in Writer.
  2. Connect a data source (Calc sheet with Name, Address columns).
  3. Insert merge fields where the name/address should appear.
  4. Preview, then output to printer or separate files.

🧠 Memory tricks

  • Empty ToC ⇒ headings are not Heading styles.
  • Track Changes must be Record On before the other person edits, or you will see no markup.

⚠️ Mistakes that cost marks

  • Saving a template as .odt instead of .ott.
  • Typing names by hand in 50 letters instead of merge fields.

SHORTS12 marks

1. Write the steps to insert a Table of Contents in Writer.

Show Answer

Ans:

Apply Heading styles → Insert → Table of Contents and Index → Table of Contents → OK. Right-click → Update Index after changes.

SHORTS22 marks

2. What is a document template?

Show Answer

Ans:

A model file (.ott) that stores styles, headers and boilerplate so new documents start consistent.

SHORTS32 marks

3. How is a table of contents generated automatically in Writer?

Show Answer

Ans:

Apply the Heading 1, Heading 2 and Heading 3 styles to the headings, then choose Insert → Table of Contents and Index → Table of Contents, Index or Bibliography. Writer collects the styled headings with their page numbers; after further edits, refresh it with Tools → Update → Update All.

SHORTS42 marks

4. What is the difference between a template (.ott) and an ordinary Writer document (.odt)?

Show Answer

Ans:

A template is a reusable starting point: it stores styles, margins, headers and layout that every new document based on it inherits. An ordinary document stores one finished piece of work. Editing a template changes all future documents made from it; editing a document changes only that file.

APPLICATIONA53 marks

5. A teacher wants 40 identical permission letters with only the parent name changing. Which Writer feature, and what two files does she need?

Show Answer

Ans:

Mail merge. She needs the main letter and a data source (Calc column ParentName).

APPLICATIONA63 marks

6. Riya is revising “ToC, Templates and Track Changes” (Table of Contents, templates, track changes, comments and mail merge.). A classmate lost marks by doing this: Saving a template as .odt instead of .ott. Apply the correct method and rewrite the scoring answer.

Show Answer

Ans:

Correct method: Empty ToC ⇒ headings are not Heading styles.
Why the mistake costs marks: Saving a template as .odt instead of .ott.
Write the definition or formula first, then the working or example.

SHORTS73 marks

7. Explain what track changes and comments do, and when you would use each.

Show Answer

Ans:

Track Changes (Edit → Track Changes → Record) marks every insertion and deletion so that a reader can see exactly what has been altered and accept or reject each change from Edit → Track Changes → Manage.
Comments (Insert → Comment) let a reviewer write a note or a question beside the text without changing the text itself.
Use track changes when several people are editing one document, and comments when you want to suggest an idea or ask a question.

SHORTS83 marks

8. After adding two new chapters, a student's ToC shows stale page numbers. What is the exact fix, and why does the problem occur?

Show Answer

Ans:

Fix — right-click inside the Table of Contents and choose Update Index (or Update Index/Table), then update the whole table.
Cause — the ToC is a snapshot taken when it was inserted; Writer does not rebuild it automatically as pages shift.
Prevention — the new chapters must use Heading styles, not manual bold, or they will be missing from the rebuilt ToC as well.

LONGL94 marks

9. Explain mail merge and its advantages.

Show Answer

Ans:

Mail merge combines a main document with a data source to produce personalised letters. Advantages: speed, accuracy of names, one design for many copies, labels/envelopes.

COMPETENCYC104 marks

10. Read and answer: Two students edit report.odt. One deletes a paragraph; the other does not know what changed. (a) Which tool should have been on? (b) How do they accept only some edits? (c) When would a Comment be better than changing the text?

Show Answer

Ans:

(a) Track Changes → Record.
(b) Review each change → Accept or Reject.
(c) When suggesting, not rewriting — e.g. “please add the figure here”.
