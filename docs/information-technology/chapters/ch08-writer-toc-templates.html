🎯 Marks lens

ToC steps and Track Changes on/off are asked every year.
Mail merge: data source + main document + merge fields.

📖 Deep concepts

1. Table of Contents: apply Heading 1/2/3 → Insert → Table of Contents and Index → Table of Contents. Update with right-click → Update Index after edits.
2. Template (.ott): a starter document with styles, headers, logos. File → Templates → Save as Template. File → New → Templates to use it.
3. Track Changes: Edit → Track Changes → Record. Insertions show as underline, deletions as strike-out. Accept or Reject from the toolbar. Useful when two people edit one file.
4. Comments: Insert → Comment (Ctrl+Alt+C) for notes in the margin without changing the text.
5. Mail Merge: main letter + data source (Calc/Base/CSV) + merge fields (Name, Address) → Print or save letters. Steps: Tools → Mail Merge Wizard, or insert fields then File → Print → Mail Merge.
6. Advantages of mail merge: same letter to many people, no retyping, fewer spelling mistakes in names, labels and envelopes too.

🛠️ Method, step by step

Mail merge:

  1. Create the letter in Writer.
  2. Connect a data source (Calc sheet with Name, Address columns).
  3. Insert merge fields where the name/address should appear.
  4. Preview, then output to printer or separate files.

🧠 Memory tricks

  • Empty ToC ⇒ headings are not Heading styles.
  • Track Changes must be Record On before the other person edits, or you will see no markup.

⚠️ Mistakes that cost marks

  • Saving a template as .odt instead of .ott.
  • Typing names by hand in 50 letters instead of merge fields.

1. Write the steps to insert a Table of Contents in Writer.

Show Answer

Ans:

Apply Heading styles → Insert → Table of Contents and Index → Table of Contents → OK. Right-click → Update Index after changes.

SHORTS22 marks

2. What is a document template?

Show Answer

Ans:

A model file (.ott) that stores styles, headers and boilerplate so new documents start consistent.

LONGL34 marks

3. Explain mail merge and its advantages.

Show Answer

Ans:

Mail merge combines a main document with a data source to produce personalised letters. Advantages: speed, accuracy of names, one design for many copies, labels/envelopes.

APPLICATIONA43 marks

4. A teacher wants 40 identical permission letters with only the parent name changing. Which Writer feature, and what two files does she need?

Show Answer

Ans:

Mail merge. She needs the main letter and a data source (Calc column ParentName).

COMPETENCYC54 marks

5. Read and answer: Two students edit report.odt. One deletes a paragraph; the other does not know what changed. (a) Which tool should have been on? (b) How do they accept only some edits? (c) When would a Comment be better than changing the text?

Show Answer

Ans:

(a) Track Changes → Record.
(b) Review each change → Accept or Reject.
(c) When suggesting, not rewriting — e.g. “please add the figure here”.
