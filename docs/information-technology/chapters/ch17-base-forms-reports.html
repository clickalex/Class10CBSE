Chapter 17 · Forms and Reports

Chapter 17 of 20. Form = type data; Report = print data. Wizards are allowed; know what each control is.

🎯 Marks lens

Practical often: form on Student + report from a query.
Theory: difference between form and report; one advantage each.

📖 Deep concepts

1. Form: on-screen layout for entering and editing records, one at a time, with labels and controls. Safer than raw datasheet (validation, no extra columns).
2. Create: Forms → Use Wizard to Create Form → pick fields → arrange (columnar) → set subform if needed → name frmStudent.
3. Controls: text box, list box, check box, label, button. Label is the caption; the text box is bound to a field.
4. Report: formatted output for printing / PDF — headers, grouping, totals. Built from a table or (better) a query.
5. Create: Reports → Wizard → fields → grouping (e.g. by Class) → sort → layout → name rptFees.
6. Why a query under a report: filter first (only unpaid fees), then print. Changing the query criteria changes the report next time you open it.
7. Form vs report: form is interactive input; report is read-only output.

🛠️ Method, step by step

Form wizard: select table → fields → display (columnar) → data-entry only if asked → finish.
Report wizard: select query → fields → group by Class → sort Name → add sum of Fees if asked → finish.

🧠 Memory tricks

  • If the report is empty, the query returned zero rows — fix criteria first.
  • Name forms frm… and reports rpt… so the examiner finds them.

⚠️ Mistakes that cost marks

  • Building a report on the whole table when the question said “students with marks > 80”.
  • Using a form to print 200 rows — that is a report’s job.

SHORTS12 marks

1. Differentiate a form and a report.

Show Answer

Ans:

A form is for entering/editing records on screen. A report is a formatted, usually read-only printout or PDF of selected data.

SHORTS22 marks

2. Why create a report from a query rather than from a whole table?

Show Answer

Ans:

The query filters and sorts first (e.g. only unpaid fees), so the report prints exactly the needed rows.

LONGL34 marks

3. Write steps to create a data-entry form for the Student table in Base.

Show Answer

Ans:

Forms → Use Wizard → table Student → select fields → choose layout (columnar) → set to display all data / data entry → style → name frmStudent → finish. Test by adding one record.

APPLICATIONA43 marks

4. The office wants a printed list of Class 10 students owing more than ₹500, grouped by section. Form or report? What sits underneath?

Show Answer

Ans:

A report. Underneath: a query with Class=10, Fees>500, then group by section in the report wizard.

COMPETENCYC54 marks

5. Read and answer: Data-entry staff keep typing in Datasheet and accidentally delete a column. (a) Which object reduces that risk? (b) Two reasons. (c) How should monthly printouts be produced?

Show Answer

Ans:

(a) A form with only the needed controls.
(b) No access to Design View; labels guide the operator; validation.
(c) A report (from a query), not a screenshot of the datasheet.
