🎯 Marks lens

10 marks with the rest of Unit 4. Hazard types + two precautions each.
Data security is part of this unit in the current curriculum — passwords, backups, authorised access.

📖 Deep concepts

1. Hazard = anything that can cause harm. Risk = chance that the harm will occur.
2. Types of hazard: physical (cables, noise, fire), electrical, chemical (cleaner fumes), biological, ergonomic (bad chair), psychosocial (stress, bullying).
3. Occupational health: physical and mental wellbeing at work. Fatigue, eye strain and RSI are IT-lab issues.
4. Electrical safety: no overloaded sockets, no frayed wires, dry hands, don’t open the SMPS, use earthed plugs, UPS/surge protector.
5. Fire: know exits, don’t block them, switch off power, use the correct extinguisher (CO2 / dry powder on electrical — not water).
6. Security: lock the lab, visitor register, don’t share passwords, lock the screen, authorised software only, backup.
7. Policy / responsibility: follow school/lab rules, report hazards, use equipment as trained. Employers provide a safe workplace; employees cooperate.

🧠 Memory tricks

  • Water on an electrical fire is the classic wrong answer.
  • Hazard vs accident: hazard is the potential; accident is the event.

⚠️ Mistakes that cost marks

  • Writing “be careful” with no concrete precaution.
  • Mixing this unit with the old “Web Applications and Security” syllabus.

SHORTS12 marks

1. Differentiate a hazard and an accident with an IT-lab example.

Show Answer

Ans:

A hazard is a potential source of harm (a loose cable across the aisle). An accident is the event (a student trips and the monitor falls).

SHORTS22 marks

2. List four electrical safety rules for a computer lab.

Show Answer

Ans:

Dry hands; earthed plugs; no overloaded boards; don’t open the power supply; report frayed wires; use a surge protector.

LONGL34 marks

3. Explain four types of workplace hazard with one IT-lab example each.

Show Answer

Ans:

Physical — trailing cables; electrical — open socket; ergonomic — low screen causing neck pain; psychosocial — long hours without a break. Control each: cable covers, close sockets, raise the monitor, timetable breaks.

APPLICATIONA43 marks

4. A student pours water on a sparking socket. Two mistakes and the correct actions.

Show Answer

Ans:

Water on electrical fire; staying next to a live spark. Instead: don’t touch, switch off mains if safe, alert staff, use CO2/powder extinguisher, evacuate.

COMPETENCYC54 marks

5. Read and answer: Lab PCs face a window, chairs don’t adjust, passwords are on sticky notes. (a) Name three hazard/security issues. (b) One control for each. (c) Who should you report this to?

Show Answer

Ans:

(a) Glare (ergonomic), poor posture, password leak (security).
(b) Blinds/position screens, adjustable chairs, unique passwords stored in a password manager / teacher vault — never sticky notes.
(c) Lab teacher / system admin / safety in-charge.
