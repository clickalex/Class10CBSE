Chapter 7 · Working with Images (Writer)

Chapter 7 of 20. Practical-heavy. Wrap settings and grouping are the viva favourites.

Open this chapter’s questions + MCQs →Mock-test this chapter (timed, scored) →

🎯 Marks lens 📖 Deep concepts 🧮 Formulas 🛠️ Steps 🧠 Tricks ⚠️ Mistakes ❓ Exam Q&A ✍️ Task

🎯 Marks lens

Expect “how to wrap an image” and “difference between anchor types”.
File work: insert a picture, wrap Optimal, add a caption, group a callout.

📖 Deep concepts

1. Insert image: Insert → Image, or drag from a folder, or copy-paste. Keep a copy of the picture with the file if you must move the document.
2. Anchoring: To Paragraph (moves with that para), To Character, As Character (like a big letter in the line), To Page (stays on that page).
3. Text wrap: None, Before, After, Parallel, Optimal, Through, In Background. Optimal is the usual body-text wrap.
4. Arrangement: Bring to Front / Send to Back when images overlap.
5. Drawing toolbar: lines, arrows, rectangles, callouts, text boxes. Hold Shift for a circle/square.
6. Grouping: select several drawing objects (Shift-click) → right-click → Group. They move as one.
7. Crop, resize, rotate from the Image toolbar. Keep aspect ratio unless the question says otherwise.
8. Caption: right-click image → Insert Caption (Figure 1: …). Captions help a Table of Figures.

🧮 Formulas to memorise

  • Anchor as character = the picture moves with the text; anchor to page/paragraph = it stays put
  • Wrap options: None · Before/After · Page · Optimal · Through · In background
  • Crop trims the picture; the original file on disk stays unchanged until you compress it
  • Keep the aspect ratio locked while resizing, or the picture looks stretched

🛠️ Method, step by step

  1. Insert → Image → choose file.
  2. Click the image → Properties / Wrap → Optimal.
  3. Anchor To Paragraph.
  4. Right-click → Insert Caption.
  5. Add an arrow from Drawing; Shift-select + Group.

🧠 Memory tricks

  • If text jumps wildly, the image is probably As Character — change wrap and anchor.
  • Grouping works on drawing objects, not always on a mixed photo+shape until you convert/careful-select.

⚠️ Mistakes that cost marks

  • Stretching a photo so faces look wide — hold Shift or lock ratio.
  • Saving a document without the image folder when images were linked, not embedded.

SHORTS12 marks

1. Name any four text-wrapping options in Writer.

Show Answer

Ans:

Writer offers these wrap options: None, Before, After, Parallel, Optimal, Through and In Background (any four). Optimal is the default — text flows around the object; Through lets text pass over it; In Background turns the picture into a watermark that sits behind the text. Choose Optimal for a report and In Background for a letterhead logo.

SHORTS22 marks

2. What does grouping do?

Show Answer

Ans:

It joins selected drawing objects so they move, resize and copy as a single object.

SHORTS32 marks

3. What is text wrapping and when is it useful?

Show Answer

Ans:

Wrapping decides how text flows around a picture. It is useful when a small picture has to sit inside a paragraph: the text runs beside or around the image instead of leaving a large empty space above and below it, so the page looks filled and balanced.

SHORTS42 marks

4. What is an image caption, and why should figures be captioned and numbered in a report?

Show Answer

Ans:

A caption is a numbered label under an image, such as ‘Figure 3: School garden’. Captions let the text refer to figures precisely (‘see Figure 3’) instead of vaguely (‘the picture above’), and automatic numbering keeps the sequence correct when images are added or moved.

APPLICATIONA53 marks

5. An image covers the heading of a report. Which two settings would you change first?

Show Answer

Ans:

Wrap (Optimal or After) and arrangement (Send to Back) or move the anchor to the correct paragraph.

APPLICATIONA63 marks

6. Riya is revising “Working with Images (Writer)” (Insert, wrap, arrange, drawing objects, grouping and captions.). A classmate lost marks by doing this: Stretching a photo so faces look wide — hold Shift or lock ratio. Apply the correct method and rewrite the scoring answer.

Show Answer

Ans:

Correct method: If text jumps wildly, the image is probably As Character — change wrap and anchor.
Why the mistake costs marks: Stretching a photo so faces look wide — hold Shift or lock ratio.
Write the definition or formula first, then the working or example.

SHORTS73 marks

7. List the steps to insert an image and set its position in a Writer document.

Show Answer

Ans:

Click where the picture should go and choose Insert → Image, then select the file and click Open.
Right-click the picture, choose Wrap and pick the style you need — Optimal, Before, After or Through.
Use Format → Image → Properties to set the size, the position, the cropping and whether the image is anchored to the page, the paragraph or the character.
Drag the picture to its place and, if you have several drawing objects, select them and choose Format → Group so that they move together.

SHORTS83 marks

8. Distinguish between anchoring an image ‘To Paragraph’ and ‘As Character’, with one use-case each.

Show Answer

Ans:

To Paragraph — the image attaches to a paragraph and moves with it, while text wraps around freely; use it for a photo beside a paragraph of a report.
As Character — the image sits inside the text line like a big letter and moves with the words; use it for a small icon or symbol within a sentence.

LONGL94 marks

9. Explain anchoring of images in Writer.

Show Answer

Ans:

Anchor decides what the image sticks to: To Paragraph (moves with the para), To Character, As Character (in the text line), To Page (fixed on that page). Choose To Paragraph + Optimal wrap for reports.

COMPETENCYC104 marks

10. Read and answer: A student’s picture sits in a huge white box and the caption is not numbered. (a) Two likely causes. (b) Steps to insert a proper Figure caption. (c) Why captions help in a long file.

Show Answer

Ans:

(a) Wrap = None; image as a huge As-Character object; no Insert Caption used.
(b) Right-click → Insert Caption → category Figure → type the title.
(c) Auto numbering and a Table of Figures.

LONGL125 marks

12. Discuss “Working with Images (Writer)” in detail. Include the idea that carries marks, one worked example or answer frame, and why students lose marks.

Show Answer

Ans:
