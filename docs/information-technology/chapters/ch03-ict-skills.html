🎯 Marks lens

1 mark. Definitions and “which of the following” items.
Know OS functions, file vs folder, and three care tips.

📖 Deep concepts

1. ICT is Information and Communication Technology — hardware, software and networks used to create, store and share information.
2. Operating system (OS) is system software that manages hardware and lets you run programs. Examples: Windows, Linux, macOS, Android. Functions: start the computer, manage files, memory, devices and security, provide a user interface.
3. File = a named collection of data (report.odt). Folder = a container for files and other folders. Use short, meaningful names and extensions (.odt, .ods, .odb, .jpg).
4. Care of computer: keep it dust-free, don't eat or drink near it, use a surge protector, shut down properly, update antivirus, don't install unknown software, backup important files.
5. Maintenance: disk cleanup, defragment (HDD), update OS, scan for malware, keep vents clear so the machine does not overheat.

🧠 Memory tricks

  • File has an extension; a folder does not need one.
  • OS = the manager of the machine, not an application like Writer.

⚠️ Mistakes that cost marks

  • Calling Writer an operating system.
  • Saving everything on the Desktop with names like final2(1).odt.

1. What is an operating system? Give two examples.

Show Answer

SHORTS22 marks

2. Differentiate a file and a folder with one example each.

Show Answer

Ans:

A file stores data (marks.ods). A folder stores files and other folders (Class10/IT/).

APPLICATIONA33 marks

3. Amit eats chips over the keyboard and never shuts the PC down. List three risks and three care steps.

Show Answer

Ans:

Risks: crumbs jam keys, oil damage, overheating, data loss. Care: no food/drink, proper shutdown, dust-free vents, surge protector, backups.

COMPETENCYC44 marks

4. Read and answer: Meera’s project file vanished after a power cut. She had saved only on the Desktop as aaa.odt. (a) Two file-management mistakes. (b) Two care/maintenance steps that would have helped.

Show Answer

Ans:

(a) No backup; a meaningless file name; Desktop-only copy.
(b) Surge protector / UPS; Save As into a named folder; weekly backup on a pen drive or cloud.
