Chapter 10 · Macros in Spreadsheet

🎯 Marks lens

Steps to record and run a macro, plus one use-case (repeating a format or a formula block).
Security: enable macros only from trusted files.

📖 Deep concepts

1. A macro is a recorded sequence of commands. Play it back to repeat the work.
2. Record: Tools → Macros → Record Macro → do the steps → Stop Recording → name it → save in the document or My Macros.
3. Run: Tools → Macros → Run Macro → pick the name. Or assign it to a button / key.
4. Use as a function: some recorded macros can be called from a sheet; in Class 10 the expected skill is record-and-run, not writing BASIC by hand.
5. Good uses: apply a school marksheet format, insert a header, convert a column to uppercase, print settings.
6. Macro security: Tools → Options → Security → Macro Security. Very high / High / Medium / Low. Use Medium or High; never run macros from unknown people.

🛠️ Method, step by step

  1. Tools → Macros → Record Macro.
  2. Perform the actions (format, sort, formula).
  3. Stop Recording, give a name.
  4. Tools → Macros → Run Macro to test.
  5. Optional: assign to a toolbar button.

🧠 Memory tricks

  • Plan the clicks before you press Record — extra clicks get recorded too.
  • Save the file as .ods with macros enabled; some formats drop macros.

⚠️ Mistakes that cost marks

  • Recording a macro that depends on a specific cell when you needed a relative range.
  • Enabling macros on a downloaded file you do not trust.

Show Answer

Ans:

LONGL34 marks

3. Explain macro security levels and a safe practice for students.

Show Answer

Ans:

Very High / High / Medium / Low control whether unsigned macros run. Students should keep High or Medium, enable macros only on their own practical files, and never open a macro-enabled sheet from an unknown chat.
