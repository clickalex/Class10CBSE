Chapter 10 · Macros in Spreadsheet

Chapter 10 of 20. Recording a macro is a 5-mark practical if you can find the menu under Tools.

Open this chapter’s questions + MCQs →

🎯 Marks lens 📖 Deep concepts 🛠️ Steps 🧠 Tricks ⚠️ Mistakes ❓ Exam Q&A ✍️ Task

🎯 Marks lens

Steps to record and run a macro, plus one use-case (repeating a format or a formula block).
Security: enable macros only from trusted files.

📖 Deep concepts

1. A macro is a recorded sequence of commands. Play it back to repeat the work.
2. Record: Tools → Macros → Record Macro → do the steps → Stop Recording → name it → save in the document or My Macros.
3. Run: Tools → Macros → Run Macro → pick the name. Or assign it to a button / key.
4. Use as a function: some recorded macros can be called from a sheet; in Class 10 the expected skill is record-and-run, not writing BASIC by hand.
5. Good uses: apply a school marksheet format, insert a header, convert a column to uppercase, print settings.
6. Macro security: Tools → Options → Security → Macro Security. Very high / High / Medium / Low. Use Medium or High; never run macros from unknown people.

🛠️ Method, step by step

  1. Tools → Macros → Record Macro.
  2. Perform the actions (format, sort, formula).
  3. Stop Recording, give a name.
  4. Tools → Macros → Run Macro to test.
  5. Optional: assign to a toolbar button.

🧠 Memory tricks

  • Plan the clicks before you press Record — extra clicks get recorded too.
  • Save the file as .ods with macros enabled; some formats drop macros.

⚠️ Mistakes that cost marks

  • Recording a macro that depends on a specific cell when you needed a relative range.
  • Enabling macros on a downloaded file you do not trust.

SHORTS12 marks

1. What is a macro? Give one use in Calc.

Show Answer

Ans:

A saved list of commands that can be replayed. Use: apply the same marksheet formatting every term.

SHORTS22 marks

2. Write the menu path to record a macro in Calc.

Show Answer

Ans:

Tools → Macros → Record Macro, perform the steps, Stop Recording, name the macro.

SHORTS32 marks

3. What is a macro and why is it used?

Show Answer

Ans:

A macro is a recorded sequence of commands that can be replayed with one click or one shortcut. It saves time on work you repeat often — formatting a daily report, cleaning imported data, or applying the same page setup to many sheets — and removes the risk of forgetting a step.

APPLICATIONA43 marks

4. Every Monday you set print area A1:G40, landscape, header “Weekly Sales”. How does a macro help?

Show Answer

Ans:

Record those page-setup steps once. Each Monday, Run Macro — one click instead of eight menu steps, fewer missed settings.

APPLICATIONA53 marks

5. Riya is revising “Macros in Spreadsheet” (Record, run, and use macros as functions; when not to use them.). A classmate lost marks by doing this: Recording a macro that depends on a specific cell when you needed a relative range. Apply the correct method and rewrite the scoring answer.

Show Answer

Ans:

Correct method: Plan the clicks before you press Record — extra clicks get recorded too.
Why the mistake costs marks: Recording a macro that depends on a specific cell when you needed a relative range.
Write the definition or formula first, then the working or example.

SHORTS63 marks

6. When should you not use a macro? Give three situations.

Show Answer

Ans:

Do not record a macro for a task you will do only once; learning the steps takes longer than doing the job.
Avoid macros for work that changes each time and cannot be reduced to fixed steps.
Never open macros in a file from an unknown sender: macro viruses can damage files and spread to other documents.
Where a built-in formula, style or tool does the job, use it instead — it is easier for others to check.

LONGL74 marks

7. Explain macro security levels and a safe practice for students.

Show Answer

Ans:

Very High / High / Medium / Low control whether unsigned macros run. Students should keep High or Medium, enable macros only on their own practical files, and never open a macro-enabled sheet from an unknown chat.

COMPETENCYC84 marks

8. Read and answer: A classmate sends marks.ods that auto-runs a macro on open. (a) What should you do first? (b) When is a macro a good idea in your own file? (c) One limitation of recorded macros.

Show Answer

Ans:

(a) Do not enable macros until you trust the source; check Security level.
(b) When the same clicks are repeated often on your own data.
(c) They record extra clicks; they may break if the sheet layout changes.
