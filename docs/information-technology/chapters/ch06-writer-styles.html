Chapter 6 · Introduction to Styles (Writer)

Chapter 6 of 20. Styles are the backbone of Unit 1. Fill Format plus custom styles are the practical.

Open this chapter’s questions + MCQs →

🎯 Marks lens 📖 Deep concepts 🧮 Formulas 🛠️ Steps 🧠 Tricks ⚠️ Mistakes ❓ Exam Q&A ✍️ Task

🎯 Marks lens

Theory asks types of styles and why styles beat manual formatting.
Practical: apply Heading 1/2, create a custom style, use Fill Format.

📖 Deep concepts

1. A style is a named collection of formatting. Change the style once, every place it is used updates.
2. Six categories in Writer: Paragraph, Character, Page, Frame, List (Numbering), Table.
3. Styles window: Sidebar → Styles, or F11. Filter: All / Applied / Hierarchical / Custom.
4. Fill Format mode: click Fill Format, then click paragraphs to paint the same style quickly.
5. Updating a style: format one paragraph as you want → right-click the style → Update Style.
6. New style: right-click in Styles → New. Give a name, set font/indents/spacing, OK.
7. Load styles from another document or template: Styles menu → Load Styles (overwrite / page / numbering options).
8. Why styles: consistent look, faster ToC (Headings), smaller files than direct formatting, easy branding.

🧮 Formulas to memorise

  • Style hierarchy: Heading 1 → Heading 2 → Heading 3 → Body Text
  • F11 opens the Styles and Formatting window
  • Modify a style once → every paragraph using it changes
  • A style carries font, size, colour, alignment, spacing and outline level together

🛠️ Method, step by step

  1. Open Styles (F11).
  2. Choose the category (Paragraph for headings).
  3. Double-click Heading 1 on the title, Heading 2 on subheadings.
  4. To copy, click Fill Format and click each target paragraph.
  5. To customise, right-click → New / Modify.

🧠 Memory tricks

  • Headings must use Heading styles, not just Bold 16 pt — otherwise ToC will be empty.
  • Character styles change a few words inside a paragraph; paragraph styles change the whole para.

⚠️ Mistakes that cost marks

  • Building a ToC from manually bolded text.
  • Updating the wrong style and changing the whole document by accident.

SHORTS12 marks

1. What is a style in Writer? Name any four categories.

Show Answer

Ans:

A named set of formatting that can be reused. Categories: Paragraph, Character, Page, Frame, List, Table.

SHORTS22 marks

2. What is Fill Format mode?

Show Answer

Ans:

A Styles-window tool that copies the selected style onto each paragraph (or object) you click, like a format paintbrush.

SHORTS32 marks

3. Why are styles better than formatting each heading by hand?

Show Answer

Ans:

A style stores the whole set of formatting — font, size, spacing, alignment — in one named item. Change the style once and every paragraph using it changes, the document stays consistent, and headings styled with Heading 1, 2 and 3 can be collected automatically into a table of contents.

APPLICATIONA43 marks

4. A 20-page report uses Bold 16 pt for titles. The examiner wants Heading 1 in navy. What should the student do instead of selecting each title?

Show Answer

Ans:

Create or modify Heading 1 (navy, size, spacing), then Fill Format / select each title and apply Heading 1. Later, one modify updates all.

APPLICATIONA53 marks

5. Riya is revising “Introduction to Styles (Writer)” (Page, paragraph, character, frame, list and table styles in LibreOffice Writer.). A classmate lost marks by doing this: Building a ToC from manually bolded text. Apply the correct method and rewrite the scoring answer.

Show Answer

Ans:

Correct method: Headings must use Heading styles, not just Bold 16 pt — otherwise ToC will be empty.
Why the mistake costs marks: Building a ToC from manually bolded text.
Write the definition or formula first, then the working or example.

SHORTS63 marks

6. Describe how to create and then apply a paragraph style in LibreOffice Writer.

Show Answer

Ans:

Format one paragraph exactly as you want it, then open the Styles window with F11 and click the New Style from Selection button.
Give the style a name such as ‘MyBodyText' and click OK.
To apply it, click anywhere in the paragraph you want to change and double-click the style name under Paragraph Styles.
To change the whole document, right-click the style, choose Modify and set the font, size and spacing once.

LONGL74 marks

7. Why should a long report use styles instead of manual formatting?

Show Answer

Ans:

One change updates every heading; ToC can be generated; the look stays consistent; less chance of mixed fonts; templates become reusable.

COMPETENCYC84 marks

8. Read and answer: Neha’s ToC is empty even though titles look big and bold. (a) Why? (b) Steps to fix it. (c) How will this help next time she changes the colour of all headings?

Show Answer

Ans:

(a) Titles used direct formatting, not Heading styles.
(b) Apply Heading 1/2, then Insert → Table of Contents.
(c) Modify Heading 1 once — every heading and the ToC pick up the new colour.
