Chapter 13 · Introduction to DBMS

Chapter 13 of 20. Unit 3 is 12 marks — start here. Definitions are free marks if the wording is tight.

🎯 Marks lens 📖 Deep concepts 🧮 Formulas 🛠️ Steps 🧠 Tricks ⚠️ Mistakes ❓ Exam Q&A ✍️ Task

🎯 Marks lens

Data vs information, advantages of DBMS, primary key — the opening trio.
Know: field, record, table, database; flat vs relational.

📖 Deep concepts

1. Data are raw facts (Ravi, 78). Information is processed, useful data (“Ravi scored 78 in IT”).
2. A database is an organised collection of related data. A DBMS (LibreOffice Base, MySQL) is software to create and manage databases.
3. Advantages of DBMS: less redundancy, consistency, sharing, security, backup/recovery, data independence, concurrent use, integrity.
4. Disadvantages: cost, training, a single failure can block many users if not backed up.
5. Building blocks: Field (column, one attribute), Record (row), Table (entity), Database (set of tables).
6. Keys: Primary key uniquely identifies a record (AdmissionNo). Composite key uses two+ fields. Foreign key in another table points to a primary key (referential integrity).
7. Flat file = one table (Calc). Relational database = several related tables (Base) — this is what Unit 3 uses.
8. Data types (preview): Text (VARCHAR), Integer, Decimal, Date, Yes/No (Boolean), Memo.

🧮 Formulas to memorise

  • Data → Information → Knowledge: raw facts, facts with meaning, meaning applied
  • Table = rows (records) + columns (fields); a primary key makes each row unique
  • DBMS advantages: no duplication, shared access, security, backup, integrity
  • RDBMS: data in related tables; a foreign key links a row to its parent table

🛠️ Method, step by step

  1. Write down what you need to store and what you will ask of it later.
  2. Split it into tables, one subject per table (students, classes, marks).
  3. Choose a primary key for each table and give every column one data type.
  4. Draw the links between tables — that drawing is your database design.

🧠 Memory tricks

  • Primary key = unique + not empty. Roll number works; student name does not.
  • DBMS advantage answers: write four, each with a three-word explanation.

⚠️ Mistakes that cost marks

  • Calling Calc a DBMS. Calc is a spreadsheet; Base is the DBMS in this course.
  • Using Name as primary key.

SHORTS12 marks

1. Differentiate data and information with an example.

Show Answer

Ans:

Data are raw facts (42, “Neha”). Information is processed and meaningful (“Neha’s attendance is 42 days”).

SHORTS22 marks

2. What is a primary key? Give one example.

Show Answer

Ans:

A field (or set of fields) that uniquely identifies each record and cannot be empty. Example: AdmissionNo in a Student table.

SHORTS32 marks

3. Distinguish between data and information with an example.

Show Answer

Ans:

Data are raw, unprocessed facts, such as the marks obtained by each student in each subject. Information is data that has been processed and given meaning, such as the class average, the highest mark or a list of students who passed. A database stores data; queries and reports turn it into information.

SHORTS42 marks

4. What is a foreign key? Explain with a Student–Library example how it links two tables.

Show Answer

Ans:

A foreign key is a field in one table that refers to the primary key of another table. Example — the Issue table stores RollNo as a foreign key pointing to the Student table's RollNo primary key, so each issued book is tied to exactly one student without retyping the student's name and class.

APPLICATIONA53 marks

5. A school stores students in one sheet with teacher phone numbers typed against every student. Two problems, and the DBMS idea that fixes them.

Show Answer

Ans:

Redundancy (phone typed 40 times) and inconsistency (one row has the old number). Split into Student and Teacher tables with a foreign key.

APPLICATIONA63 marks

6. Riya is revising “Introduction to DBMS” (Data vs information, database, DBMS advantages, keys and types of database.). A classmate lost marks by doing this: Calling Calc a DBMS. Calc is a spreadsheet; Base is the DBMS in this course. Apply the correct method and rewrite the scoring answer.

Show Answer

Ans:

Correct method: Primary key = unique + not empty. Roll number works; student name does not.
Why the mistake costs marks: Calling Calc a DBMS. Calc is a spreadsheet; Base is the DBMS in this course.
Write the definition or formula first, then the working or example.

SHORTS73 marks

7. List any four advantages of a DBMS over a simple file system.

Show Answer

Ans:

It removes duplication, so the same fact is stored once and every user sees the same value.
It keeps the data consistent and lets the designer set rules, so that wrong data cannot easily be entered.
It allows many users to work at the same time without overwriting each other's work.
It gives security through passwords and permissions, and fast searching, sorting and reporting through queries.

SHORTS83 marks

8. Define field, record and table with reference to a school database.

Show Answer

Ans:

Field — one attribute, such as Name or Class; a column of the table.
Record — all the fields for one item, such as one student's complete row.
Table — the full set of records of one kind, such as the Student table holding every student's row.

LONGL94 marks

9. List four advantages of a DBMS over a paper register or a single Calc sheet.

Show Answer

Ans:

Less duplication; one correction updates all uses; password/security; backup and recovery; many users; validation (integrity). A Calc sheet is easy to duplicate and hard to relate as tables grow.

COMPETENCYC104 marks

10. Read and answer: A clinic keeps patient names in a diary. Two staff write different spellings; a page is lost. (a) Two problems of this system. (b) Two DBMS advantages that help. (c) Suggest a primary key.

Show Answer

Ans:

(a) Inconsistency, no backup, slow search, redundancy.
(b) Central consistent data, backup/recovery, validation, sharing.
(c) PatientID or a unique registration number — not the name.
