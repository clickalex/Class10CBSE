🎯 Marks lens

Goal Seek and Scenarios are the theory + practical pair.
Also: Consolidate, Group/Outline, Subtotals.

📖 Deep concepts

1. Consolidate: Data → Consolidate. Combines the same layout from several sheets (e.g. four term marks) using Sum/Average. Tick “Link to source data” to auto-update.
2. Groups and outline: Data → Group and Outline. Hide detail rows; show only totals.
3. Subtotals: sort first, then Data → Subtotals on a column (e.g. subtotal marks by section).
4. What-if analysis: change inputs to see outputs. Three tools: Scenarios, Goal Seek, Solver.
5. Scenarios: named sets of input cells (Best case, Worst case). Tools → Scenarios. Switching the name swaps the inputs and the formulas recalculate.
6. Goal Seek: Tools → Goal Seek. You know the result you want; Calc finds the input. Example: “What price makes profit = 10000?” Set cell, To value, By changing cell.
7. Solver: for many variables and constraints (maximise profit with limits). Heavier than Goal Seek.

🧮 Formulas to memorise

  • Profit = Revenue − Cost
  • Goal Seek: set formula cell → target value → change input cell

🛠️ Method, step by step

Goal Seek:

  1. Click the formula cell (profit).
  2. Tools → Goal Seek.
  3. Formula cell already filled; type the target in “To value”.
  4. “By changing cell” = the input (price).
  5. OK — Calc tries values until the target is hit.

🧠 Memory tricks

  • Goal Seek needs a formula in the set cell. Typing a number there will fail.
  • Sort before Subtotals or the groups will be wrong.

⚠️ Mistakes that cost marks

  • Mixing up Goal Seek (one input) with Solver (many inputs + constraints).
  • Forgetting to name scenarios, so you cannot switch back.

SHORTS12 marks

1. What is Goal Seek in Calc?

Show Answer

Ans:

A what-if tool: you set the result you want in a formula cell and Calc finds the input value that produces it.

SHORTS22 marks

2. What is a scenario?

Show Answer

Ans:

A named set of values for specified cells so you can switch between cases (best/worst) without retyping.

LONGL34 marks

3. Differentiate Consolidate and Subtotals.

Show Answer

Ans:

Consolidate combines several ranges/sheets into one summary (often another sheet). Subtotals insert summary rows inside one sorted list (sum of each group). Consolidate is across blocks; Subtotals is inside a table.

APPLICATIONA43 marks

4. A shop wants profit of ₹8,000. Profit is =B2*B3-B4 (price × qty − cost). Which tool, and which cell is “By changing” if qty and cost are fixed?

Show Answer

Ans:

Goal Seek. Set cell = profit, To value = 8000, By changing = price (B2).

COMPETENCYC54 marks

5. Read and answer: Four quarterly sheets have the same layout of expenses. The owner wants one yearly total that updates if a quarter changes. (a) Which tool? (b) Two settings to tick/choose. (c) Why not just type the four totals by hand?

Show Answer

Ans:

(a) Data → Consolidate.
(b) Function Sum; add each range; Link to source data.
(c) Manual totals go stale; a link updates and reduces typing errors.
