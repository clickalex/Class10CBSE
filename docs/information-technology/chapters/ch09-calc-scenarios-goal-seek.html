Chapter 9 · Scenarios and Goal Seek (Calc)

Chapter 9 of 20. The analysis half of Calc. Goal Seek is the one tool you must be able to demo.

Open this chapter’s questions + MCQs →

🎯 Marks lens 📖 Deep concepts 🧮 Formulas 🛠️ Steps 🧠 Tricks ⚠️ Mistakes ❓ Exam Q&A ✍️ Task

🎯 Marks lens

Goal Seek and Scenarios are the theory + practical pair.
Also: Consolidate, Group/Outline, Subtotals.

📖 Deep concepts

1. Consolidate: Data → Consolidate. Combines the same layout from several sheets (e.g. four term marks) using Sum/Average. Tick “Link to source data” to auto-update.
2. Groups and outline: Data → Group and Outline. Hide detail rows; show only totals.
3. Subtotals: sort first, then Data → Subtotals on a column (e.g. subtotal marks by section).
4. What-if analysis: change inputs to see outputs. Three tools: Scenarios, Goal Seek, Solver.
5. Scenarios: named sets of input cells (Best case, Worst case). Tools → Scenarios. Switching the name swaps the inputs and the formulas recalculate.
6. Goal Seek: Tools → Goal Seek. You know the result you want; Calc finds the input. Example: “What price makes profit = 10000?” Set cell, To value, By changing cell.
7. Solver: for many variables and constraints (maximise profit with limits). Heavier than Goal Seek.

🧮 Formulas to memorise

  • Profit = Revenue − Cost
  • Goal Seek: set formula cell → target value → change input cell

🛠️ Method, step by step

Goal Seek:

  1. Click the formula cell (profit).
  2. Tools → Goal Seek.
  3. Formula cell already filled; type the target in “To value”.
  4. “By changing cell” = the input (price).
  5. OK — Calc tries values until the target is hit.

🧠 Memory tricks

  • Goal Seek needs a formula in the set cell. Typing a number there will fail.
  • Sort before Subtotals or the groups will be wrong.

⚠️ Mistakes that cost marks

  • Mixing up Goal Seek (one input) with Solver (many inputs + constraints).
  • Forgetting to name scenarios, so you cannot switch back.

SHORTS12 marks

1. What is Goal Seek in Calc?

Show Answer

Ans:

A what-if tool: you set the result you want in a formula cell and Calc finds the input value that produces it.

SHORTS22 marks

2. What is a scenario?

Show Answer

Ans:

A named set of values for specified cells so you can switch between cases (best/worst) without retyping.

SHORTS32 marks

3. What is the difference between a scenario and Goal Seek?

Show Answer

Ans:

A scenario is a named set of input values that you save and switch between to compare outcomes, such as best case, worst case and expected case. Goal Seek works the other way: you state the result you want and Calc finds the single input value that produces it.

SHORTS42 marks

4. What is Solver in Calc, and how does it differ from Goal Seek?

Show Answer

Ans:

Solver finds input values that produce a target result, like Goal Seek — but it can change many cells at once and respect constraints (for example, quantities that must stay whole numbers). Goal Seek changes exactly one cell with no constraints. Use Goal Seek for one unknown, Solver for many.

APPLICATIONA53 marks

5. A shop wants profit of ₹8,000. Profit is =B2*B3-B4 (price × qty − cost). Which tool, and which cell is “By changing” if qty and cost are fixed?

Show Answer

Ans:

Use Goal Seek (Tools → Goal Seek). Set cell = the profit cell, To value = 8000, and By changing cell = the price cell B2.
Goal Seek works backwards: instead of asking what the profit is, it asks what input would produce the profit you want, and it tries values until the formula cell reaches 8000.
Only one input cell can be changed, so the quantity and the cost must stay fixed while the price is adjusted.

APPLICATIONA63 marks

6. Riya is revising “Scenarios and Goal Seek (Calc)” (Data consolidation, subtotals, what-if scenarios, Goal Seek and Solver.). A classmate lost marks by doing this: Mixing up Goal Seek (one input) with Solver (many inputs + constraints). Apply the correct method and rewrite the scoring answer.

Show Answer

Ans:

Correct method: Goal Seek needs a formula in the set cell. Typing a number there will fail.
Why the mistake costs marks: Mixing up Goal Seek (one input) with Solver (many inputs + constraints).
Write the definition or formula first, then the working or example.

SHORTS73 marks

7. Describe how to use Goal Seek in Calc, with an example.

Show Answer

Ans:

Build the sheet so that the result cell contains a formula, for example the EMI for a loan in B5.
Choose Tools → Goal Seek and fill in the dialog: Formula Cell B5, Target Value 8000, Variable Cell B2 (the interest rate or the loan amount).
Click OK; Calc changes the variable cell step by step until the formula gives the target, and reports whether it succeeded.
This is quicker than trial and error when only one input is unknown.

SHORTS83 marks

8. What is the ‘Group’ feature in Calc? Explain with a monthly-expense sheet example.

Show Answer

Ans:

Group (Data → Define Range → Group) bundles rows or columns so they can be collapsed to a single line or expanded again with one click.
Example — a yearly sheet with twelve monthly blocks: group each month's daily rows, collapse all twelve, and only the monthly totals stay visible for review.
Unlike hiding, grouping shows a clear plus/minus control, so hidden detail is never forgotten.

LONGL94 marks

9. Differentiate Consolidate and Subtotals.

Show Answer

Ans:

Consolidate combines several ranges/sheets into one summary (often another sheet). Subtotals insert summary rows inside one sorted list (sum of each group). Consolidate is across blocks; Subtotals is inside a table.

COMPETENCYC104 marks

10. Read and answer: Four quarterly sheets have the same layout of expenses. The owner wants one yearly total that updates if a quarter changes. (a) Which tool? (b) Two settings to tick/choose. (c) Why not just type the four totals by hand?

Show Answer

Ans:

(a) Data → Consolidate.
(b) Function Sum; add each range; Link to source data.
(c) Manual totals go stale; a link updates and reduces typing errors.
