CBSE • CLASS 10 • IT 402

Information Technology — Practical & internal assessment

IT 402 practical is 50 marks: Writer 5 + Calc 5 + Base 10 + viva 10 + project 10 + file 10. Software is LibreOffice.

  • Writer (5): styles, image wrap, ToC from Heading styles, track changes or mail merge as asked.
  • Calc (5): a formula sheet plus Goal Seek or a scenario; sometimes a recorded macro.
  • Base (10): two related tables, a query with criteria, a form and a report.
  • Viva (10): “what is a primary key?”, “name the 7 Cs”, “which extinguisher on an electrical fire?”
  • File (10): at least five problems each in Writer, Calc and Base, with the question at the top of the printout.
  • Project (10): an interdisciplinary case — for example a school inventory in Base plus a Calc analysis.
