Removed from the syllabus

  • Periodic Classification of Elements — removed.
  • Sources of Energy — removed.
  • Management of Natural Resources — removed.
  • Chapter 8 no longer covers the full evolution section; it is now Heredity.

Prescribed books

  • Science — Textbook for Class X, NCERT (the board paper is set from this book, including the activities)
  • NCERT Exemplar Problems for Class X Science (for case-based and higher-order questions)
  • CBSE Laboratory Manual for Class X (the practical exam is drawn from these activities)
