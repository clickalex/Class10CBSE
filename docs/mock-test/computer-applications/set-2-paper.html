Section A · Networking Q1–Q10 · 10 marks

1. How many bits are in an IPv6 address?

  • (a) 32
  • (b) 64
  • (c) 128
  • (d) 256

2. URL stands for:

  • (a) Uniform Resource Locator
  • (b) Universal Resource Link
  • (c) United Resource Locator
  • (d) Uniform Resource Link

3. Which protocol is used to send email?

  • (a) POP3
  • (b) IMAP
  • (c) SMTP
  • (d) FTP

4. Which protocol keeps mail on the server?

  • (a) POP3
  • (b) IMAP
  • (c) SMTP
  • (d) Telnet

5. Which network covers a whole city?

  • (a) LAN
  • (b) MAN
  • (c) WAN
  • (d) PAN

6. Which medium is immune to electrical interference?

  • (a) twisted pair
  • (b) coaxial
  • (c) optical fibre
  • (d) infrared

7. Which generation first made video calling practical?

  • (a) 2G
  • (b) 3G
  • (c) 4G
  • (d) 1G

8. NFC works only when the two devices are:

  • (a) a few centimetres apart
  • (b) in the same building
  • (c) on the same Wi-Fi network
  • (d) several metres apart

9. Which stores a local copy of a page to speed up loading?

  • (a) cookie
  • (b) bookmark
  • (c) cache
  • (d) portal

10. A padlock symbol in the address bar means the page:

  • (a) is served over an encrypted HTTPS connection
  • (b) is free
  • (c) is saved offline
  • (d) belongs to the government

Section B · HTML Q11–Q25 · 15 marks

11. Which of these is an empty tag?

  • (a) <p>
  • (b) <br>
  • (c) <h1>
  • (d) <title>

12. The tag that sets the text shown in the browser's title bar is:

  • (a) <title>
  • (b) <head>
  • (c) <h1>
  • (d) <body>

13. The valid values of the align attribute are —

  • (a) left, middle, right
  • (b) left, center, right
  • (c) start, center, end
  • (d) top, middle, bottom

14. <ul type='square'> shows bullets as:

  • (a) discs
  • (b) squares
  • (c) circles
  • (d) numbers

15. Which attribute of <a> gives the destination address?

  • (a) src
  • (b) href
  • (c) link
  • (d) target

16. mailto: is used to —

  • (a) download mail
  • (b) open the email program
  • (c) create a table
  • (d) send an image

17. The attribute of <img> that shows text if the picture cannot be displayed is:

  • (a) alt
  • (b) src
  • (c) title
  • (d) name

18. A header cell is written with —

  • (a) <td>
  • (b) <th>
  • (c) <head>
  • (d) <caption>

19. How many <tr> tags does a 4-row table need?

  • (a) 1
  • (b) 2
  • (c) 4
  • (d) 8

20. cellpadding controls:

  • (a) space inside each cell
  • (b) space between cells
  • (c) the border thickness
  • (d) the table width

21. Radio buttons in one group must share the same —

  • (a) value
  • (b) name
  • (c) id
  • (d) size

22. Which method sends data in the request body?

  • (a) GET
  • (b) POST
  • (c) SEND
  • (d) PUT

23. The tag that creates a box for several lines of text is:

  • (a) <textarea>
  • (b) <input type="text">
  • (c) <select>
  • (d) <option>

24. To set a picture 200 px wide with text wrapping on its right, use —

  • (a) img { align: left; }
  • (b) img { float: left; width: 200px; }
  • (c) img { margin: left; }
  • (d) img { size: 200px; }

25. Which tag embeds a film in a page?

  • (a) <movie>
  • (b) <media>
  • (c) <video>
  • (d) <film>

Section C · Cyber Ethics Q26–Q30 · 5 marks

26. Which of these is an e-commerce activity?

  • (a) reading a blog
  • (b) paying an electricity bill on a bank app
  • (c) watching a video
  • (d) typing a document

27. Which step does NOT bridge the digital divide?

  • (a) village mobile networks
  • (b) regional-language apps
  • (c) English-only services
  • (d) low-cost data

28. Which IPR protects an invention?

  • (a) copyright
  • (b) patent
  • (c) trademark
  • (d) licence

29. Software free to use but closed in source is called —

  • (a) shareware
  • (b) freeware
  • (c) FOSS
  • (d) malware

30. Copying a paid program and selling it without the owner's permission is:

  • (a) software piracy
  • (b) fair use
  • (c) open source
  • (d) shareware
