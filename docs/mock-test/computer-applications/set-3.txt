SECTION A - Networking (Q1-Q10, 10 marks)
-----------------------------------------

Q1. ARPANET was developed in —
    (a) 1959
    (b) 1969
    (c) 1989
    (d) 1995

Q2. The World Wide Web was invented by:
    (a) Tim Berners-Lee
    (b) Bill Gates
    (c) Vint Cerf
    (d) Steve Jobs

Q3. The default port for HTTPS is —
    (a) 21
    (b) 23
    (c) 80
    (d) 443

Q4. HTTPS is safer than HTTP because it:
    (a) encrypts the data sent between the browser and the site
    (b) is faster
    (c) is free
    (d) needs no server

Q5. A device that joins two different networks and picks the best path is a —
    (a) hub
    (b) switch
    (c) repeater
    (d) router

Q6. The device that connects two different networks and chooses the best path is a:
    (a) router
    (b) switch
    (c) hub
    (d) repeater

Q7. NFC works over a range of —
    (a) metres
    (b) kilometres
    (c) centimetres
    (d) it has no limit

Q8. Which standard family defines Wi-Fi?
    (a) IEEE 802.3
    (b) IEEE 802.11
    (c) IEEE 802.15
    (d) IEEE 802.16

Q9. The entry page of a website is called the —
    (a) portal
    (b) home page
    (c) cache
    (d) feed

Q10. The address bar of a browser shows the:
    (a) URL of the page you are on
    (b) IP address of your own computer
    (c) size of the page
    (d) number of visitors to the site


SECTION B - HTML (Q11-Q25, 15 marks)
------------------------------------

Q11. The tag used for the most important heading is:
    (a) <h1>
    (b) <h6>
    (c) <p>
    (d) <b>

Q12. Which tag creates a bulleted list?
    (a) <ol>
    (b) <ul>
    (c) <dl>
    (d) <li>

Q13. <ol type='a'> numbers the items as —
    (a) 1,2,3
    (b) A,B,C
    (c) a,b,c
    (d) i,ii,iii

Q14. The tag that draws a horizontal rule across the page is:
    (a) <hr>
    (b) <br>
    (c) <line>
    (d) <rule>

Q15. <img> is —
    (a) a paired tag
    (b) an empty tag
    (c) a heading tag
    (d) not a valid tag

Q16. To link to a file in the parent folder you write —
    (a) /index.html
    (b) ./index.html
    (c) ../index.html
    (d) index.html

Q17. An in-page link to a section with id='top' is written as:
    (a) <a href='#top'>
    (b) <a src='top'>
    (c) <a link='top'>
    (d) <a href='top.html'>

Q18. cellspacing controls —
    (a) space inside a cell
    (b) space between cells
    (c) the border thickness
    (d) the table width

Q19. The attribute that adds a visible border around a table is:
    (a) border
    (b) cellspacing
    (c) cellpadding
    (d) width

Q20. The tag used for a cell that holds a column heading is:
    (a) <th>
    (b) <td>
    (c) <tr>
    (d) <caption>

Q21. Which of these is a paired tag?
    (a) <input>
    (b) <textarea>
    (c) <img>
    (d) <br>

Q22. In <select>, the option shown by default is marked with:
    (a) selected
    (b) checked
    (c) default
    (d) value

Q23. To make paragraph text red you write —
    (a) p { font-color: red; }
    (b) p { color: red; }
    (c) p { text: red; }
    (d) p { ink: red; }

Q24. The space OUTSIDE an element’s border is controlled by —
    (a) padding
    (b) margin
    (c) outline
    (d) float

Q25. outline differs from border because it —
    (a) sits inside the text
    (b) is drawn outside the border
    (c) only works on images
    (d) needs no style value
