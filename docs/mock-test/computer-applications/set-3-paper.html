Section A · Networking Q1–Q10 · 10 marks

1. ARPANET was developed in —

  • (a) 1959
  • (b) 1969
  • (c) 1989
  • (d) 1995

2. The World Wide Web was invented by:

  • (a) Tim Berners-Lee
  • (b) Bill Gates
  • (c) Vint Cerf
  • (d) Steve Jobs

3. The default port for HTTPS is —

  • (a) 21
  • (b) 23
  • (c) 80
  • (d) 443

4. HTTPS is safer than HTTP because it:

  • (a) encrypts the data sent between the browser and the site
  • (b) is faster
  • (c) is free
  • (d) needs no server

5. A device that joins two different networks and picks the best path is a —

  • (a) hub
  • (b) switch
  • (c) repeater
  • (d) router

6. The device that connects two different networks and chooses the best path is a:

  • (a) router
  • (b) switch
  • (c) hub
  • (d) repeater

7. NFC works over a range of —

  • (a) metres
  • (b) kilometres
  • (c) centimetres
  • (d) it has no limit

8. Which standard family defines Wi-Fi?

  • (a) IEEE 802.3
  • (b) IEEE 802.11
  • (c) IEEE 802.15
  • (d) IEEE 802.16

9. The entry page of a website is called the —

  • (a) portal
  • (b) home page
  • (c) cache
  • (d) feed

10. The address bar of a browser shows the:

  • (a) URL of the page you are on
  • (b) IP address of your own computer
  • (c) size of the page
  • (d) number of visitors to the site

Section B · HTML Q11–Q25 · 15 marks

11. The tag used for the most important heading is:

  • (a) <h1>
  • (b) <h6>
  • (c) <p>
  • (d) <b>

12. Which tag creates a bulleted list?

  • (a) <ol>
  • (b) <ul>
  • (c) <dl>
  • (d) <li>

13. <ol type='a'> numbers the items as —

  • (a) 1,2,3
  • (b) A,B,C
  • (c) a,b,c
  • (d) i,ii,iii

14. The tag that draws a horizontal rule across the page is:

  • (a) <hr>
  • (b) <br>
  • (c) <line>
  • (d) <rule>

15. <img> is —

  • (a) a paired tag
  • (b) an empty tag
  • (c) a heading tag
  • (d) not a valid tag

16. To link to a file in the parent folder you write —

  • (a) /index.html
  • (b) ./index.html
  • (c) ../index.html
  • (d) index.html

17. An in-page link to a section with id='top' is written as:

  • (a) <a href='#top'>
  • (b) <a src='top'>
  • (c) <a link='top'>
  • (d) <a href='top.html'>

18. cellspacing controls —

  • (a) space inside a cell
  • (b) space between cells
  • (c) the border thickness
  • (d) the table width

19. The attribute that adds a visible border around a table is:

  • (a) border
  • (b) cellspacing
  • (c) cellpadding
  • (d) width

20. The tag used for a cell that holds a column heading is:

  • (a) <th>
  • (b) <td>
  • (c) <tr>
  • (d) <caption>

21. Which of these is a paired tag?

  • (a) <input>
  • (b) <textarea>
  • (c) <img>
  • (d) <br>

22. In <select>, the option shown by default is marked with:

  • (a) selected
  • (b) checked
  • (c) default
  • (d) value

23. To make paragraph text red you write —

  • (a) p { font-color: red; }
  • (b) p { color: red; }
  • (c) p { text: red; }
  • (d) p { ink: red; }

24. The space OUTSIDE an element’s border is controlled by —

  • (a) padding
  • (b) margin
  • (c) outline
  • (d) float

25. outline differs from border because it —

  • (a) sits inside the text
  • (b) is drawn outside the border
  • (c) only works on images
  • (d) needs no style value

  • (a) MS Windows

  • (c) Linux
  • (d) Skype

30. Software distributed as a paid trial is called:

  • (a) shareware
  • (b) freeware
  • (c) FOSS
  • (d) malware
