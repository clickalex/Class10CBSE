Section A · Networking Q1–Q10 · 10 marks

1. Who invented the World Wide Web?

  • (a) Vint Cerf
  • (b) Tim Berners-Lee
  • (c) Bill Gates
  • (d) Charles Babbage

2. DNS stands for —

  • (a) Dynamic Name Service
  • (b) Domain Name System
  • (c) Data Network Server
  • (d) Digital Naming Standard

3. In https://example.com/page.html, example.com is the —

  • (a) protocol
  • (b) domain
  • (c) path
  • (d) port

4. The protocol used to send an email is:

  • (a) SMTP
  • (b) POP3
  • (c) IMAP
  • (d) FTP

5. Which topology has a single point of failure at its centre?

  • (a) Mesh
  • (b) Bus
  • (c) Star
  • (d) Ring

6. The topology in which every computer is connected to every other computer is the:

  • (a) mesh topology
  • (b) star topology
  • (c) bus topology
  • (d) ring topology

7. 4G networks are described as —

  • (a) analog
  • (b) circuit-switched
  • (c) all-IP
  • (d) infrared-based

8. The generation of mobile technology that first made mobile internet practical was:

  • (a) 3G
  • (b) 1G
  • (c) 2G
  • (d) 5G

9. Google is an example of a —

  • (a) browser
  • (b) search engine
  • (c) protocol
  • (d) server operating system

10. The program that automatically visits and indexes web pages is called a —

  • (a) router
  • (b) crawler
  • (c) modem
  • (d) gateway

Section B · HTML Q11–Q25 · 15 marks

11. HTML stands for —

  • (a) HighText Machine Language
  • (b) HyperText Markup Language
  • (c) HyperTool Markup Language
  • (d) Home Tool Markup Language

12. Which tag goes inside <head>?

  • (a) <body>
  • (b) <h1>
  • (c) <title>
  • (d) <p>

13. The smallest heading tag is —

  • (a) <h1>
  • (b) <h3>
  • (c) <h6>
  • (d) <head>

14. Which attribute of <font> sets the typeface?

  • (a) size
  • (b) color
  • (c) face
  • (d) style

15. To write x² in HTML you use —

  • (a) <sub>
  • (b) <sup>
  • (c) <u>
  • (d) <tt>

16. The tag that starts a new line without starting a new paragraph is:

  • (a) <br>
  • (b) <hr>
  • (c) <p>
  • (d) <lb>

17. Which opens a link in a new tab?

  • (a) target='_new'
  • (b) target='_blank'
  • (c) new='true'
  • (d) href='_blank'

18. The attribute of the <a> tag that holds the destination address is:

  • (a) href
  • (b) src
  • (c) link
  • (d) target

19. Which tag defines a table row?

  • (a) <td>
  • (b) <tr>
  • (c) <th>
  • (d) <table>

20. To merge a cell across three columns you use —

  • (a) rowspan='3'
  • (b) colspan='3'
  • (c) span='3'
  • (d) merge='3'

21. Which input type hides the characters typed?

  • (a) text
  • (b) hidden
  • (c) password
  • (d) secure

22. To pre-select a radio button you use the attribute —

  • (a) selected
  • (b) checked
  • (c) default
  • (d) value

23. Which of these is a valid border-style value?

  • (a) striped
  • (b) dashed
  • (c) glowing
  • (d) thick

24. Which rule makes all <h2> headings italic?

  • (a) h2 { font: italic; }
  • (b) h2 { style: italic; }
  • (c) h2 { font-style: italic; }
  • (d) h2 { text: italic; }

25. The attribute that makes the browser show play, pause and volume buttons is:

  • (a) controls
  • (b) autoplay
  • (c) loop
  • (d) src

Section C · Cyber Ethics Q26–Q30 · 5 marks

26. Typing a message in ALL CAPS is bad netiquette because it —

  • (a) saves time
  • (b) reads as shouting
  • (c) looks stylish
  • (d) avoids spam

27. A safe shopping site must show —

  • (a) http://
  • (b) https:// with a padlock
  • (c) flashing ads
  • (d) pop-up prizes

28. Someone calls “from the bank” and asks for your OTP. You should —

  • (a) share it quickly
  • (b) share half of it
  • (c) refuse and cut the call
  • (d) ask for a bigger limit

29. Which IPR protects a brand logo?

  • (a) copyright
  • (b) patent
  • (c) trademark
  • (d) trade secret

30. Presenting someone else's work as your own is —

  • (a) piracy
  • (b) plagiarism
  • (c) phishing
  • (d) hacking
