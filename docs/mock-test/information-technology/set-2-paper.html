Section A · Employability Skills Q1–Q6 · 6 marks

1. The easiest method of communication is:

  • (a) written
  • (b) oral
  • (c) non-verbal
  • (d) email

2. Which goal is SMART?

  • (a) I will study more
  • (b) I will type 40 correct rows in Calc by 3 pm
  • (c) I will become famous
  • (d) I will try

3. A computer should be shut down:

  • (a) by pulling the plug
  • (b) using the OS shutdown command
  • (c) by holding the monitor button
  • (d) never

4. A person who starts a business, organises it and bears its risks is a/an:

  • (a) entrepreneur
  • (b) manager
  • (c) employee
  • (d) customer

5. Which of these is a myth about entrepreneurs?

  • (a) they are born, not made
  • (b) they take risks
  • (c) they work hard
  • (d) they need capital

6. Sustainable development looks after:

  • (a) only the present
  • (b) only the future
  • (c) present without harming the future
  • (d) only factories

Section B · Digital Documentation (Writer) Q7–Q11 · 5 marks

7. Fill Format is used to:

  • (a) insert images
  • (b) paint a style onto many paragraphs
  • (c) mail merge
  • (d) record a macro

8. Heading 1, Heading 2 and Heading 3 are examples of:

  • (a) paragraph styles
  • (b) character styles
  • (c) page styles
  • (d) frame styles

9. Optimal wrap means:

  • (a) image hidden
  • (b) text flows in the best way around the image
  • (c) image deleted
  • (d) no caption

10. Inserting a caption is done by:

  • (a) File → New
  • (b) right-click image → Insert Caption
  • (c) Tools → Macros
  • (d) Data → Sort

11. ToC is updated by:

  • (a) F11
  • (b) right-click the ToC → Update Index
  • (c) Goal Seek
  • (d) Group

Section C · Electronic Spreadsheet (Calc) Q12–Q17 · 6 marks

12. Subtotals in Calc are created from:

  • (a) Data → Subtotals
  • (b) Tools → Subtotals
  • (c) Insert → Subtotals
  • (d) Format → Subtotals

13. Macros in Calc are started from:

  • (a) Insert → Image
  • (b) Tools → Macros
  • (c) Data → Sort
  • (d) Format → Cells

14. Linked data in a spreadsheet:

  • (a) updates when the source value changes
  • (b) is frozen at the time of linking
  • (c) must be typed again
  • (d) cannot be used in a formula

15. A hyperlink in a sheet can point to:

  • (a) a web page, an email address or a place in the same document
  • (b) only a web page
  • (c) only a file on the desktop
  • (d) only a printer

16. Share Spreadsheet is under:

  • (a) Insert
  • (b) Tools
  • (c) Format
  • (d) Data

17. Comments in a spreadsheet are used to:

  • (a) ask a question or explain a cell without changing its value
  • (b) delete the cell
  • (c) sort the data
  • (d) create a chart

Section D · Database Management (Base) Q18–Q24 · 7 marks

18. LibreOffice Base is:

  • (a) a DBMS
  • (b) an OS
  • (c) a browser
  • (d) a style

19. A primary key must:

  • (a) be unique and never empty
  • (b) contain only numbers
  • (c) be the first field of the table
  • (d) change every day

20. Referential integrity prevents:

  • (a) styles
  • (b) orphan FK values
  • (c) Goal Seek
  • (d) macros

21. The relationship between one customer and the many orders placed by that customer is:

  • (a) one-to-many
  • (b) one-to-one
  • (c) many-to-many
  • (d) not possible

22. A query stores:

  • (a) a second full copy of all data always
  • (b) the question (fields, criteria)
  • (c) a Writer template
  • (d) an OS

23. To show only the students of Class 10 in a query you would:

  • (a) type a criterion in the Class field
  • (b) sort the Class field
  • (c) rename the field
  • (d) delete the other rows

24. A form is mainly for:

  • (a) printing totals
  • (b) entering and editing records
  • (c) recording macros
  • (d) 7 Cs

  • (a) grab the person

  • (d) apply toothpaste

30. The single all-India emergency number for police, fire and ambulance is:

  • (a) 112
  • (b) 100
  • (c) 101
  • (d) 108
