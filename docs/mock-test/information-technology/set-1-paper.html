Section A · Employability Skills Q1–Q6 · 6 marks

1. Paralanguage refers to:

  • (a) body posture only
  • (b) charts and maps
  • (c) tone, pitch and speed of voice
  • (d) grammar rules

2. SMART: the M stands for:

  • (a) Magical
  • (b) Measurable
  • (c) Maximum
  • (d) Monthly

3. Which is an OS?

  • (a) LibreOffice Writer
  • (b) Chrome
  • (c) Linux
  • (d) Calc

4. The keyboard shortcut used to copy a selected file is:

  • (a) Ctrl + C
  • (b) Ctrl + V
  • (c) Ctrl + X
  • (d) Ctrl + P

5. A social entrepreneur mainly aims to:

  • (a) ignore people
  • (b) solve a social problem, not only maximise profit
  • (c) avoid accounts
  • (d) work without a product

6. Which of these is a green skill?

  • (a) segregating waste at source
  • (b) leaving taps running
  • (c) burning dry leaves
  • (d) using a plastic bag every day

Section B · Digital Documentation (Writer) Q7–Q11 · 5 marks

7. Shortcut for the Styles window is usually:

  • (a) F1
  • (b) F5
  • (c) F11
  • (d) F12

8. To move several shapes together:

  • (a) Mail Merge
  • (b) Group
  • (c) Goal Seek
  • (d) Styles F11

9. To make two drawing objects move together you should:

  • (a) group them
  • (b) crop them
  • (c) wrap them
  • (d) delete one of them

10. Writer templates usually use the extension:

  • (a) .ods
  • (b) .ott
  • (c) .odb
  • (d) .jpg

11. A template is:

  • (a) a ready-made document with styles, margins and layout already set
  • (b) a picture
  • (c) a macro
  • (d) a printer setting

Section C · Electronic Spreadsheet (Calc) Q12–Q17 · 6 marks

12. Goal Seek is on the menu:

  • (a) Insert
  • (b) Tools
  • (c) Format
  • (d) Window

13. Consolidate is best when data is:

  • (a) on several similar sheets
  • (b) a single cell
  • (c) an image
  • (d) a Writer ToC

14. A macro is:

  • (a) a virus always
  • (b) a recorded command sequence
  • (c) a Heading style
  • (d) a primary key

15. Macros in LibreOffice are commonly stored and written in:

  • (a) LibreOffice Basic
  • (b) HTML
  • (c) SQL only
  • (d) CSS

16. Paste Special → Link is used to:

  • (a) break a file
  • (b) keep a live connection to copied cells
  • (c) record a macro
  • (d) group shapes

17. Sharing a sheet while protecting it from changes is done from:

  • (a) Tools → Protect Sheet
  • (b) File → Print
  • (c) Insert → Comment
  • (d) Format → Cells

Section D · Database Management (Base) Q18–Q24 · 7 marks

18. Which is information, not raw data?

  • (a) 36
  • (b) “Amit”
  • (c) “Amit’s temperature is 36 °C”
  • (d) a blank cell

19. A good primary key for books is:

  • (a) Title
  • (b) Author
  • (c) ISBN
  • (d) Colour

20. The exam-preferred way to create a table is:

  • (a) Wizard only
  • (b) Design View
  • (c) Mail Merge
  • (d) Goal Seek

21. Datasheet view is for:

  • (a) setting data types
  • (b) entering records
  • (c) recording macros
  • (d) wrapping images

22. The foreign key is stored on the:

  • (a) one side always
  • (b) many side
  • (c) report
  • (d) form title

23. To sort marks highest first:

  • (a) Sort Ascending
  • (b) Sort Descending on Marks
  • (c) Primary key
  • (d) Wrap Optimal

24. The Report Wizard in Base is started from:

  • (a) Reports → Use Wizard to Create Report
  • (b) Tables → Create Table in Design View
  • (c) Queries → Design View
  • (d) Tools → Options

  • (a) ice cubes rubbed hard
  • (b) running water
