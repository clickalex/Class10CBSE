Section A · Employability Skills Q1–Q6 · 6 marks

1. Which of the 7 Cs means “to the point, no extra words”?

  • (a) Clear
  • (b) Concise
  • (c) Concrete
  • (d) Courteous

2. A hobby after study is mainly:

  • (a) a waste
  • (b) a stress-management method
  • (c) self-employment
  • (d) a barrier

3. The Recycle Bin is used to:

  • (a) speed up RAM
  • (b) store deleted files until emptied
  • (c) install an OS
  • (d) scan viruses

4. An entrepreneur primarily:

  • (a) avoids all risk
  • (b) takes calculated risk to create value
  • (c) only works for a salary
  • (d) copies without a customer

5. A solar-panel technician is:

  • (a) a linguistic barrier
  • (b) a green job
  • (c) an OS
  • (d) a myth

6. A green economy is one that:

  • (a) improves human well-being while reducing environmental risks
  • (b) produces the most goods
  • (c) bans all industry
  • (d) depends only on coal

Section B · Digital Documentation (Writer) Q7–Q11 · 5 marks

7. ToC in Writer is built from:

  • (a) bold text
  • (b) Heading styles
  • (c) page numbers only
  • (d) hyperlinks only

8. The Styles window in Writer is opened with:

  • (a) F11
  • (b) Ctrl + S
  • (c) F7
  • (d) Ctrl + P

9. The tool used to remove unwanted parts of a picture is the:

  • (a) Crop tool
  • (b) Wrap tool
  • (c) Rotate tool
  • (d) Fill tool

10. Recorded deletions in Track Changes usually appear as:

  • (a) a new page
  • (b) strike-out text
  • (c) a ToC
  • (d) a style

11. Recorded changes are accepted or rejected from:

  • (a) Edit → Track Changes → Manage
  • (b) File → Save
  • (c) Insert → Comment
  • (d) View → Zoom

Section C · Electronic Spreadsheet (Calc) Q12–Q17 · 6 marks

12. Before Subtotals you must:

  • (a) insert a chart
  • (b) sort the group column
  • (c) record a macro
  • (d) protect the sheet

13. Consolidating data means:

  • (a) combining data from several sheets or ranges into one summary
  • (b) deleting duplicate rows
  • (c) sorting a column
  • (d) filtering rows

14. Unknown file asks to enable macros. You should:

  • (a) always click Enable
  • (b) enable only if you trust the source
  • (c) delete LibreOffice
  • (d) turn security to Low forever

15. Recording a macro in LibreOffice starts from:

  • (a) Tools → Macros → Record Macro
  • (b) Insert → Macro
  • (c) Format → Macro
  • (d) Data → Macro

16. Insert → Hyperlink can open:

  • (a) only images
  • (b) a web page or a file
  • (c) Goal Seek
  • (d) a style

17. Compare Document is useful when:

  • (a) you have an older copy to diff
  • (b) you need a chart
  • (c) you insert an image
  • (d) you write a ToC

Section D · Database Management (Base) Q18–Q24 · 7 marks

18. The field that uniquely identifies each record in a table is the:

  • (a) primary key
  • (b) foreign key
  • (c) index
  • (d) alias

19. Which of these is DBMS software?

  • (a) LibreOffice Base
  • (b) MS Word
  • (c) Google Chrome
  • (d) VLC player

20. In Design View, the property that limits how many characters a text field can hold is:

  • (a) Field Length
  • (b) Format
  • (c) Default Value
  • (d) Caption

21. In a relationship, the field in the child table that matches the primary key of the parent table is the:

  • (a) foreign key
  • (b) primary key
  • (c) index
  • (d) alias

22. Sorting a query result in descending order arranges the values:

  • (a) from largest to smallest
  • (b) from A to Z
  • (c) oldest first
  • (d) in the order they were entered

23. The best source for a filtered report is:

  • (a) a query
  • (b) a random image
  • (c) Track Changes
  • (d) a template .ott

24. A report is mainly used to:

  • (a) print or present data in a formatted way
  • (b) enter new records
  • (c) store the data
  • (d) delete old records

  • (a) raise the alarm and leave by the marked exit
  • (b) collect your belongings
  • (c) use the lift
  • (d) finish the work you are doing

26. PPE stands for:

  • (a) Personal Protective Equipment
  • (b) Public Protection Exercise
  • (c) Power Protection Equipment
  • (d) Personal Programme Entry

27. Screen top should be:

  • (a) at knee level
  • (b) at eye level
  • (c) behind you
  • (d) on the floor

28. Repetitive Strain Injury is caused mainly by:

  • (a) repeating the same small movement for long periods
  • (b) a single heavy fall
  • (c) loud noise
  • (d) cold weather

29. During a fire, do not:

  • (a) use stairs
  • (b) go to the assembly point
  • (c) use the lift
  • (d) follow the teacher

30. During an evacuation you should:

  • (a) walk quickly to the assembly point without using the lift
  • (b) run and push past others
  • (c) use the lift to leave faster
  • (d) go back for your bag
