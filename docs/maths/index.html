Topper’s study order

  1. Algebra first (20 marks, Chapters 2–5) — the biggest single block of marks.
  2. Statistics and Probability (11 marks) — short chapters, high yield.
  3. Trigonometry (12 marks) — the ratio table unlocks both chapters.
  4. Geometry (15 marks) — theorem statements first, then the proof practice.
  5. Mensuration (10) and Coordinate Geometry (6) — formula-driven.
  6. Number Systems (6) last — the quickest unit to revise the night before.
  7. Then two timed full papers with the official marking scheme.
