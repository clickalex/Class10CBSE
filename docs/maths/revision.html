Mathematics — Quick revision

One screen per chapter: formulas and the points that actually get asked. Expand what you need, skip what you know.

Ch 1 Real Numbers

Formulas

  • a = bq + r, 0 ≤ r < b
  • HCF(a, b) × LCM(a, b) = a × b
  • p/q terminates ⇔ q = 2ᵐ × 5ⁿ
  • HCF × LCM = product (two numbers only).
  • Terminating ⇔ denominator is 2ᵐ × 5ⁿ after reducing.
  • Irrationality proof: assume p/q coprime, square, show a prime divides both, contradiction.
Ch 2 Polynomials

Formulas

  • α + β = −b/a
  • αβ = c/a
  • p(x) = x² − (α + β)x + αβ
  • p(x) = g(x) × q(x) + r(x), deg r < deg g
  • Sum = −b/a, product = c/a. The sign is the trap.
  • Form it as x² − (sum)x + product, then clear fractions.
  • x-axis crossings = number of zeroes.
Ch 3 Pair of Linear Equations in Two Variables

Formulas

  • x/(b₁c₂ − b₂c₁) = y/(c₁a₂ − c₂a₁) = 1/(a₁b₂ − a₂b₁)
  • Upstream speed = still-water speed − stream speed
  • Downstream speed = still-water speed + stream speed
  • Equal a and b ratios but a different c ratio → no solution.
  • All three ratios equal → infinitely many solutions.
  • Word problems: name the unknowns in words first, then translate.
  • Downstream = still + stream; upstream = still − stream.
Ch 4 Quadratic Equations

Formulas

  • x = (−b ± √(b² − 4ac)) / 2a
  • D = b² − 4ac
  • Equal roots ⇔ D = 0
  • Sum of roots = −b/a, Product of roots = c/a
  • D = b² − 4ac decides everything: > 0 distinct, = 0 equal, < 0 none.
  • Split the middle term using product a × c and sum b.
  • Reject impossible roots in word problems.
Ch 5 Arithmetic Progressions

Formulas

  • aₙ = a + (n − 1)d
  • Sₙ = (n/2)[2a + (n − 1)d]
  • Sₙ = (n/2)(first term + last term)
  • aₙ = Sₙ − Sₙ₋₁
  • Sum of first n natural numbers = n(n + 1)/2
  • aₙ = a + (n−1)d and Sₙ = (n/2)[2a + (n−1)d].
  • aₙ = Sₙ − Sₙ₋₁ when Sₙ is given as a formula.
  • Three terms with a known sum: take a − d, a, a + d.
Ch 6 Triangles

Formulas

  • ar(ΔABC)/ar(ΔDEF) = (AB/DE)² = (BC/EF)² = (CA/FD)²
  • Right triangle: hypotenuse² = base² + perpendicular²
  • BPT: AD/DB = AE/EC
  • AAA, SSS, SAS are the three similarity criteria.
  • Area ratio = square of side ratio.
  • BPT: a parallel line cuts the other two sides proportionally.
Ch 7 Coordinate Geometry

Formulas

  • d = √[(x₂ − x₁)² + (y₂ − y₁)²]
  • Section: ((mx₂ + nx₁)/(m+n), (my₂ + ny₁)/(m+n))
  • Midpoint: ((x₁+x₂)/2, (y₁+y₂)/2)
  • Centroid: ((x₁+x₂+x₃)/3, (y₁+y₂+y₃)/3)
  • Area = ½|x₁(y₂−y₃) + x₂(y₃−y₁) + x₃(y₁−y₂)|
  • Distance is Pythagoras.
  • Section: m pairs with the second point.
  • Area = 0 means collinear.
Ch 8 Introduction to Trigonometry

Formulas

  • sin²A + cos²A = 1
  • 1 + tan²A = sec²A
  • 1 + cot²A = cosec²A
  • sin(90° − A) = cos A, cos(90° − A) = sin A
  • tan θ = sin θ / cos θ, cot θ = 1/tan θ
  • sin² + cos² = 1; 1 + tan² = sec²; 1 + cot² = cosec².
  • The 0/30/45/60/90 table.
  • Proofs: work from one side only.
Ch 9 Some Applications of Trigonometry

Formulas

  • tan θ = opposite / adjacent
  • For θ = 45°: height = horizontal distance
  • For θ = 60°: height = distance × √3
  • For θ = 30°: height = distance / √3
  • Draw the triangle first, always.
  • Depression angle = elevation angle from the other end.
  • Add the observer’s height back at the end.
Ch 10 Circles

Formulas

  • Tangent ⊥ radius at the point of contact
  • PA = PB for tangents from an external point P
  • Tangent length = √(d² − r²), where d is the distance from the centre
  • Tangent ⊥ radius at the point of contact.
  • Tangents from one external point are equal.
  • 0 tangents inside, 1 on, 2 outside.
Ch 11 Areas Related to Circles

Formulas

  • Arc length = (θ/360) × 2πr
  • Sector area = (θ/360) × πr²
  • Segment area = sector area − ½ r² sin θ
  • Perimeter of a sector = 2r + arc length
  • Quadrant = sector with θ = 90°
  • Sector perimeter = 2r + arc.
  • Segment = sector − triangle.
  • Inscribed circle: diameter = side of square.
Ch 12 Surface Areas and Volumes

Formulas

  • Cylinder: CSA = 2πrh, V = πr²h
  • Cone: CSA = πrl, V = πr²h/3, l = √(r² + h²)
  • Sphere: SA = 4πr², V = 4πr³/3
  • Hemisphere: CSA = 2πr², TSA = 3πr², V = 2πr³/3
  • Frustum: l = √[h² + (R − r)²], CSA = π(R + r)l
  • Frustum volume = πh(R² + r² + Rr)/3
  • Total surface area of a frustum = π(R + r)l + πR² + πr²
  • Surface area: count only what is exposed. Volume: always additive.
  • Melting conserves volume, never surface area.
  • Cone volume has the 1/3. Hemisphere CSA is 2πr², TSA is 3πr².
  • Frustum slant height uses (R − r).
Ch 13 Statistics

Formulas

  • Class mark xᵢ = (upper + lower)/2
  • Mean x̄ = Σfᵢxᵢ / Σfᵢ
  • Step deviation: x̄ = a + (Σfᵢuᵢ / Σfᵢ) × h
  • Median = l + [((N/2 − cf)/f) × h]
  • Mode = l + [(f₁ − f₀)/(2f₁ − f₀ − f₂)] × h
  • 3 Median = Mode + 2 Mean
  • Use class marks, not class limits.
  • Median: cf is the cumulative frequency before the median class.
  • Mode uses the frequency column, not the cf column.
  • 3 Median = Mode + 2 Mean as a check.
Ch 14 Probability

Formulas

  • P(E) = favourable outcomes / total outcomes
  • P(not E) = 1 − P(E)
  • 0 ≤ P(E) ≤ 1
  • Two dice: 36 outcomes
  • Deck: 52 cards, 26 red, 12 face cards, 4 aces
  • P(E) = favourable / total, and P(E) + P(not E) = 1.
  • Two dice = 36 outcomes. Deck = 52, red 26, face cards 12.
  • “At least one” = 1 − P(none).
