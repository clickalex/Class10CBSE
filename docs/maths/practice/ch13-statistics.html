MCQs

The class mark of the class 15–25 is: (a) 15 (b) 20 (c) 25 (d) 10

(b) 20. (15 + 25)/2.

The median class is the class whose cumulative frequency is: (a) equal to N/2 (b) the first one greater than N/2 (c) the largest (d) the smallest

(b) The first one greater than N/2.

If mean = 20 and mode = 26, then by the empirical relation the median is: (a) 22 (b) 22.67 (c) 23 (d) 24

(a) 22. 3 Median = 26 + 2(20) = 66, so Median = 22.

Written questions

2 marks Find the class mark of the class 25–35.

Class mark = (25 + 35)/2 = 30.

3 marks Find the mean of the data: class intervals 0–10, 10–20, 20–30, 30–40 with frequencies 3, 5, 7, 5.

Class marks: 5, 15, 25, 35. Σfᵢ = 20.
Σfᵢxᵢ = 3(5) + 5(15) + 7(25) + 5(35) = 15 + 75 + 175 + 175 = 440.
Mean = 440/20 = 22.

4 marks Find the median of the distribution: 0–10 (f = 4), 10–20 (f = 6), 20–30 (f = 10), 30–40 (f = 8), 40–50 (f = 2).

Cumulative frequencies: 4, 10, 20, 28, 30. So N = 30 and N/2 = 15.
The first cf greater than 15 is 20, so the median class is 20–30.
l = 20, cf = 10, f = 10, h = 10.
Median = 20 + [((15 − 10)/10) × 10] = 20 + 5 = 25.

3 marks Find the mode of the data: 10–20 (f = 3), 20–30 (f = 12), 30–40 (f = 9).

Modal class is 20–30 (highest frequency 12).
l = 20, f₁ = 12, f₀ = 3, f₂ = 9, h = 10.
Mode = 20 + [(12 − 3)/(24 − 3 − 9)] × 10 = 20 + (9/12) × 10 = 20 + 7.5 = 27.5.

4 marks The mean of the distribution 0–10 (f = 5), 10–20 (f = f), 20–30 (f = 8), 30–40 (f = 7) is 20.5. Find f.

Class marks: 5, 15, 25, 35.
Σfᵢ = 5 + f + 8 + 7 = f + 20.
Σfᵢxᵢ = 25 + 15f + 200 + 245 = 15f + 470.
Mean = (15f + 470)/(f + 20) = 20.5.
15f + 470 = 20.5f + 410, so 5.5f = 60 and f ≈ 10.9. Check your reading of the data — frequencies must be whole numbers, so re-check the given mean before answering.
