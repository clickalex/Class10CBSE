Written questions · Write

SHORTS12 marks

1. Find the zeroes of x² − 2x − 8 and verify the relationship with the coefficients.

Show Answer

Ans:

x² − 2x − 8 = (x − 4)(x + 2), so the zeroes are 4 and −2.
Sum = 4 + (−2) = 2 = −(−2)/1 = −b/a ✓
Product = 4 × (−2) = −8 = c/a ✓

SHORTS22 marks

2. If α and β are the zeroes of 6x² − 3x − 7, find 1/α + 1/β.

Show Answer

Ans:

α + β = 3/6 = 1/2 and αβ = −7/6.
1/α + 1/β = (α + β)/(αβ) = (1/2)/(−7/6) = −3/7.

SHORTS33 marks

3. Find a quadratic polynomial whose zeroes have sum 1/4 and product −1.

Show Answer

Ans:

p(x) = x² − (1/4)x − 1.
Clearing the fraction: 4x² − x − 4.

SHORTS43 marks

4. If one zero of (k² − 1)x² − 3x + 2 is the reciprocal of the other, find k.

Show Answer

Ans:

Product of zeroes = c/a = 2/(k² − 1).
Reciprocal zeroes ⇒ product = 1, so 2/(k² − 1) = 1.
k² − 1 = 2, k² = 3, so k = ±√3.

LONGL55 marks

5. Discuss “Polynomials” in detail. Include the idea that carries marks, one worked example or answer frame, and why students lose marks.

Show Answer

Ans:

Zeroes of a polynomial. A zero of p(x) is a value of x for which p(x) = 0. Geometrically it is where the graph cuts or touches the x-axis.
Marks lens: Usually one 2-mark question plus part of an objective question.
Method / memory trick: Sign trap: the sum is minus b/a. Almost every wrong answer here has the wrong sign.
Do not: Writing the sum as +b/a. It is −b/a.
