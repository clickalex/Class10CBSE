Written questions · Write

SHORTS11 mark

1. Evaluate sin 60° cos 30° + cos 60° sin 30°.

Show Answer

Ans:

(√3/2)(√3/2) + (1/2)(1/2) = 3/4 + 1/4 = 1.

SHORTS22 marks

2. If sin A = 3/5, find cos A and tan A (A is acute).

Show Answer

Ans:

Draw the right triangle: opposite = 3, hypotenuse = 5, so adjacent = √(25 − 9) = 4.
cos A = 4/5 and tan A = 3/4.

SHORTS33 marks

3. Prove that (1 + tan²A)/(1 + cot²A) = tan²A.

Show Answer

Ans:

Start from the left-hand side.
1 + tan²A = sec²A and 1 + cot²A = cosec²A.
So LHS = sec²A / cosec²A = (1/cos²A) ÷ (1/sin²A) = sin²A/cos²A = tan²A = RHS.

SHORTS43 marks

4. If tan(A + B) = √3 and tan(A − B) = 1/√3, with 0° < A + B ≤ 90° and A > B, find A and B.

Show Answer

Ans:

tan(A + B) = √3 gives A + B = 60°.
tan(A − B) = 1/√3 gives A − B = 30°.
Adding: 2A = 90°, so A = 45° and B = 15°.

LONGL55 marks

5. Discuss “Introduction to Trigonometry” in detail. Include the idea that carries marks, one worked example or answer frame, and why students lose marks.

Show Answer

Ans:

The six ratios. In a right triangle with respect to an acute angle θ: sin = opposite/hypotenuse, cos = adjacent/hypotenuse, tan = opposite/adjacent. The other three are their reciprocals: cosec, sec, cot.
Marks lens: Roughly 7–8 of the 12 Trigonometry marks. Identities are worth 3 marks and are asked as proofs.
Method / memory trick: Building the sin table: write 0, 1, 2, 3, 4 under 0°, 30°, 45°, 60°, 90°, divide each by 4, then take the square root. The cos row is the sin row read backwards.
Do not: Writing tan 90° = 0. It is not defined.
