SHORTS12 marks

1. Find the distance between (−2, 3) and (4, −5).

Show Answer

Ans:

d = √[(4 − (−2))² + (−5 − 3)²] = √[36 + 64] = √100 = 10 units.

SHORTS22 marks

2. Find the point that divides the segment joining (−1, 7) and (4, −3) in the ratio 2:3.

Show Answer

Ans:

x = (2(4) + 3(−1))/5 = (8 − 3)/5 = 1.
y = (2(−3) + 3(7))/5 = (−6 + 21)/5 = 3.
The point is (1, 3).

SHORTS33 marks

3. Find a relation between x and y if the point (x, y) is equidistant from (3, 6) and (−3, 4).

Show Answer

Ans:

Set the squared distances equal: (x−3)² + (y−6)² = (x+3)² + (y−4)².
Expanding and cancelling x² and y²: −6x − 12y + 45 = 6x − 8y + 25.
So 12x + 4y = 20, that is 3x + y = 5.

SHORTS43 marks

4. Find the area of the triangle with vertices (1, −1), (−4, 2k) and (−k, 5) if the area is 24/2 square units.

Show Answer

Ans:

Area = ½|1(2k − 5) + (−4)(5 − (−1)) + (−k)(−1 − 2k)|
= ½|2k − 5 − 24 + k + 2k²| = ½|2k² + 3k − 29| = 12.
So 2k² + 3k − 29 = ±24, giving 2k² + 3k − 53 = 0 or 2k² + 3k − 5 = 0.
The second factorises as (2k + 5)(k − 1) = 0, so k = 1 or k = −5/2. Always keep both the + and − cases because of the modulus.

LONGL55 marks

5. Discuss “Coordinate Geometry” in detail. Include the idea that carries marks, one worked example or answer frame, and why students lose marks.

Show Answer

Ans:

Distance formula. The distance between (x₁, y₁) and (x₂, y₂) is √[(x₂ − x₁)² + (y₂ − y₁)²] — just Pythagoras.
Marks lens: marks, almost always formula substitution.
Method / memory trick: Section formula cross pattern: m goes with the second point’s coordinates and n with the first. Write it out once correctly and reuse it.
Do not: Mixing up which ratio component multiplies which point in the section formula.
