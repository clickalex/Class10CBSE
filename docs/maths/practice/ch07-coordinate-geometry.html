The distance of the point (3, 4) from the origin is: (a) 5 (b) 7 (c) 25 (d) 12

(a) 5. √(9 + 16) = 5.

The midpoint of (2, −3) and (−6, 5) is: (a) (−2, 1) (b) (2, −1) (c) (−4, 2) (d) (4, −8)

(a) (−2, 1). ((2−6)/2, (−3+5)/2).

Three points are collinear if the area of the triangle they form is: (a) 1 (b) maximum (c) 0 (d) negative

(c) 0.

Written questions

2 marks Find the distance between (−2, 3) and (4, −5).

d = √[(4 − (−2))² + (−5 − 3)²] = √[36 + 64] = √100 = 10 units.

2 marks Find the point that divides the segment joining (−1, 7) and (4, −3) in the ratio 2:3.

x = (2(4) + 3(−1))/5 = (8 − 3)/5 = 1.
y = (2(−3) + 3(7))/5 = (−6 + 21)/5 = 3.
The point is (1, 3).

3 marks Find a relation between x and y if the point (x, y) is equidistant from (3, 6) and (−3, 4).

Set the squared distances equal: (x−3)² + (y−6)² = (x+3)² + (y−4)².
Expanding and cancelling x² and y²: −6x − 12y + 45 = 6x − 8y + 25.
So 12x + 4y = 20, that is 3x + y = 5.

3 marks Find the area of the triangle with vertices (1, −1), (−4, 2k) and (−k, 5) if the area is 24/2 square units.

Area = ½|1(2k − 5) + (−4)(5 − (−1)) + (−k)(−1 − 2k)|
= ½|2k − 5 − 24 + k + 2k²| = ½|2k² + 3k − 29| = 12.
So 2k² + 3k − 29 = ±24, giving 2k² + 3k − 53 = 0 or 2k² + 3k − 5 = 0.
The second factorises as (2k + 5)(k − 1) = 0, so k = 1 or k = −5/2. Always keep both the + and − cases because of the modulus.
