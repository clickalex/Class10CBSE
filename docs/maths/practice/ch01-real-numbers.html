MCQs · Drill

MCQM11 mark

1. The HCF of 8 and 12 is: (a) 2 (b) 4 (c) 8 (d) 24

Show Answer

Ans:

(b) 4. 8 = 2³, 12 = 2² × 3; the lowest power of the common prime 2 is 2² = 4.

MCQM21 mark

2. Which has a terminating decimal expansion? (a) 7/24 (b) 5/13 (c) 9/40 (d) 11/21

Show Answer

Ans:

(c) 9/40. 40 = 2³ × 5, of the form 2ᵐ × 5ⁿ. The others have denominators with other primes.

MCQM31 mark

3. If the HCF of two numbers is 6 and their LCM is 60, one number being 12, the other is: (a) 20 (b) 30 (c) 40 (d) 60

Show Answer

Ans:

(b) 30. Other number = (6 × 60)/12 = 30.

Written questions · Write

SHORTS11 mark

1. State Euclid’s division lemma.

Show Answer

Ans:

Given positive integers a and b, there exist unique integers q and r such that a = bq + r, where 0 ≤ r < b.

SHORTS22 marks

2. Without performing long division, state whether 13/3125 will have a terminating decimal expansion.

Show Answer

Ans:

3125 = 5⁵, which is of the form 2ᵐ × 5ⁿ with m = 0, n = 5. The fraction is already in lowest terms, so yes — it terminates.

SHORTS33 marks

3. Prove that √3 is irrational.

Show Answer

Ans:

Assume √3 is rational. Then √3 = p/q where p, q are coprime integers and q ≠ 0.
Squaring: 3 = p²/q², so p² = 3q². Hence 3 divides p², and since 3 is prime, 3 divides p.
Write p = 3k. Then 9k² = 3q², so q² = 3k². Hence 3 divides q², so 3 divides q.
So 3 divides both p and q, contradicting that they are coprime.
Therefore √3 is irrational.

SHORTS43 marks

4. The HCF of 96 and 404 is 4. Find their LCM.

Show Answer

Ans:

HCF × LCM = product, so LCM = (96 × 404)/4 = 38784/4 = 9696.

LONGL54 marks

5. An army contingent of 616 members marches behind an army band of 32 members. Both groups must march in the same number of columns. What is the maximum number of columns?

Show Answer

Ans:

Maximum columns = HCF(616, 32).
616 = 2³ × 7 × 11 and 32 = 2⁵.
HCF = 2³ = 8, so the maximum is 8 columns.

LONGL65 marks

6. Discuss “Real Numbers” in detail. Include the idea that carries marks, one worked example or answer frame, and why students lose marks.

Show Answer

Ans:

Euclid’s Division Lemma. Given positive integers a and b, there exist unique integers q and r satisfying a = bq + r, where 0 ≤ r < b. It is the basis of the HCF algorithm: divide, then repeat with (b, r) until the remainder is 0. The last non-zero divisor is the HCF.
Marks lens: marks, always procedural. Expect one HCF/LCM word problem (2–3 marks), one irrationality proof (3 marks), and one terminating-decimal question (1 mark).
Method / memory trick: Terminating test: look only at the denominator. If, after reducing, the denominator has any prime other than 2 or 5, it repeats. Ignore the numerator entirely.
Do not: Using HCF × LCM = product for three numbers. It fails. Factorise instead.
