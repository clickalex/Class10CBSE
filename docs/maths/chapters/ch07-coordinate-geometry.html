Chapter 7 · Coordinate Geometry

Chapter 7 of 14. Three formulas, six marks, no surprises. Finish this unit early and bank it.

🎯 Marks lens 📖 Deep concepts 🧮 Formulas 🛠️ Steps 🧠 Tricks ⚠️ Mistakes ❓ Exam Q&A ✍️ Task

🎯 Marks lens

6 marks, almost always formula substitution.
Typical questions: distance between two points, a point dividing a segment in a given ratio, finding an unknown coordinate from a given distance, and area of a triangle or collinearity.

📖 Deep concepts

1. Distance formula. The distance between (x₁, y₁) and (x₂, y₂) is √[(x₂ − x₁)² + (y₂ − y₁)²] — just Pythagoras.
2. Section formula. The point dividing the segment joining (x₁, y₁) and (x₂, y₂) internally in the ratio m:n is ((mx₂ + nx₁)/(m+n), (my₂ + ny₁)/(m+n)).
3. Midpoint is the section formula with m:n = 1:1.
4. Centroid of a triangle is the average of the three vertices’ coordinates.
5. Area of a triangle. (1/2)|x₁(y₂ − y₃) + x₂(y₃ − y₁) + x₃(y₁ − y₂)|. If this comes out as 0, the three points are collinear.

🧮 Formulas to memorise

  • d = √[(x₂ − x₁)² + (y₂ − y₁)²]
  • Section: ((mx₂ + nx₁)/(m+n), (my₂ + ny₁)/(m+n))
  • Midpoint: ((x₁+x₂)/2, (y₁+y₂)/2)
  • Centroid: ((x₁+x₂+x₃)/3, (y₁+y₂+y₃)/3)
  • Area = ½|x₁(y₂−y₃) + x₂(y₃−y₁) + x₃(y₁−y₂)|

🛠️ Method, step by step

  1. Write every point as (x, y) and mark roughly where it lies — a quick sketch catches sign errors before they reach the formula.
  2. For a distance use d = √[(x₂ − x₁)² + (y₂ − y₁)²]; for a midpoint use ((x₁ + x₂)/2, (y₁ + y₂)/2). Keep the differences in brackets until you have squared them.
  3. For a section, apply the section formula with m : n in the order given: ((mx₂ + nx₁)/(m + n), (my₂ + ny₁)/(m + n)). For a trisection, take m : n as 1 : 2 then 2 : 1.
  4. For collinearity, check that the area of the triangle is zero, or that the slopes of all three pairs match — state which test you used.

🧠 Memory tricks

  • Section formula cross pattern: m goes with the second point’s coordinates and n with the first. Write it out once correctly and reuse it.
  • Equidistant point problems: set the two distances equal and square both sides immediately to remove the roots.
  • Collinearity is the same calculation as area = 0. Do not learn it as a separate method.
  • A point on the x-axis has y = 0; a point on the y-axis has x = 0. Substituting that first halves the working.

⚠️ Mistakes that cost marks

  • Mixing up which ratio component multiplies which point in the section formula.
  • Forgetting the modulus in the area formula, then reporting a negative area.
  • Sign errors with negative coordinates: (x₂ − x₁) with x₁ negative becomes addition.
  • Leaving the distance as an unsimplified surd when an exact value is wanted.

SHORTS12 marks

1. Find the distance between (−2, 3) and (4, −5).

Show Answer

Ans:

Using the distance formula d = √[(x₂ − x₁)² + (y₂ − y₁)²]: d = √[(4 − (−2))² + (−5 − 3)²] = √[36 + 64] = √100 = 10 units. Note the signs: subtracting a negative coordinate becomes an addition, and both differences are squared, so it does not matter which point is taken first.

SHORTS22 marks

2. Find the point that divides the segment joining (−1, 7) and (4, −3) in the ratio 2:3.

Show Answer

Ans:

x = (2(4) + 3(−1))/5 = (8 − 3)/5 = 1.
y = (2(−3) + 3(7))/5 = (−6 + 21)/5 = 3.
The point is (1, 3).

SHORTS33 marks

3. Find a relation between x and y if the point (x, y) is equidistant from (3, 6) and (−3, 4).

Show Answer

Ans:

Set the squared distances equal: (x−3)² + (y−6)² = (x+3)² + (y−4)².
Expanding and cancelling x² and y²: −6x − 12y + 45 = 6x − 8y + 25.
So 12x + 4y = 20, that is 3x + y = 5.

SHORTS43 marks

4. Find the area of the triangle with vertices (1, −1), (−4, 2k) and (−k, 5) if the area is 24/2 square units.

Show Answer

Ans:

Area = ½|1(2k − 5) + (−4)(5 − (−1)) + (−k)(−1 − 2k)|
= ½|2k − 5 − 24 + k + 2k²| = ½|2k² + 3k − 29| = 12.
So 2k² + 3k − 29 = ±24, giving 2k² + 3k − 53 = 0 or 2k² + 3k − 5 = 0.
The second factorises as (2k + 5)(k − 1) = 0, so k = 1 or k = −5/2. Always keep both the + and − cases because of the modulus.

SHORTS73 marks

7. Find the ratio in which the point (−1, 6) divides the line segment joining (−3, 10) and (6, −8).

Show Answer

Ans:

Let the ratio be k : 1. Using the section formula on x: −1 = (6k − 3)/(k + 1).
⇒ −k − 1 = 6k − 3 ⇒ 7k = 2 ⇒ k = 2/7, so the ratio is 2 : 7.
Verify with y: (−8(2/7) + 10)/(9/7) = (54/7) × (7/9) = 6, which matches.

LONGL104 marks

10. Find the area of the quadrilateral with vertices (−4, −2), (−3, −5), (3, −2) and (2, 3), taken in order.

Show Answer

Ans:

Split it along the diagonal AC into ΔABC and ΔACD.
ar(ABC) = ½|(−4)(−5 + 2) + (−3)(−2 + 2) + 3(−2 + 5)| = ½|12 + 0 + 9| = 10.5 sq units.
ar(ACD) = ½|(−4)(−2 − 3) + 3(3 + 2) + 2(−2 + 2)| = ½|20 + 15 + 0| = 17.5 sq units.
Total area = 10.5 + 17.5 = 28 sq units.

LONGL114 marks

11. Show that the points (1, 7), (4, 2), (−1, −1) and (−4, 4) are the vertices of a square.

Show Answer

Ans:

Each side: AB = √(9 + 25) = √34, BC = √(25 + 9) = √34, CD = √(9 + 25) = √34, DA = √(25 + 9) = √34 — all equal.
Diagonals: AC = √(4 + 64) = √68 and BD = √(64 + 4) = √68 — equal.
A quadrilateral with all four sides equal and equal diagonals is a square.
