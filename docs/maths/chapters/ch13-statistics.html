Chapter 13 · Statistics

🎯 Marks lens

Most of the 11-mark Statistics and Probability unit, roughly 7–8 marks.
Almost always one 4–5 mark question: find the mean, median or mode of grouped data, or find a missing frequency f.
The step-deviation method is the fastest and is accepted for the mean.

📖 Deep concepts

1. Grouped data. Data arranged in class intervals with frequencies. For calculations, each class is represented by its class mark xᵢ = (upper limit + lower limit)/2.
2. Three methods for the mean. Direct method, assumed-mean method and step-deviation method. All three give the same answer — use whichever suits the numbers.

MethodFormula
Directx̄ = Σfᵢxᵢ / Σfᵢ
Assumed meanx̄ = a + (Σfᵢdᵢ / Σfᵢ), where dᵢ = xᵢ − a
Step deviationx̄ = a + (Σfᵢuᵢ / Σfᵢ) × h, where uᵢ = (xᵢ − a)/h

3. Median of grouped data. Median = l + [((N/2 − cf)/f) × h], where l is the lower limit of the median class, N = Σfᵢ, cf is the cumulative frequency of the class before the median class, f is the frequency of the median class and h is the class width.
4. Finding the median class. Compute N/2 and find the class whose cumulative frequency is the first one greater than N/2.
5. Mode of grouped data. Mode = l + [(f₁ − f₀)/(2f₁ − f₀ − f₂)] × h, where l is the lower limit of the modal class (highest frequency), f₁ its frequency, f₀ the frequency of the preceding class and f₂ of the following class.
6. Empirical relationship. 3 Median = Mode + 2 Mean. Handy for checking your answers when all three are asked.
7. Ogives. A less than ogive plots the upper class limits against the less-than cumulative frequencies. A more than ogive plots the lower limits against more-than cumulative frequencies. The x-coordinate where the two curves intersect is the median.

🧮 Formulas to memorise

  • Class mark xᵢ = (upper + lower)/2
  • Mean x̄ = Σfᵢxᵢ / Σfᵢ
  • Step deviation: x̄ = a + (Σfᵢuᵢ / Σfᵢ) × h
  • Median = l + [((N/2 − cf)/f) × h]
  • Mode = l + [(f₁ − f₀)/(2f₁ − f₀ − f₂)] × h
  • 3 Median = Mode + 2 Mean

🛠️ Method, step by step

  1. Add a class-mark column (xᵢ) and a cumulative-frequency column (cf) before you start any calculation.
  2. For the mean, pick a as a class mark near the middle so the deviations are small.
  3. For the median, compute N/2 first and identify the median class from the cf column.
  4. For the mode, identify the modal class from the frequency column, not the cumulative one.
  5. Check with 3 Median = Mode + 2 Mean if you have computed all three.

🧠 Memory tricks

  • Median class vs modal class are different things. Median comes from the cumulative frequency crossing N/2; mode comes from the largest frequency.
  • cf in the median formula is the cumulative frequency of the class before the median class. Using the median class’s own cf is the single most common error here.
  • Choose a = a class mark (not a class limit) for the assumed mean, and h = the class width.
  • If a class is written as “10–20, 20–30”, the boundary value 20 belongs to the later class.
  • For a missing frequency f, use Σfᵢ = N and the mean formula together to get two equations.

⚠️ Mistakes that cost marks

  • Using class limits instead of class marks in the mean.
  • Using the wrong cf in the median formula.
  • In the mode formula, taking f₀ and f₂ from the wrong side.
  • Forgetting to multiply by h at the end of the step-deviation and mode formulas.
  • Drawing an ogive with class marks on the x-axis. Ogives use class limits.

SHORTS12 marks

1. Find the class mark of the class 25–35.

Show Answer

Ans:

The class mark is the midpoint of the class: (lower limit + upper limit) ÷ 2 = (25 + 35)/2 = 30. It stands in for every value in that interval when a mean is calculated from grouped data, which is why it is also called the mid-value.

SHORTS22 marks

2. Write the formula for the mode of grouped data and explain each symbol.

Show Answer

Ans:

Mode = l + [(f₁ − f₀)/(2f₁ − f₀ − f₂)] × h, where l is the lower limit of the modal class, f₁ its frequency, f₀ the frequency of the class before it, f₂ the frequency of the class after it, and h the class size. The modal class is the class with the highest frequency.

SHORTS33 marks

3. Find the mean of the data: class intervals 0–10, 10–20, 20–30, 30–40 with frequencies 3, 5, 7, 5.

Show Answer

Ans:

Class marks: 5, 15, 25, 35. Σfᵢ = 20.
Σfᵢxᵢ = 3(5) + 5(15) + 7(25) + 5(35) = 15 + 75 + 175 + 175 = 440.
Mean = 440/20 = 22.

SHORTS43 marks

4. Find the mode of the data: 10–20 (f = 3), 20–30 (f = 12), 30–40 (f = 9).

Show Answer

Ans:

Modal class is 20–30 (highest frequency 12).
l = 20, f₁ = 12, f₀ = 3, f₂ = 9, h = 10.
Mode = 20 + [(12 − 3)/(24 − 3 − 9)] × 10 = 20 + (9/12) × 10 = 20 + 7.5 = 27.5.

LONGL74 marks

7. Find the median of the distribution: 0–10 (f = 4), 10–20 (f = 6), 20–30 (f = 10), 30–40 (f = 8), 40–50 (f = 2).

Show Answer

Ans:

Cumulative frequencies: 4, 10, 20, 28, 30. So N = 30 and N/2 = 15.
The first cf greater than 15 is 20, so the median class is 20–30.
l = 20, cf = 10, f = 10, h = 10.
Median = 20 + [((15 − 10)/10) × 10] = 20 + 5 = 25.

LONGL84 marks

8. The mean of the distribution 0–10 (f = 5), 10–20 (f = f), 20–30 (f = 8), 30–40 (f = 7) is 20.5. Find f.

Show Answer

Ans:

Class marks: 5, 15, 25, 35.
Σfᵢ = 5 + f + 8 + 7 = f + 20.
Σfᵢxᵢ = 25 + 15f + 200 + 245 = 15f + 470.
Mean = (15f + 470)/(f + 20) = 20.5.
15f + 470 = 20.5f + 410, so 5.5f = 60 and f ≈ 10.9. Check your reading of the data — frequencies must be whole numbers, so re-check the given mean before answering.

LONGL114 marks

11. Find the mean of this data by the step-deviation method: 0–20 (f = 7), 20–40 (f = 12), 40–60 (f = 16), 60–80 (f = 13), 80–100 (f = 12).

Show Answer

Ans:

Class marks: 10, 30, 50, 70, 90. Take A = 50 and h = 20, so u = −2, −1, 0, 1, 2.
Σf = 60 and Σfu = 7(−2) + 12(−1) + 16(0) + 13(1) + 12(2) = −14 − 12 + 13 + 24 = 11.
Mean = A + h(Σfu/Σf) = 50 + 20(11/60) = 50 + 3.67 = 53.67.

APPLICATIONA124 marks

12. For the distribution 0–10 (5), 10–20 (8), 20–30 (12), 30–40 (7), 40–50 (3), write the less-than cumulative frequencies, name the median class and find the median.

Show Answer

Ans:

Less-than cumulative frequencies: 5, 13, 25, 32, 35. N = 35, so N/2 = 17.5.
The cumulative frequency first crosses 17.5 in the class 20–30, so that is the median class.
Median = l + [(N/2 − cf)/f] × h = 20 + [(17.5 − 13)/12] × 10 = 20 + 3.75 = 23.75.
