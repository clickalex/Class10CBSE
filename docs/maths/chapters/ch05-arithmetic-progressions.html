Chapter 5 · Arithmetic Progressions

Chapter 5 of 14. Two formulas and a great many word problems. One of the most reliably scoring chapters.

Open this chapter’s questions + MCQs →Mock-test this chapter (timed, scored) →

🎯 Marks lens 📖 Deep concepts 🧮 Formulas 🛠️ Steps 🧠 Tricks ⚠️ Mistakes ❓ Exam Q&A ✍️ Task

🎯 Marks lens

5–6 marks. Typically one 3-mark question on finding a term or the number of terms, and one 4–5 mark word problem.
Common framings: which term of the AP is a given number, the sum of the first n terms, instalment tables and seating arrangements.

📖 Deep concepts

1. Definition. An AP has a constant common difference d = aₙ₊₁ − aₙ between consecutive terms.
2. General term. aₙ = a + (n − 1)d.
3. Sum of n terms. Sₙ = (n/2)[2a + (n − 1)d], or equivalently Sₙ = (n/2)(a + l) where l is the last term.
4. Recovering the nth term from the sum. aₙ = Sₙ − Sₙ₋₁. This is asked more often than students expect.
5. Useful facts. If three terms are consecutive then the middle one is the average of the other two: 2b = a + c. Taking three terms as a − d, a, a + d makes sum problems collapse quickly.

🧮 Formulas to memorise

  • aₙ = a + (n − 1)d
  • Sₙ = (n/2)[2a + (n − 1)d]
  • Sₙ = (n/2)(first term + last term)
  • aₙ = Sₙ − Sₙ₋₁
  • Sum of first n natural numbers = n(n + 1)/2

🛠️ Method, step by step

  1. Write down a and d explicitly — including the sign of d.
  2. Decide which formula the question needs: a term, a sum, or the number of terms.
  3. If solving for n you get a quadratic. Reject the non-positive or non-integer root — n must be a positive whole number.
  4. For word problems, identify what the terms represent (instalments, seats, savings) before substituting.

🧠 Memory tricks

  • d can be negative. A decreasing AP has a negative d; students lose marks by writing it positive.
  • Three unknown terms whose sum is known: take them as a − d, a, a + d. The sum gives 3a immediately.
  • “Which term is 78?”: substitute into aₙ = a + (n−1)d and solve for n. If n is not a whole number, that number is not in the AP.
  • If Sₙ is given as a formula in n (like 3n² + 5n), use aₙ = Sₙ − Sₙ₋₁ rather than trying to read a and d off it.

⚠️ Mistakes that cost marks

  • Using a + nd instead of a + (n − 1)d.
  • Taking d as positive in a decreasing AP.
  • Accepting a fractional or negative value of n.
  • In Sₙ = (n/2)(a + l), using the wrong l — it is the last term actually present.

SHORTS12 marks

1. Find the 20th term from the last term of the AP 3, 8, 13, …, 253.

Show Answer

Ans:

Counting from the end, the AP is 253, 248, 243, … with a = 253 and d = −5.
20th term = 253 + 19(−5) = 158.

SHORTS22 marks

2. Find the sum of the first 20 terms of the AP 7, 10, 13, …

Show Answer

Ans:

Here a = 7, d = 3 and n = 20. S₂₀ = (20/2)[2(7) + 19(3)] = 10(14 + 57) = 10 × 71 = 710.

SHORTS33 marks

3. Which term of the AP 3, 15, 27, 39, … will be 132 more than its 54th term?

Show Answer

Ans:

54th term = 3 + 53(12) = 639.
Required term = 639 + 132 = 771.
3 + (n − 1)12 = 771 gives (n − 1)12 = 768, so n = 65.

SHORTS43 marks

4. If the sum of the first n terms of an AP is 3n² + 5n, find its 10th term.

Show Answer

Ans:

aₙ = Sₙ − Sₙ₋₁.
S₁₀ = 300 + 50 = 350 and S₉ = 243 + 45 = 288.
a₁₀ = 350 − 288 = 62.

SHORTS73 marks

7. How many terms of the AP 24, 21, 18, … must be taken to give a sum of 78? Explain the two answers.

Show Answer

Ans:

Sₙ = (n/2)[2(24) + (n − 1)(−3)] = n(51 − 3n)/2 = 78.
⇒ 3n² − 51n + 156 = 0 ⇒ n² − 17n + 52 = 0 ⇒ (n − 4)(n − 13) = 0.
So n = 4 or n = 13. Both are valid: the terms from the 5th to the 13th are negative and cancel out the extra positive terms.

LONGL104 marks

10. The first term of an AP is 5, the last term is 45 and the sum of all terms is 400. Find the number of terms and the common difference.

Show Answer

Ans:

Sₙ = (n/2)(a + l) ⇒ 400 = (n/2)(5 + 45) = 25n ⇒ n = 16.
l = a + (n − 1)d ⇒ 45 = 5 + 15d ⇒ d = 40/15 = 8/3.
So there are 16 terms with common difference 8/3.

LONGL115 marks

11. A sum of Rs 700 is to be used to give seven cash prizes, each prize being Rs 20 less than its preceding prize. Find the value of each prize.

Show Answer

Ans:

Seven prizes in AP with d = −20 and S₇ = 700.
700 = (7/2)[2a + 6(−20)] = (7/2)(2a − 120).
200 = 2a − 120, so a = 160.
The prizes are Rs 160, 140, 120, 100, 80, 60 and 40.
