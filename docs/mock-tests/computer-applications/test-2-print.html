1. The topology in which every computer is connected to every other computer is the [Network Types, Topologies & Devices]

  • (a) mesh topology
  • (b) star topology
  • (c) bus topology
  • (d) ring topology

Answer: __________   Correct: (a) mesh topology

2. Which medium is immune to electrical interference? [Network Types, Topologies & Devices]

  • (a) twisted pair
  • (b) coaxial
  • (c) optical fibre
  • (d) infrared

Answer: __________   Correct: (c) optical fibre

3. Which network covers a whole city? [Network Types, Topologies & Devices]

  • (a) LAN
  • (b) MAN
  • (c) WAN
  • (d) PAN

Answer: __________   Correct: (b) MAN

4. Which topology has a single point of failure at its centre? [Network Types, Topologies & Devices]

  • (a) Mesh
  • (b) Bus
  • (c) Star
  • (d) Ring

Answer: __________   Correct: (c) Star

5. 4G networks are described as — [Mobile & Wireless Technology]

  • (a) analog
  • (b) circuit-switched
  • (c) all-IP
  • (d) infrared-based

Answer: __________   Correct: (c) all-IP

  • (c) copy the whole chapter

7. NFC works only when the two devices are [Mobile & Wireless Technology]

  • (a) a few centimetres apart

  • (d) several metres apart

  • (b) kilometres
  • (c) centimetres
  • (d) it has no limit

Answer: __________   Correct: (c) centimetres

  • (a) 3G
  • (b) 1G
  • (c) 2G
  • (d) 5G

Answer: __________   Correct: (a) 3G

11. Which generation first made video calling practical? [Mobile & Wireless Technology]

  • (a) 2G
  • (b) 3G
  • (c) 4G
  • (d) 1G

Answer: __________   Correct: (b) 3G

12. Which standard family defines Wi-Fi? [Mobile & Wireless Technology]

  • (a) IEEE 802.3
  • (b) IEEE 802.11
  • (c) IEEE 802.15
  • (d) IEEE 802.16

Answer: __________   Correct: (b) IEEE 802.11

14. A padlock symbol in the address bar means the page [Web Browsers, Search & Web Concepts]

  • (a) is served over an encrypted HTTPS connection
  • (b) is free
  • (c) is saved offline
  • (d) belongs to the government

15. Google is an example of a — [Web Browsers, Search & Web Concepts]

  • (a) browser
  • (b) search engine
  • (c) protocol
  • (d) server operating system

Answer: __________   Correct: (b) search engine

16. The address bar of a browser shows the [Web Browsers, Search & Web Concepts]

  • (a) URL of the page you are on
  • (b) IP address of your own computer
  • (c) size of the page
  • (d) number of visitors to the site

Answer: __________   Correct: (a) URL of the page you are on

17. The entry page of a website is called the — [Web Browsers, Search & Web Concepts]

  • (a) portal
  • (b) home page
  • (c) cache
  • (d) feed

  • (a) router
  • (b) crawler
  • (c) modem
  • (d) gateway

Answer: __________   Correct: (b) crawler

  • (d) portal
