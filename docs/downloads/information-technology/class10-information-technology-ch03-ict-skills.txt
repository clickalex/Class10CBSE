A. WRITTEN QUESTIONS (12)
------------------------------------------------------------------------

Q1. [Short · 1 mark] What is an operating system? Give two examples.
    Ans: System software that manages hardware and runs programs. Examples: Windows, Linux, Android.

Q2. [Short · 2 marks] Differentiate a file and a folder with one example each.
    Ans: A file stores data (marks.ods). A folder stores files and other folders (Class10/IT/).

Q3. [Short · 2 marks] What is an operating system? Name two examples.
    Ans: An operating system is the system software that manages the computer's memory, processor, disks and devices and lets the user run application programs. Examples are Windows, Linux, macOS and Android.

Q4. [Short · 2 marks] What is the Recycle Bin, and how is restoring a file different from deleting it permanently?
    Ans: The Recycle Bin is a holding area where deleted files wait until it is emptied. Restoring returns the file to its original folder, so nothing is lost. Deleting permanently (emptying the Bin, or Shift + Delete) removes the file beyond easy recovery — which is why important files should be backed up before the Bin is emptied.

Q5. [Short · 2 marks] List four basic care rules that protect a computer from physical damage and data loss.
    Ans:
      Keep the machine dust-free and away from food and drink, which damage keyboards and circuits.
      Use a surge protector so voltage spikes do not harm the hardware.
      Shut down through the OS command instead of pulling the plug, which can corrupt files.
      Run updated antivirus software and keep a backup of important work.

Q6. [Application · 3 marks] Amit eats chips over the keyboard and never shuts the PC down. List three risks and three care steps.
    Ans: Risks: crumbs jam keys, oil damage, overheating, data loss. Care: no food/drink, proper shutdown, dust-free vents, surge protector, backups.

Q7. [Application · 3 marks] A student says, “Windows, Linux and LibreOffice Writer are all operating systems.” Correct the statement.
    Ans:
      Windows and Linux are operating systems: system software that controls the hardware and lets other programs run.
      LibreOffice Writer is application software, a word processor used to create documents; it runs on top of an operating system.
      Other operating systems are macOS and Android; other applications are Calc and a web browser.

Q8. [Short · 3 marks] How would you organise files and folders so that your work is always easy to find?
    Ans:
      Make one folder for each subject or project, and inside it one folder per term or per type of work.
      Give every file a short, descriptive name with the date, such as maths_notes_2026-08-12.
      Keep the folder tree shallow — no more than two or three levels — and delete or archive old versions.
      Keep a backup copy on an external drive or in the cloud, and run an antivirus scan on anything you download.

Q9. [Short · 3 marks] Why should files be given clear names and kept in subject-wise folders? Illustrate with a school-project example.
    Ans:
      Clear names and folders make work findable: a file named aaa.odt on a crowded Desktop is easily lost or overwritten.
      Example — a project split as Project/notes.odt, Project/images/, Project/final-report.odt lets any part be found in seconds.
      Good organisation also protects against loss: one folder is easy to back up, scattered files are not.

Q10. [Competency · 4 marks] Read and answer:
    
    Meera’s project file vanished after a power cut. She had saved only on the Desktop as aaa.odt.
    
    (a) Two file-management mistakes.
    (b) Two care/maintenance steps that would have helped.
    Ans:
      (a) No backup; a meaningless file name; Desktop-only copy.
      (b) Surge protector / UPS; Save As into a named folder; weekly backup on a pen drive or cloud.

Q11. [Competency · 4 marks] Read and answer:
    
    Rohan creates a letter in Writer, a budget in Calc and a database in Base. He also wants to give his teacher a copy of the letter that opens in Microsoft Word.
    
    (a) Give the default file extension for each of the three files.
    (b) What is the difference between Save and Save As?
    (c) How can he make a Word-compatible copy?
    Ans:
      (a) Writer: .odt; Calc: .ods; Base: .odb.
      (b) Save overwrites the current file; Save As lets you choose a new name, folder or file type and keeps the original.
      (c) Use File → Save As and choose the Word file type (.docx) in the “Save as type” box.

Q12. [Long · 5 marks] Describe five basic file-management operations in an operating system and give the shortcut or method for each.
    Ans:
      Create a folder: right-click an empty space and choose New → Folder, then type its name.
      Rename: select the file and press F2 (or right-click → Rename).
      Copy: select the file, press Ctrl + C, open the destination and press Ctrl + V.
      Move: select the file, press Ctrl + X, open the destination and press Ctrl + V (or drag it there).
      Delete: press Delete to send it to the Recycle Bin, from where it can be restored; Shift + Delete removes it permanently.

B. MCQs (8)
------------------------------------------------------------------------

M1. Which is an OS? (a) LibreOffice Writer (b) Chrome (c) Linux (d) Calc
    Ans: (c) Linux.

M2. .ods is usually: (a) a Writer file (b) a Calc spreadsheet (c) a Base database (d) an image
    Ans: (b) a Calc spreadsheet.

M3. The Recycle Bin is used to: (a) speed up RAM (b) store deleted files until emptied (c) install an OS (d) scan viruses
    Ans: (b).

M4. A computer should be shut down: (a) by pulling the plug (b) using the OS shutdown command (c) by holding the monitor button (d) never
    Ans: (b).

M5. Which of the following is application software? (a) Windows (b) Linux (c) Android (d) LibreOffice Writer
    Ans: (d) LibreOffice Writer. Writer is a program for a task (word processing); the others are operating systems.

M6. A folder that is stored inside another folder is called a: (a) shortcut (b) sub-folder (c) file extension (d) drive
    Ans: (b) sub-folder. Folders can be nested, and a folder within a folder is a sub-folder.

M7. Which of these is an operating system? (a) Linux  (b) MS Word  (c) Chrome  (d) HDMI
    Ans: (a) Linux. Word and Chrome are application programs and HDMI is a port.

M8. The keyboard shortcut used to copy a selected file is: (a) Ctrl + C  (b) Ctrl + V  (c) Ctrl + X  (d) Ctrl + P
    Ans: (a) Ctrl + C. Ctrl + V pastes, Ctrl + X cuts and Ctrl + P prints.
