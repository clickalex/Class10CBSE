A. WRITTEN QUESTIONS (12)
------------------------------------------------------------------------

Q1. [Short · 2 marks] What is Goal Seek in Calc?
    Ans: A what-if tool: you set the result you want in a formula cell and Calc finds the input value that produces it.

Q2. [Short · 2 marks] What is a scenario?
    Ans: A named set of values for specified cells so you can switch between cases (best/worst) without retyping.

Q3. [Short · 2 marks] What is the difference between a scenario and Goal Seek?
    Ans: A scenario is a named set of input values that you save and switch between to compare outcomes, such as best case, worst case and expected case. Goal Seek works the other way: you state the result you want and Calc finds the single input value that produces it.

Q4. [Short · 2 marks] What is Solver in Calc, and how does it differ from Goal Seek?
    Ans: Solver finds input values that produce a target result, like Goal Seek — but it can change many cells at once and respect constraints (for example, quantities that must stay whole numbers). Goal Seek changes exactly one cell with no constraints. Use Goal Seek for one unknown, Solver for many.

Q5. [Application · 3 marks] A shop wants profit of ₹8,000. Profit is =B2*B3-B4 (price × qty − cost). Which tool, and which cell is “By changing” if qty and cost are fixed?
    Ans:
      Use Goal Seek (Tools → Goal Seek). Set cell = the profit cell, To value = 8000, and By changing cell = the price cell B2.
      Goal Seek works backwards: instead of asking what the profit is, it asks what input would produce the profit you want, and it tries values until the formula cell reaches 8000.
      Only one input cell can be changed, so the quantity and the cost must stay fixed while the price is adjusted.

Q6. [Application · 3 marks] Riya is revising “Scenarios and Goal Seek (Calc)” (Data consolidation, subtotals, what-if scenarios, Goal Seek and Solver). A classmate lost marks by doing this: Mixing up Goal Seek (one input) with Solver (many inputs + constraints). Apply the correct method and rewrite the scoring answer.
    Ans:
      Correct method: Goal Seek needs a formula in the set cell. Typing a number there will fail.
      Why the mistake costs marks: Mixing up Goal Seek (one input) with Solver (many inputs + constraints).
      Write the definition or formula first, then the working or example.

Q7. [Short · 3 marks] Describe how to use Goal Seek in Calc, with an example.
    Ans:
      Build the sheet so that the result cell contains a formula, for example the EMI for a loan in B5.
      Choose Tools → Goal Seek and fill in the dialog: Formula Cell B5, Target Value 8000, Variable Cell B2 (the interest rate or the loan amount).
      Click OK; Calc changes the variable cell step by step until the formula gives the target, and reports whether it succeeded.
      This is quicker than trial and error when only one input is unknown.

Q8. [Short · 3 marks] What is the ‘Group’ feature in Calc? Explain with a monthly-expense sheet example.
    Ans:
      Group (Data → Define Range → Group) bundles rows or columns so they can be collapsed to a single line or expanded again with one click.
      Example — a yearly sheet with twelve monthly blocks: group each month's daily rows, collapse all twelve, and only the monthly totals stay visible for review.
      Unlike hiding, grouping shows a clear plus/minus control, so hidden detail is never forgotten.

Q9. [Long · 4 marks] Differentiate Consolidate and Subtotals.
    Ans: Consolidate combines several ranges/sheets into one summary (often another sheet). Subtotals insert summary rows inside one sorted list (sum of each group). Consolidate is across blocks; Subtotals is inside a table.

Q10. [Competency · 4 marks] Read and answer:
    
    Four quarterly sheets have the same layout of expenses. The owner wants one yearly total that updates if a quarter changes.
    
    (a) Which tool?
    (b) Two settings to tick/choose.
    (c) Why not just type the four totals by hand?
    Ans:
      (a) Data → Consolidate.
      (b) Function Sum; add each range; Link to source data.
      (c) Manual totals go stale; a link updates and reduces typing errors.

    Ans:

B. MCQs (8)
------------------------------------------------------------------------

M1. Goal Seek is on the menu: (a) Insert (b) Tools (c) Format (d) Window
    Ans: (b) Tools.

M2. Before Subtotals you must: (a) insert a chart (b) sort the group column (c) record a macro (d) protect the sheet
    Ans: (b) sort.

M3. A named best-case / worst-case set of inputs is a: (a) style (b) scenario (c) query (d) template
    Ans: (b) scenario.

M4. Consolidate is best when data is: (a) on several similar sheets (b) a single cell (c) an image (d) a Writer ToC
    Ans: (a).

M5. The most exam-ready way to revise “Scenarios and Goal Seek (Calc)” is: (a) read the heading only  (b) learn the key idea plus one example  (c) skip written practice  (d) memorise a random extra topic
    Ans: (b) learn the key idea plus one example. The chapter is Data consolidation, subtotals, what-if scenarios, Goal Seek and Solver.

M6. A 3-mark answer on “Scenarios and Goal Seek (Calc)” should: (a) be one sentence  (b) start with the idea, then a reason or method  (c) copy the whole chapter  (d) leave the example out
    Ans: (b) start with the idea, then a reason or method. Step marks follow that frame.

M7. Subtotals in Calc are created from: (a) Data → Subtotals  (b) Tools → Subtotals  (c) Insert → Subtotals  (d) Format → Subtotals
    Ans: (a) Data → Subtotals. Calc groups the rows and inserts the subtotal formula for you.

M8. Consolidating data means: (a) combining data from several sheets or ranges into one summary  (b) deleting duplicate rows  (c) sorting a column  (d) filtering rows
    Ans: (a) combining data from several sheets or ranges into one summary. It is useful when each branch sends its own sheet.
