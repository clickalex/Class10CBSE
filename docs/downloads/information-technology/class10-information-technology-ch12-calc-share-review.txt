A. WRITTEN QUESTIONS (12)
------------------------------------------------------------------------

Q1. [Short · 2 marks] How do you share a Calc spreadsheet?
    Ans: Tools → Share Spreadsheet → enable sharing. Save on a network location the team can open.

Q2. [Short · 2 marks] Why add a comment to a cell instead of changing the value?
    Ans: A comment suggests or questions without overwriting data; the original number stays until someone decides.

Q3. [Short · 2 marks] What does recording changes do when a spreadsheet is shared?
    Ans: Edit → Track Changes → Record logs every edit with the author's name, the time and the old value. Each change can then be reviewed, accepted or rejected from Edit → Track Changes → Manage, so a team can work on one file without losing track of who changed what.

Q4. [Short · 2 marks] What is the difference between accepting and rejecting a recorded change? Where is each done?
    Ans: Accepting keeps the edited value as the final content; rejecting discards the edit and restores the original value. Both are done in the Manage Changes dialogue (Edit → Track Changes → Manage), which lists every change with its author and time so each can be judged separately.

Q5. [Application · 3 marks] Three lab partners type in three copies of stock.ods and the totals disagree. What should they have used?
    Ans: One shared spreadsheet (or one file with Record Changes + merge), not three independent copies.

Q6. [Application · 3 marks] A teacher types her corrections into a shared spreadsheet and only afterwards switches on Record Changes. Why do her corrections not appear in the review list, and what should she do?
    Ans:
      Recording tracks only edits made after it is switched on; the changes already typed are not marked.
      She should first turn on Edit → Track Changes → Record, and then make the corrections.
      Each change is then shown with the author and date, so it can later be accepted or rejected.

Q7. [Short · 3 marks] How do you compare two versions of a document in LibreOffice?
    Ans:
      Open the newer copy and choose Edit → Track Changes → Compare Document.
      Select the older copy in the file dialog and click Insert; LibreOffice shows the differences as tracked changes.
      Review each one with Next and Previous, then accept or reject it from the Manage dialog.
      This works in both Writer and Calc and is the safest way to merge two people's work.

Q8. [Short · 3 marks] What is ‘Protect Sheet’, and why must input cells be unlocked before it is applied?
    Ans:
      Protect Sheet (Tools → Protect Sheet) locks the sheet so that only permitted actions — usually editing unlocked cells — are possible.
      By default every cell is locked, so protecting first would freeze the whole sheet including the inputs.
      Correct order — select the input cells, uncheck Protected in Format → Cells → Protection, then protect the sheet; formulas stay safe while inputs stay editable.

Q9. [Long · 4 marks] Explain recording, showing and accepting changes in Calc.
    Ans: Turn Record on before editing. Each changed cell is marked. Show lists author, date and old/new value. Accept keeps the new value; Reject restores the old. Compare Document does this against a saved copy.

Q10. [Competency · 4 marks] Read and answer:
    
    A teacher wants students to fill only column B, not the formulas in C.
    
    (a) Which tool?
    (b) Steps.
    (c) How can the teacher see who changed B5?
    Ans:
      (a) Protect Sheet (unlock B first).
      (b) Select B → unprotect cells; Tools → Protect Sheet; set password.
      (c) Record / Show Changes — author and date on B5.

Q11. [Competency · 4 marks] Read and answer:
    
    A class keeps stock.ods on the lab server. Two students open it at the same time and both change cell C5.
    
    (a) How can the file be shared so that several people can edit it at once?
    (b) What happens when the two students save?
    (c) Why is it useful to record changes in such a file?
    Ans:
      (a) Choose Tools → Share Spreadsheet and allow it to be edited by several users.
      (b) When the second student saves, Calc finds the conflict and asks which version of C5 to keep.
      (c) It records who changed which cell and when, so the changes can be reviewed and wrong ones rejected.

Q12. [Long · 5 marks] Describe a five-step method for a class to review a spreadsheet together.
    Ans:
      Step 1: protect the cells that must not change (such as formulas) with Protect Sheet, leaving the input cells unlocked.
      Step 2: turn on Edit → Track Changes → Record so that every edit is recorded.
      Step 3: share the file with Tools → Share Spreadsheet so that several people can work on it.
      Step 4: reviewers add comments to cells that need attention instead of changing the values.
      Step 5: the owner goes through the changes and accepts or rejects each one, and merges any separate copies back into the original.

B. MCQs (8)
------------------------------------------------------------------------

M1. Share Spreadsheet is under: (a) Insert (b) Tools (c) Format (d) Data
    Ans: (b) Tools.

M2. A cell comment is for: (a) hiding formulas forever (b) notes without changing the value (c) Goal Seek (d) styles
    Ans: (b).

M3. To allow editing only some cells: (a) Group (b) Protect Sheet after unlocking inputs (c) Consolidate (d) Mail Merge
    Ans: (b).

M4. Compare Document is useful when: (a) you have an older copy to diff (b) you need a chart (c) you insert an image (d) you write a ToC
    Ans: (a).

M5. The feature that locks cells so that formulas cannot be changed by mistake is: (a) Protect Sheet (b) Freeze Rows (c) Goal Seek (d) Fill Series
    Ans: (a) Protect Sheet. Protect Sheet (with the input cells left unlocked) stops people from editing the locked cells.

M6. Bringing another user’s copy of a spreadsheet back into the shared original is called: (a) consolidating (b) subtotalling (c) merging (d) formatting
    Ans: (c) merging. Merging combines the changes made in another copy with the original document.

M7. Sharing a sheet while protecting it from changes is done from: (a) Tools → Protect Sheet  (b) File → Print  (c) Insert → Comment  (d) Format → Cells
    Ans: (a) Tools → Protect Sheet. You can also allow selected users to edit certain ranges.

M8. Comments in a spreadsheet are used to: (a) ask a question or explain a cell without changing its value  (b) delete the cell  (c) sort the data  (d) create a chart
    Ans: (a) ask a question or explain a cell without changing its value. The cell keeps its formula.
