A. WRITTEN QUESTIONS (12)
------------------------------------------------------------------------

Q1. [Short · 2 marks] Differentiate data and information with an example.
    Ans: Data are raw facts (42, “Neha”). Information is processed and meaningful (“Neha’s attendance is 42 days”).

Q2. [Short · 2 marks] What is a primary key? Give one example.
    Ans: A field (or set of fields) that uniquely identifies each record and cannot be empty. Example: AdmissionNo in a Student table.

Q3. [Short · 2 marks] Distinguish between data and information with an example.
    Ans: Data are raw, unprocessed facts, such as the marks obtained by each student in each subject. Information is data that has been processed and given meaning, such as the class average, the highest mark or a list of students who passed. A database stores data; queries and reports turn it into information.

Q4. [Short · 2 marks] What is a foreign key? Explain with a Student–Library example how it links two tables.
    Ans: A foreign key is a field in one table that refers to the primary key of another table. Example — the Issue table stores RollNo as a foreign key pointing to the Student table's RollNo primary key, so each issued book is tied to exactly one student without retyping the student's name and class.

Q5. [Application · 3 marks] A school stores students in one sheet with teacher phone numbers typed against every student. Two problems, and the DBMS idea that fixes them.
    Ans: Redundancy (phone typed 40 times) and inconsistency (one row has the old number). Split into Student and Teacher tables with a foreign key.

Q6. [Application · 3 marks] A student writes: “Calc is the DBMS we use in this course.” Correct this and give one reason why a DBMS suits large, related data better than a spreadsheet.
    Ans:
      Calc is a spreadsheet. The DBMS used in this course is LibreOffice Base.
      A spreadsheet keeps everything in one table, so data such as a teacher’s phone number is repeated against every student.
      A DBMS keeps data in related tables linked by keys, which reduces repetition and errors and keeps the data consistent.

Q7. [Short · 3 marks] List any four advantages of a DBMS over a simple file system.
    Ans:
      It removes duplication, so the same fact is stored once and every user sees the same value.
      It keeps the data consistent and lets the designer set rules, so that wrong data cannot easily be entered.
      It allows many users to work at the same time without overwriting each other's work.
      It gives security through passwords and permissions, and fast searching, sorting and reporting through queries.

Q8. [Short · 3 marks] Define field, record and table with reference to a school database.
    Ans:
      Field — one attribute, such as Name or Class; a column of the table.
      Record — all the fields for one item, such as one student's complete row.
      Table — the full set of records of one kind, such as the Student table holding every student's row.

Q9. [Long · 4 marks] List four advantages of a DBMS over a paper register or a single Calc sheet.
    Ans: Less duplication; one correction updates all uses; password/security; backup and recovery; many users; validation (integrity). A Calc sheet is easy to duplicate and hard to relate as tables grow.

Q10. [Competency · 4 marks] Read and answer:
    
    A clinic keeps patient names in a diary. Two staff write different spellings; a page is lost.
    
    (a) Two problems of this system.
    (b) Two DBMS advantages that help.
    (c) Suggest a primary key.
    Ans:
      (a) Inconsistency, no backup, slow search, redundancy.
      (b) Central consistent data, backup/recovery, validation, sharing.
      (c) PatientID or a unique registration number — not the name.

Q11. [Competency · 4 marks] Read and answer:
    
    A library keeps three tables: Book (BookID, Title), Member (MemberID, Name) and Issue (IssueID, BookID, MemberID, IssueDate).
    
    (a) Which field is the primary key of each table?
    (b) Which fields in Issue are foreign keys?
    (c) Why is a separate Issue table used?
    Ans:
      (a) BookID in Book, MemberID in Member and IssueID in Issue.
      (b) BookID and MemberID, because they refer to the primary keys of Book and Member.
      (c) Many members issue many books, so each issue is recorded as a row in Issue instead of repeating book or member details.

Q12. [Long · 5 marks] Compare a flat-file database and a relational database on five points.
    Ans:
      Structure: a flat file is a single table, as in a Calc sheet; a relational database has several related tables, as in Base.
      Repetition: a flat file repeats data (for example teacher details against each student); a relational database stores each fact once.
      Updating: a change in a flat file must be made in many rows; in a relational database it is made in one place.
      Links: a flat file has no relationships; a relational database joins tables through primary and foreign keys.
      Use: a flat file suits small, simple lists; a relational database suits large data with many connected items.

B. MCQs (8)
------------------------------------------------------------------------

M1. Which is information, not raw data? (a) 36 (b) “Amit” (c) “Amit’s temperature is 36 °C” (d) a blank cell
    Ans: (c).

M2. LibreOffice Base is: (a) a DBMS (b) an OS (c) a browser (d) a style
    Ans: (a) a DBMS.

M3. A good primary key for books is: (a) Title (b) Author (c) ISBN (d) Colour
    Ans: (c) ISBN.

M4. A foreign key: (a) deletes the database (b) refers to a primary key in another table (c) is always a picture (d) is a macro
    Ans: (b).

M5. Which of the following is a DBMS? (a) LibreOffice Calc (b) LibreOffice Writer (c) LibreOffice Base (d) LibreOffice Impress
    Ans: (c) LibreOffice Base. Base is the database program; Calc is a spreadsheet, Writer a word processor and Impress a presentation program.

M6. A field that uniquely identifies each record in a table is called the: (a) foreign key (b) alias (c) query (d) primary key
    Ans: (d) primary key. A primary key has a different value in every record, so that no two records can be confused.

M7. The field that uniquely identifies each record in a table is the: (a) primary key  (b) foreign key  (c) index  (d) alias
    Ans: (a) primary key. It must be unique and cannot be empty.

M8. Which of these is DBMS software? (a) LibreOffice Base  (b) MS Word  (c) Google Chrome  (d) VLC player
    Ans: (a) LibreOffice Base. MySQL, PostgreSQL and Oracle are other examples.
