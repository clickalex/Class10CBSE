A. WRITTEN QUESTIONS (12)
------------------------------------------------------------------------

Q1. [Short · 2 marks] Find the distance between (−2, 3) and (4, −5).
    Ans: Using the distance formula d = √[(x₂ − x₁)² + (y₂ − y₁)²]: d = √[(4 − (−2))² + (−5 − 3)²] = √[36 + 64] = √100 = 10 units. Note the signs: subtracting a negative coordinate becomes an addition, and both differences are squared, so it does not matter which point is taken first.

Q2. [Short · 2 marks] Find the point that divides the segment joining (−1, 7) and (4, −3) in the ratio 2:3.
    Ans:
      x = (2(4) + 3(−1))/5 = (8 − 3)/5 = 1.
      y = (2(−3) + 3(7))/5 = (−6 + 21)/5 = 3.
      The point is (1, 3).

Q3. [Short · 3 marks] Find a relation between x and y if the point (x, y) is equidistant from (3, 6) and (−3, 4).
    Ans:
      Set the squared distances equal: (x−3)² + (y−6)² = (x+3)² + (y−4)².
      Expanding and cancelling x² and y²: −6x − 12y + 45 = 6x − 8y + 25.
      So 12x + 4y = 20, that is 3x + y = 5.

Q4. [Short · 3 marks] Find the area of the triangle with vertices (1, −1), (−4, 2k) and (−k, 5) if the area is 24/2 square units.
    Ans:
      Area = ½|1(2k − 5) + (−4)(5 − (−1)) + (−k)(−1 − 2k)|
      = ½|2k − 5 − 24 + k + 2k²| = ½|2k² + 3k − 29| = 12.
      So 2k² + 3k − 29 = ±24, giving 2k² + 3k − 53 = 0 or 2k² + 3k − 5 = 0.
      The second factorises as (2k + 5)(k − 1) = 0, so k = 1 or k = −5/2. Always keep both the + and − cases because of the modulus.

Q5. [Application · 3 marks] Riya is revising “Coordinate Geometry” (Distance formula, section formula, area of a triangle). A classmate lost marks by doing this: Mixing up which ratio component multiplies which point in the section formula. Apply the correct method and rewrite the scoring answer.
    Ans:
      Correct method: Section formula cross pattern: m goes with the second point’s coordinates and n with the first. Write it out once correctly and reuse it.
      Why the mistake costs marks: Mixing up which ratio component multiplies which point in the section formula.
      Write the definition or formula first, then the working or example.

Q6. [Application · 3 marks] Amit is given this exam-style task from “Coordinate Geometry”: “Find the distance between (−2, 3) and (4, −5).” Treat it as an application question. Identify the idea, then write the working in points.
    Ans:
      Idea: Distance formula, section formula, area of a triangle.
      d = √[(4 − (−2))² + (−5 − 3)²] = √[36 + 64] = √100 = 10 units.

Q7. [Short · 3 marks] Find the ratio in which the point (−1, 6) divides the line segment joining (−3, 10) and (6, −8).
    Ans:
      Let the ratio be k : 1. Using the section formula on x: −1 = (6k − 3)/(k + 1).
      ⇒ −k − 1 = 6k − 3 ⇒ 7k = 2 ⇒ k = 2/7, so the ratio is 2 : 7.
      Verify with y: (−8(2/7) + 10)/(9/7) = (54/7) × (7/9) = 6, which matches.

Q10. [Long · 4 marks] Find the area of the quadrilateral with vertices (−4, −2), (−3, −5), (3, −2) and (2, 3), taken in order.
    Ans:
      Split it along the diagonal AC into ΔABC and ΔACD.
      ar(ABC) = ½|(−4)(−5 + 2) + (−3)(−2 + 2) + 3(−2 + 5)| = ½|12 + 0 + 9| = 10.5 sq units.
      ar(ACD) = ½|(−4)(−2 − 3) + 3(3 + 2) + 2(−2 + 2)| = ½|20 + 15 + 0| = 17.5 sq units.
      Total area = 10.5 + 17.5 = 28 sq units.

Q11. [Long · 4 marks] Show that the points (1, 7), (4, 2), (−1, −1) and (−4, 4) are the vertices of a square.
    Ans:
      Each side: AB = √(9 + 25) = √34, BC = √(25 + 9) = √34, CD = √(9 + 25) = √34, DA = √(25 + 9) = √34 — all equal.
      Diagonals: AC = √(4 + 64) = √68 and BD = √(64 + 4) = √68 — equal.
      A quadrilateral with all four sides equal and equal diagonals is a square.

Q12. [Long · 5 marks] Discuss “Coordinate Geometry” in detail. Include the idea that carries marks, one worked example or answer frame, and why students lose marks.
    Ans:
      Distance formula. The distance between (x₁, y₁) and (x₂, y₂) is √[(x₂ − x₁)² + (y₂ − y₁)²] — just Pythagoras.
      Marks lens: marks, almost always formula substitution.
      Method / memory trick: Section formula cross pattern: m goes with the second point’s coordinates and n with the first. Write it out once correctly and reuse it.
      Do not: Mixing up which ratio component multiplies which point in the section formula.

B. MCQs (8)
------------------------------------------------------------------------

M1. The distance of the point (3, 4) from the origin is: (a) 5  (b) 7  (c) 25  (d) 12
    Ans: (a) 5. √(9 + 16) = 5.

M2. The midpoint of (2, −3) and (−6, 5) is: (a) (−2, 1)  (b) (2, −1)  (c) (−4, 2)  (d) (4, −8)
    Ans: (a) (−2, 1). ((2−6)/2, (−3+5)/2).

M3. Three points are collinear if the area of the triangle they form is: (a) 1  (b) maximum  (c) 0  (d) negative
    Ans: (c) 0.

M4. The most exam-ready way to revise “Coordinate Geometry” is: (a) read the heading only  (b) learn the key idea plus one example  (c) skip written practice  (d) memorise a random extra topic
    Ans: (b) learn the key idea plus one example. The chapter is Distance formula, section formula, area of a triangle.

M5. A 3-mark answer on “Coordinate Geometry” should: (a) be one sentence  (b) start with the idea, then a reason or method  (c) copy the whole chapter  (d) leave the example out
    Ans: (b) start with the idea, then a reason or method. Step marks follow that frame.

M6. The point (−3, 0) lies on: (a) the x-axis  (b) the y-axis  (c) the line y = x  (d) the origin
    Ans: (a) the x-axis. Every point whose y-coordinate is 0 lies on the x-axis.

M7. The distance of (a cos θ, a sin θ) from the origin is: (a) a  (b) a²  (c) 1  (d) 2a
    Ans: (a) a. Distance = √(a²cos²θ + a²sin²θ) = √(a²) = a.

M8. The centroid of the triangle with vertices (2, 3), (−4, 7) and (2, −4) is: (a) (0, 2)  (b) (0, 0)  (c) (2, 2)  (d) (0, 3)
    Ans: (a) (0, 2). x = (2 − 4 + 2)/3 = 0 and y = (3 + 7 − 4)/3 = 2.
