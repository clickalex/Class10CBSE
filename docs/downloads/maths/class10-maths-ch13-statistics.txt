A. WRITTEN QUESTIONS (12)
------------------------------------------------------------------------

Q1. [Short · 2 marks] Find the class mark of the class 25–35.
    Ans: The class mark is the midpoint of the class: (lower limit + upper limit) ÷ 2 = (25 + 35)/2 = 30. It stands in for every value in that interval when a mean is calculated from grouped data, which is why it is also called the mid-value.

Q2. [Short · 2 marks] Write the formula for the mode of grouped data and explain each symbol.
    Ans: Mode = l + [(f₁ − f₀)/(2f₁ − f₀ − f₂)] × h, where l is the lower limit of the modal class, f₁ its frequency, f₀ the frequency of the class before it, f₂ the frequency of the class after it, and h the class size. The modal class is the class with the highest frequency.

Q3. [Short · 3 marks] Find the mean of the data: class intervals 0–10, 10–20, 20–30, 30–40 with frequencies 3, 5, 7, 5.
    Ans:
      Class marks: 5, 15, 25, 35. Σfᵢ = 20.
      Σfᵢxᵢ = 3(5) + 5(15) + 7(25) + 5(35) = 15 + 75 + 175 + 175 = 440.
      Mean = 440/20 = 22.

Q4. [Short · 3 marks] Find the mode of the data: 10–20 (f = 3), 20–30 (f = 12), 30–40 (f = 9).
    Ans:
      Modal class is 20–30 (highest frequency 12).
      l = 20, f₁ = 12, f₀ = 3, f₂ = 9, h = 10.
      Mode = 20 + [(12 − 3)/(24 − 3 − 9)] × 10 = 20 + (9/12) × 10 = 20 + 7.5 = 27.5.

Q5. [Application · 3 marks] Riya is revising “Statistics” (Mean, median and mode of grouped data, and ogives). A classmate lost marks by doing this: Using class limits instead of class marks in the mean. Apply the correct method and rewrite the scoring answer.
    Ans:
      Correct method: Median class vs modal class are different things. Median comes from the cumulative frequency crossing N/2; mode comes from the largest frequency.
      Why the mistake costs marks: Using class limits instead of class marks in the mean.
      Write the definition or formula first, then the working or example.

Q6. [Application · 3 marks] Amit is given this exam-style task from “Statistics”: “Find the class mark of the class 25–35.” Treat it as an application question. Identify the idea, then write the working in points.
    Ans:
      Idea: Mean, median and mode of grouped data, and ogives.
      Class mark = (25 + 35)/2 = 30.

Q7. [Long · 4 marks] Find the median of the distribution: 0–10 (f = 4), 10–20 (f = 6), 20–30 (f = 10), 30–40 (f = 8), 40–50 (f = 2).
    Ans:
      Cumulative frequencies: 4, 10, 20, 28, 30. So N = 30 and N/2 = 15.
      The first cf greater than 15 is 20, so the median class is 20–30.
      l = 20, cf = 10, f = 10, h = 10.
      Median = 20 + [((15 − 10)/10) × 10] = 20 + 5 = 25.

Q8. [Long · 4 marks] The mean of the distribution 0–10 (f = 5), 10–20 (f = f), 20–30 (f = 8), 30–40 (f = 7) is 20.5. Find f.
    Ans:
      Class marks: 5, 15, 25, 35.
      Σfᵢ = 5 + f + 8 + 7 = f + 20.
      Σfᵢxᵢ = 25 + 15f + 200 + 245 = 15f + 470.
      Mean = (15f + 470)/(f + 20) = 20.5.
      15f + 470 = 20.5f + 410, so 5.5f = 60 and f ≈ 10.9. Check your reading of the data — frequencies must be whole numbers, so re-check the given mean before answering.

Q11. [Long · 4 marks] Find the mean of this data by the step-deviation method: 0–20 (f = 7), 20–40 (f = 12), 40–60 (f = 16), 60–80 (f = 13), 80–100 (f = 12).
    Ans:
      Class marks: 10, 30, 50, 70, 90. Take A = 50 and h = 20, so u = −2, −1, 0, 1, 2.
      Σf = 60 and Σfu = 7(−2) + 12(−1) + 16(0) + 13(1) + 12(2) = −14 − 12 + 13 + 24 = 11.
      Mean = A + h(Σfu/Σf) = 50 + 20(11/60) = 50 + 3.67 = 53.67.

Q12. [Application · 4 marks] For the distribution 0–10 (5), 10–20 (8), 20–30 (12), 30–40 (7), 40–50 (3), write the less-than cumulative frequencies, name the median class and find the median.
    Ans:
      Less-than cumulative frequencies: 5, 13, 25, 32, 35. N = 35, so N/2 = 17.5.
      The cumulative frequency first crosses 17.5 in the class 20–30, so that is the median class.
      Median = l + [(N/2 − cf)/f] × h = 20 + [(17.5 − 13)/12] × 10 = 20 + 3.75 = 23.75.

B. MCQs (8)
------------------------------------------------------------------------

M1. The class mark of the class 15–25 is: (a) 15  (b) 20  (c) 25  (d) 10
    Ans: (b) 20. (15 + 25)/2.

M2. The median class is the class whose cumulative frequency is: (a) equal to N/2  (b) the first one greater than N/2  (c) the largest  (d) the smallest
    Ans: (b) The first one greater than N/2.

M3. If mean = 20 and mode = 26, then by the empirical relation the median is: (a) 22  (b) 22.67  (c) 23  (d) 24
    Ans: (a) 22. 3 Median = 26 + 2(20) = 66, so Median = 22.

M4. The most exam-ready way to revise “Statistics” is: (a) read the heading only  (b) learn the key idea plus one example  (c) skip written practice  (d) memorise a random extra topic
    Ans: (b) learn the key idea plus one example. The chapter is Mean, median and mode of grouped data, and ogives.

M5. A 3-mark answer on “Statistics” should: (a) be one sentence  (b) start with the idea, then a reason or method  (c) copy the whole chapter  (d) leave the example out
    Ans: (b) start with the idea, then a reason or method. Step marks follow that frame.

M6. The mode of 3, 5, 7, 5, 9, 5, 8 is: (a) 3  (b) 5  (c) 7  (d) 9
    Ans: (b) 5. It occurs three times, more than any other value.

M7. The class mark of the class 45–55 is: (a) 45  (b) 50  (c) 55  (d) 100
    Ans: (b) 50. Class mark = (lower limit + upper limit)/2 = 50.

M8. The empirical relation connecting the three measures of central tendency is: (a) Mode = 3 Median − 2 Mean  (b) Median = 3 Mode − 2 Mean  (c) Mean = 3 Median − 2 Mode  (d) Mode = 2 Median − Mean
    Ans: (a) Mode = 3 Median − 2 Mean. Equivalently, 3 Median = Mode + 2 Mean.
