# 03 · Mathematics (Standard 041 / Basic 241)

Standard and Basic share the **same syllabus**; Basic tests the same topics at a
lower difficulty. Keep both in this one folder and label files `-std` / `-basic`.

- **Session:** 2026–27 · folder tree and chapter list checked 12 Sep 2026
- **Theory:** 80 marks · **Internal assessment:** 20 marks · **Time:** 3 hours

## Chapters — NCERT Class X textbook order

**Note the book order vs. the syllabus order.** The textbook puts Triangles (6)
before Coordinate Geometry (7), but Coordinate Geometry is its own unit. Folder
numbers follow the **book**, not the unit, so keep the NCERT solution PDFs
straight.

Trigonometric identities (`sin²A + cos²A = 1` and friends) are a *topic inside*
Chapter 8, not a separate chapter — file them under `ch08-Introduction-to-Trigonometry/`.

## Highest-return places to start

Algebra is 20 of 80 marks on its own (Chapters 2–5), and Statistics +
Probability is another 11. Those six chapters are half the paper.
