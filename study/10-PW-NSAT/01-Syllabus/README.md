# Class 10 syllabus

1. Open the [official PW NSAT page](https://www.pw.live/scholarship/vidyapeeth/nsat).
2. Choose **View Syllabus**, then **Class 10th** (your current class).
3. Save the current syllabus locally and note the exam cycle and download date.
4. Make a checklist of topics and compare it with your school preparation.

No syllabus PDF is copied here. Follow PW's current syllabus rather than assuming
that every CBSE Class 10 chapter is included. PDF files are ignored by this repo.
