# Diploma / polytechnic college options

These routes are alternatives to Class XI–XII, not school admissions. Each portal publishes participating colleges and branch/seat lists; it is not one college. Verify recognition, further-study options and state eligibility.

[Website directory](https://clickalex.github.io/Class10CBSE/after-10th/#diploma) · [Live daily report](https://clickalex.github.io/Class10CBSE/after-10th/report.html) · [Daily checker](../02-Admission-Tracker/README.md)

## Haryana polytechnic colleges — HSTES Diploma Engineering

- **Location:** Haryana; useful for a Delhi NCR shortlist
- **Route:** First-year Diploma Engineering admissions through HSTES merit/counselling, rather than a general entrance test.
- **Eligibility to verify:** Check Class X subjects/marks, domicile, reservation and approved college/branch lists. Choose first-year engineering diploma, not lateral entry or pharmacy; their requirements differ.
- **Cycle:** 2027-28 admission; verify the new prospectus
- **Timing:** Not verified for 2027-28. Follow the current official prospectus and counselling notices.
- **Official sources:** <https://www.hstes.org.in/>

## Uttar Pradesh polytechnic colleges — JEECUP / UPJEE(P)

- **Location:** Uttar Pradesh
- **Route:** Polytechnic entrance test followed by counselling. Look for first-year engineering/technology groups that accept Class X.
- **Eligibility to verify:** Check group-specific Class X eligibility, subjects, age, domicile and seat rules in the current brochure. Not every JEECUP group accepts Class X; pharmacy and post-diploma routes differ.
- **Cycle:** 2027-28 admission; verify the new prospectus
- **Timing:** Not verified for 2027-28. Follow the current official prospectus and counselling notices.
- **Official sources:** <https://jeecup.admissions.nic.in/>

## Bihar polytechnic colleges — DCECE (PE)

- **Location:** Bihar
- **Route:** Diploma Certificate Entrance Competitive Examination, Polytechnic Engineering (PE) route and counselling.
- **Eligibility to verify:** Verify Class X qualification, marks, residence/category and medical requirements for PE. Do not confuse PE with PM/PMM or lateral-entry exams, which have different eligibility.
- **Cycle:** 2027-28 admission; verify the new prospectus
- **Timing:** Not verified for 2027-28. Follow the current official prospectus and counselling notices.
- **Official sources:** <https://bceceboard.bihar.gov.in/DCECEIndex.php>
