# Class XI / intermediate school shortlist

Entrance-test and merit/vacancy routes are different. Verify current Class X eligibility, age, streams and hostel rules.

[Website directory](https://clickalex.github.io/Class10CBSE/after-10th/#school) · [Live daily report](https://clickalex.github.io/Class10CBSE/after-10th/report.html) · [Daily checker](../02-Admission-Tracker/README.md)

## JMI — Jamia Millia Islamia schools

- **Location:** New Delhi
- **Route:** Class XI school admission / entrance test; check the current school prospectus for each stream.
- **Eligibility to verify:** Class X qualification, stream-wise marks and age rules apply. Check school, stream, category and hostel availability separately.
- **Cycle:** 2027-28 admission; verify the new prospectus
- **Timing:** Not verified for 2027-28. Do not reuse last year's dates.
- **Official sources:** <https://admission.jmi.ac.in/> · <https://jmicoe.in/>

## AMU — Senior Secondary School (Class XI)

- **Location:** Aligarh, Uttar Pradesh
- **Route:** Class XI admission test; consult the admission guide for Science and other available streams.
- **Eligibility to verify:** Class X qualification, marks, age and stream-specific requirements apply. School admission is not undergraduate admission.
- **Cycle:** 2027-28 admission; verify the new prospectus
- **Timing:** Not verified for 2027-28. Watch for the new admission guide.
- **Official sources:** <https://www.amucontrollerexams.com/>

## BHU / CHS — Central Hindu Boys' and Girls' Schools

- **Location:** Varanasi, Uttar Pradesh
- **Route:** School Entrance Test (SET) for Class XI; consult the bulletin for the relevant school and stream.
- **Eligibility to verify:** Class X qualification and current marks/age criteria apply. Check boys'/girls' school eligibility and available streams. This is SET, not CUET UG.
- **Cycle:** 2027-28 admission; verify the new prospectus
- **Timing:** Not verified for 2027-28. Watch for the new SET bulletin.
- **Official sources:** <https://bhuonline.in/>

## JNV — Jawahar Navodaya Vidyalayas

- **Location:** Participating districts across India
- **Route:** Class XI Lateral Entry Selection Test (LEST), against vacant seats.
- **Eligibility to verify:** Check district/residence, school location, age and Class X study requirements in the current prospectus. This is not the Class VI or IX test.
- **Cycle:** 2027-28 admission; verify the new prospectus
- **Timing:** Check immediately: the application cycle can precede Class X board results. No deadline is confirmed by this tracker.
- **Official sources:** <https://navodaya.gov.in/nvs/en/Admission-Notifications/Class-XI/> · <https://cbseitms.nic.in/2026/nvsxi_11/>

## Kendriya Vidyalayas — Class XI backup option

- **Location:** Local KVs, including Delhi NCR
- **Route:** Merit / vacancy-based admission, not a general Class XI entrance exam.
- **Eligibility to verify:** Non-KV students depend on vacancies after eligible KV students. Check current stream cut-offs, priorities and the individual school's notice.
- **Cycle:** 2027-28 admission; verify the new prospectus
- **Timing:** Follow the current KVS schedule and local school notices around Class X results; exact dates are not verified.
- **Official sources:** <https://kvsangathan.nic.in/en/admission/>

## Ramakrishna Mission Vidyalaya, Narendrapur — Class XI

- **Location:** Narendrapur, West Bengal
- **Route:** Higher-secondary admission for selected external students; check the current Class XI selection notice.
- **Eligibility to verify:** Confirm whether external Class X students are being admitted this cycle, gender/residential rules, accepted boards, medium, streams and marks requirements. Old Class XI notices are still on the site.
- **Cycle:** 2027-28 admission; verify the new prospectus
- **Timing:** Not verified for 2027-28. Follow the current official prospectus and counselling notices.
- **Official sources:** <https://www.rkmvnarendrapur.org/>

## Chandigarh government senior secondary schools — Class XI

- **Location:** Chandigarh
- **Route:** Centralised Class XI school/stream allotment and counselling; a non-entrance-test backup route.
- **Eligibility to verify:** Check Class X marks, stream criteria, category rules and preferences for students from Chandigarh schools. Do not assume every seat is available to an out-of-state applicant.
- **Cycle:** 2027-28 admission; verify the new prospectus
- **Timing:** Not verified for 2027-28. Follow the current official prospectus and counselling notices.
- **Official sources:** <https://www.chdeducation.gov.in/>
