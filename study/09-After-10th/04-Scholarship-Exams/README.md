# Scholarship exams for Class 10 students

These are private coaching scholarship tests, not government cash scholarships or school admission tests. An “up to” award is not guaranteed. Compare the final payable course fee, validity and centre/mode restrictions.

[Website directory](https://clickalex.github.io/Class10CBSE/after-10th/#scholarship) · [Live daily report](https://clickalex.github.io/Class10CBSE/after-10th/report.html) · [Daily checker](../02-Admission-Tracker/README.md)

## PW NSAT — Physics Wallah

- **Location:** PW Vidyapeeth / participating centres and online test options
- **Route:** Coaching admission-cum-scholarship test; separate from Class XI school admission.
- **Eligibility to verify:** Select current Class 10 and confirm the intended next-session course. Verify scholarship components, remaining fees, validity and online/offline conditions.
- **Cycle:** Current test cycle for Class 10 students; course/admission year varies
- **Timing:** See the separate PW NSAT hub for a dated 2026 snapshot. Recheck current slots and closing date with PW.
- **Official sources:** <https://www.pw.live/scholarship/vidyapeeth/nsat>

## ALLEN TALLENTEX

- **Location:** ALLEN participating centres / offered test modes
- **Route:** Talent-search and coaching scholarship examination; not a school admission test.
- **Eligibility to verify:** Class X has been included in the published eligibility range. Confirm the current cycle, present class, course year and test mode. Online and classroom scholarships may have different conditions.
- **Cycle:** Current test cycle for Class 10 students; course/admission year varies
- **Timing:** Current dates not verified: the main portal could not be fetched during this update. Do not use archived cycle dates. Open the official site manually.
- **Official sources:** <https://www.tallentex.com/>

## Aakash ANTHE — National Talent Hunt Exam

- **Location:** Aakash participating centres / online
- **Route:** Talent-hunt test for coaching scholarships; cash awards, if offered, have separate conditions.
- **Eligibility to verify:** Class 10 students should select their current class and intended JEE/NEET/Foundation course. Check test-mode differences, fee components, award conditions and scholarship validity.
- **Cycle:** Current test cycle for Class 10 students; course/admission year varies
- **Timing:** Check the current ANTHE exam calendar and registration deadline. A test date is not necessarily the application closing date.
- **Official sources:** <https://anthe.aakash.ac.in/home>

## Aakash iACST — Instant Admission Cum Scholarship Test

- **Location:** Online; applicable Aakash courses/centres
- **Route:** Slot-based coaching admission and scholarship test, distinct from ANTHE.
- **Eligibility to verify:** Class 10 is within the published school-class eligibility range. Check current course/stream criteria, available slots and offer expiry before taking the test.
- **Cycle:** Current test cycle for Class 10 students; course/admission year varies
- **Timing:** Slot-based: confirm availability in the official portal rather than assuming one annual exam date. Verify the scholarship acceptance deadline.
- **Official sources:** <https://iacst.aakash.ac.in/>

## Vidyamandir Classes VIQ — Intellect Quest

- **Location:** VMC participating centres / online
- **Route:** Coaching admission-cum-scholarship test for JEE, NEET and Foundation preparation.
- **Eligibility to verify:** Class 10 is included in the published school-class range. Select current class, course and test mode; verify centre, fee components, scholarship terms and remaining course cost.
- **Cycle:** Current test cycle for Class 10 students; course/admission year varies
- **Timing:** Check the current VIQ schedule and centre/mode options. Archived NAT and VIQ pages can show different cycles; use the current registration notice.
- **Official sources:** <https://vidyamandir.com/viq-scholarship-test-free.html>
