# After Class 10 — admissions & scholarships

[Website directory](https://clickalex.github.io/Class10CBSE/after-10th/)
(updated when these changes are published).

The directory now has **15 options**: **7 Class XI school routes**, **3 diploma /
polytechnic routes** and **5 coaching scholarship exams**. For students studying
Class X in 2026–27, the school/diploma admission target is **2027–28**; scholarship
test cycles may run earlier and differ by course. “BHI” means **BHU / CHS** here.

- [Class XI school list](01-College-List/README.md): JMI, AMU, BHU/CHS, JNV, KV,
  Ramakrishna Mission Vidyalaya Narendrapur and Chandigarh government schools.
- [Diploma college routes](05-Diploma-Colleges/README.md): Haryana HSTES,
  Uttar Pradesh JEECUP and Bihar DCECE (PE), with official college/seat-list portals.
- [Scholarship exam list](04-Scholarship-Exams/README.md): PW NSAT, ALLEN
  TALLENTEX, Aakash ANTHE, Aakash iACST and VMC VIQ.
- [Daily 9 PM IST checker and tracking sheet](02-Admission-Tracker/README.md)
- [Entrance preparation plan](03-Preparation/README.md)

All directory sources are included in the checker. This is not confirmation of
open registration. The scheduler requires activation on GitHub; see instructions.

Keep the routes separate: a coaching scholarship does not secure a school seat,
a diploma is not automatically equivalent to every Class XII stream, and
merit-based admissions do not require the same exams as test-based routes.
Verify course recognition, eligibility, location, fees and hostel availability.
