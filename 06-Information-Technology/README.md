# 06 · Information Technology — Skill Subject (Code 402)

**Only if IT is your sixth subject.** If not, delete this folder.

- **Total:** 100 marks = Theory 50 + Practical 50
- **Job role:** Domestic Data Entry Operator
- **Software:** LibreOffice Writer, Calc and Base (not MS Office — the practical
  is set on LibreOffice)
- **Curriculum PDF:** <https://cbseacademic.nic.in/web_material/Curriculum26/sec/402-IT-X.pdf>

## Part A — Employability Skills (10 marks)

| Unit | Folder | Marks |
|---|---|---|
| Unit 1: Communication Skills-II | `unit1-Communication-Skills/` | 2 |
| Unit 2: Self-Management Skills-II | `unit2-Self-Management-Skills/` | 3 |
| Unit 3: ICT Skills-II | `unit3-ICT-Skills/` | 1 |
| Unit 4: Entrepreneurial Skills-II | `unit4-Entrepreneurial-Skills/` | 3 |
| Unit 5: Green Skills-II | `unit5-Green-Skills/` | 1 |

Short, definition-heavy, mostly MCQ and one-mark answers. Highest marks-per-hour
in the whole paper — finish this part early.

## Part B — Subject Specific Skills (40 marks)

| Unit | Folder | Marks |
|---|---|---|
| Unit 1: Digital Documentation (Advanced) — LibreOffice Writer | `unit1-Digital-Documentation-Advanced/` | 8 |
| Unit 2: Electronic Spreadsheet (Advanced) — LibreOffice Calc | `unit2-Electronic-Spreadsheet-Advanced/` | 10 |

Unit 3 (Base) is the heaviest at 12 marks — tables, queries, forms and reports.

## Parts C and D — Practical (50 marks)

| Component | Marks |
|---|---|
| Practical exam: Writer 5 + Calc 5 + Base 10 + Viva voce 10 | 30 |
| Project work / field visit (interdisciplinary case study) | 10 |
| Portfolio / practical file — min. 5 problems each in Writer, Calc and Base | 10 |

`04-Practical-File/` is where the portfolio goes: printouts of every practical
you do, grouped by tool, with the problem statement at the top of each page.

## Naming note

The official curriculum table for this session titles Part B Unit 4 *"Maintain
Healthy, Safe and Secure Working Environment"*. Some older revision guides still
call it *"Web Applications and Security"* — that is the previous version of the
unit. Check the PDF linked above before you rely on either.
