# Registration checklist

Official portal: <https://www.pw.live/scholarship/vidyapeeth/nsat>

- [ ] Confirm the current test cycle and applicable course eligibility.
- [ ] Select current class **Class 10**, not the class you intend to join next year.
- [ ] Read the current scholarship terms and remaining course fees.
- [ ] Confirm the application closing date directly; no verified deadline is stored here.
- [ ] Choose online/offline mode and confirm your test date, centre and slot.
- [ ] Complete registration only on PW's official portal.
- [ ] Save the confirmation and instructions privately.
- [ ] Set your own calendar reminders before the selected test.
- [ ] Recheck the official result date and instructions after the exam.

This repository does not collect applications or guarantee a scholarship.
Keep application IDs, phone numbers, passwords and identity documents out of Git.
